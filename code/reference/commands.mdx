title: "Commands"
description: "Every command you can type in Aristra Code in the terminal, from /help to /remote-control."
---

In the terminal, type `/` at the start of the composer to open the command menu: commands and your [skills](/code/extend/skills), filtered as you type. Up and Down choose, Tab completes, Enter runs it (a command that needs an argument waits for you to type one), and Esc closes the menu and clears the composer. An unknown command isn't sent. To send a message that starts with `/`, start it with a space.

Aristra Desktop's `/` menu has its own short list; see [Desktop's Code tab](/code/desktop#in-the-chat). For `aristra` subcommands and flags, see the [CLI reference](/code/reference/cli).

## The chat

| Command | Does |
|---|---|
| `/new` (or `/clear`, `/reset`) | Start a new chat in this folder |
| `/resume` | Go back to an earlier chat |
| `/search <words>` | Find words in the messages of every chat on this computer. `/search #2` opens the second result's chat |
| `/rename <title>` | Rename this chat |
| `/branch [name]` | Copy this chat as it is now into a new chat and carry on in the copy |
| `/fork <directive>` | Start a background agent with this chat's full context to do the directive and report back |
| `/btw <question>` | Ask a side question without interrupting the running turn; the answer isn't added to the chat |
| `/queue <message>` | Send this after the running turn finishes |
| `/rewind` (or `/checkpoint`) | Restore the code and/or the conversation to before one of your messages |
| `/export [md\|json]` | Save this chat to a file in `~/.aristra/exports/` |
| `/copy [N]` | Copy the newest reply (or the Nth newest) to the clipboard |
| `/files [words \| find WORDS \| open N \| save PATH \| update N]` | The files your chats shared, made or changed, the files you attached, and signed in, the files in your account, newest first; words search names, folders and chat titles, `find WORDS` searches inside the files (with the page of a PDF), `open N` opens one in its app (a file in your account is downloaded first), `save PATH` saves a copy of a file here to your account, and `update N [replace\|keep-both]` replaces a saved file's copy after it changed |
| `/recap` | A one-line recap of the chat now |
| `/exit` (`/quit`) | Leave; a running turn can keep going |

## Context and memory

| Command | Does |
|---|---|
| `/context [all]` | What fills the model's context, as a grid, with suggestions |
| `/compact [instructions]` | Summarize the conversation so far, keeping what the instructions say |
| `/autocompact [auto\|<tokens>]` | Set how full the context gets before it is summarized, for this model |
| `/memory` | Edit your instruction files (`AGENTS.md`), or open the repository's notes |
| `/init` | Write this folder's `AGENTS.md` from the code |
| `/goal [<condition> \| clear]` | Set a condition Aristra Code checks before it stops. See [Goals](/code/guides/goals) |

## Model and permissions

| Command | Does |
|---|---|
| `/model` | Choose the model, with who pays for it |
| `/effort [level\|auto]` | How hard the model thinks: `low`, `medium`, `high`, and on some models `xhigh` or `max` |
| `/mode [mode]` | Set the permission mode: `manual` (or `default`), `acceptEdits`, `plan`, `auto`, `dontAsk`, `bypassPermissions` (when you started `aristra` with `--dangerously-skip-permissions` or `--allow-dangerously-skip-permissions`), `read_only`. With no mode, the next one. A cloud chat has `manual` and `auto` |
| `/permissions` | Rules by source, the chat's folders, and steps Auto mode recently blocked |
| `/sandbox [exclude <pattern>]` | Run commands in the [sandbox](/code/configure/sandbox) (off by default): with auto-allow, with regular permissions, or not at all. `exclude` adds a command that always runs outside it |
| `/add-dir <path>` | Let this chat work in another folder |
| `/retry` | Let the steps Auto mode's reviewer just blocked run once, as they were |
| `/folder` | This chat's folder, and whether it is trusted |

## Git and pull requests

| Command | Does |
|---|---|
| `/diff` | Uncommitted changes and each turn's changes. In fullscreen, a diff panel beside the chat |
| `/pr [number]` | The branch's pull request: status, checks, files, review and merge |
| `/create-pr [--draft]` | Commit, push and open a pull request |
| `/commit [guidance]` | Commit the changes with a message in the repository's style |
| `/autofix-pr [number\|stop]` | Watch the pull request and fix failing checks, conflicts and review comments |

See [Git and pull requests](/code/guides/git).

## Background work

| Command | Does |
|---|---|
| `/tasks` (or `/bashes`) | Everything running in the background: agents, workflows, commands. Stop one with x |
| `/schedule [pause\|resume\|run\|remove N]` (or `/scheduled`) | The [scheduled tasks](/code/guides/background#scheduled-tasks) saved on this computer, numbered; change one by its number. To make one, ask in plain words |
| `/workflows` | Running and finished workflows: their phases and agents |

See [Background work](/code/guides/background).

## Extensions

| Command | Does |
|---|---|
| `/mcp [reconnect\|enable\|disable [<server>\|all]]` | Manage MCP servers: approve a project's, sign in, reconnect, turn one off for this project, view tools |
| `/hooks` | Your hooks by event, and which still need approval |
| `/plugin [subcommand]` (or `/plugins`, `/marketplace`) | Manage plugins and marketplaces |
| `/reload-plugins` | Read your plugins again and activate the changes in this chat |
| `/<skill> [args]` | Run one of your skills or saved workflows (a plugin's as `/<plugin>:<name>`) |
| `/mcp__<server>__<prompt> [args]` | Run an MCP server's prompt |

## Your account and setup

| Command | Does |
|---|---|
| `/help` | Every command, your skills and the keys |
| `/status` | Your account and its plan, the runtime and the model sources |
| `/usage` | Tokens this chat used and who paid, your Aristra balance in dollars and your plans' limits, and what's contributing to your usage. Without an Aristra plan, what pays for what |
| `/config` | Your settings in effect, and which file each comes from |
| `/login [code]`, `/logout` | Sign in to Aristra (`code`: with a code, on another device), or out on this computer |
| `/remote-control [off]` (or `/rc`) | Continue this chat on your phone and the web. Comes with a plan. See [Remote Control](/code/remote-control) |
| `/remote-control computer [on\|off]` | Let the web and your phone start chats on this computer. Off by default |
| `/remote-control folder [on\|off]` | Allow chats from the web and your phone to start in the folder you are in |
| `/release-notes` | What changed in each version |

## The terminal

| Command | Does |
|---|---|
| `/tui [default\|fullscreen]` | Choose the renderer: the classic one, or fullscreen |
| `/keybindings` | Open your keyboard shortcuts file |
| `/terminal-setup` | Set up a key for new lines in your terminal (Shift+Enter or Option+Enter) |

## Built-in skills

These run as [skills](/code/extend/skills#built-in-skills): `/init`, `/code-review` (or `/review`), `/simplify`, `/security-review`, `/update-config`, `/fewer-permission-prompts`, `/debug`, `/verify`, `/commit`, `/create-pr` and `/loop` (or `/proactive`), plus `workflow-authoring`, the reference Aristra Code reads when it writes a workflow. `/deep-research <question>` runs Aristra Code's built-in [workflow](/code/guides/subagents#workflows).
