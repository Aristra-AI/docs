---
title: "Settings reference"
description: "Every key in Aristra Code's settings files, with its default and what it does."
---

Settings live in `~/.aristra/settings.json` (yours), `<folder>/.aristra/settings.json` (the project's) and `<folder>/.aristra/settings.local.json` (yours, for the project). How the layers combine, and which keys a repository can't set, is in [Settings](/code/configure/settings). Keys marked *yours only* are read only from your own file.

## Model

| Key | Default | Does |
|---|---|---|
| `model.source` | `aristra` | Where new chats' model comes from: `aristra`, `chatgpt`, a provider, `ollama`, `lmstudio`, `custom` |
| `model.model` | The plan's default | The model's id |
| `model.effort` | The model's own | The reasoning level, for models that take one |
| `model.fallback` | `[]` | Up to 10 `{source, model, effort}` tried in order when a call fails. *Yours only* |
| `autoCompactWindow` | The model's window | How full the context gets before it is summarized: `"auto"` or 100,000 to 1,000,000 tokens |
| `modelSettings.<model>.autoCompactWindow` | none | The same, for one model. `/autocompact` writes it |
| `auxiliary.title`, `auxiliary.summary`, `auxiliary.memory` | The plan's background model, else the chat's | `{source, model}` from one of your own sources (not `aristra`) for titles, summaries and the memory backstop. `auxiliary.title: "off"` keeps your first words. *Yours only* |

## Permissions

| Key | Default | Does |
|---|---|---|
| `permissions.defaultMode` | `default` | The mode new chats start in: `default` (Manual), `acceptEdits`, `plan`, `auto`, `dontAsk`, `bypassPermissions`, `read_only` |
| `permissions.allow`, `ask`, `deny` | `[]` | [Permission rules](/code/configure/permissions#rules) |
| `permissions.additionalDirectories` | `[]` | More folders the chat may work in |
| `permissions.trustedMcpServers` | `[]` | MCP servers whose tools run without asking. *Yours only* |
| `permissions.disableAutoMode` | none | `"disable"` turns Auto mode off |
| `skipDangerousModePermissionPrompt` | `false` | Set when you accept the Bypass permissions warning. Not read from a project's `settings.json` |
| `skipAutoPermissionPrompt` | `false` | You opted in to Auto mode; plan mode then keeps its reviewer. Not read from a project's `settings.json` |
| `useAutoModeDuringPlan` | `true` | `false`: plan mode asks you even when you opted in to Auto. Not read from a project's `settings.json` |
| `approvals.timeoutMinutes` | `30` | How long an approval waits before it is declined (1 to 1440) |
| `projects["<folder>"].trusted` | none | Whether a folder (and its subfolders) is trusted. Set by the trust question. *Yours only* |
| `projects["<folder>"].permissions` | none | Rules for one folder. *Yours only* |
| `projects["<folder>"].mcpServers`, `.disabledMcpServers`, `.trustedMcpServers` | none | MCP servers only for that folder, turned off there, or trusted there. *Yours only* |

## Auto mode's reviewer

| Key | Default | Does |
|---|---|---|
| `review.enabled` | `true` | `false`: in Auto mode, what the reviewer would decide asks you instead. *Yours only* |
| `review.policy` | `""` | Your own guidance for the reviewer, up to 8,000 characters. *Yours only* |
| `review.model` | none | The reviewing model for chats on your own key or a local model. *Yours only* |
| `autoMode` | none | `allow`, `soft_deny` and `environment` lists for the reviewer, as Claude Code's. Not read from a project's `settings.json` |

## Sandbox

| Key | Default | Does |
|---|---|---|
| `sandbox.enabled` | `false` | Commands run in the [sandbox](/code/configure/sandbox) (`/sandbox`) |
| `sandbox.failIfUnavailable` | `false` | With `enabled`: a turn doesn't start when the sandbox can't, instead of running commands outside it |
| `sandbox.autoAllowBashIfSandboxed` | `true` | A sandboxed command runs without asking unless a rule covers it |
| `sandbox.allowUnsandboxedCommands` | `true` | Whether Aristra Code may ask to run a command outside the sandbox |
| `sandbox.excludedCommands` | `[]` | Commands that always run outside the sandbox, through the checks |
| `sandbox.filesystem.allowWrite`, `denyWrite`, `denyRead`, `allowRead` | `[]` | More paths to open or close |
| `sandbox.filesystem.allowGitConfig` | `false` | Let commands write `.git/config` |
| `sandbox.network.allowedDomains` | `[]` | Hosts commands reach without asking |
| `sandbox.network.allowLocalBinding` | `false` | Let commands listen on and reach `localhost` |
| `sandbox.network.httpProxyPort`, `socksProxyPort` | none | Your own proxy on `localhost`, in place of the sandbox's |
| `sandbox.network.allowUnixSockets`, `allowAllUnixSockets` | `[]`, `false` | `allowUnixSockets`: socket paths commands may connect to (macOS). `allowAllUnixSockets`: every Unix socket (macOS and Linux) |
| `sandbox.ignoreViolations` | `{}` | Refusals not to report back, by command |
| `sandbox.enableWeakerNestedSandbox` | `false` | In a container that can't mount `/proc` (Linux) |
| `sandbox.enableWeakerNetworkIsolation` | `false` | Open macOS's certificate service for Go tools such as `gh` behind a proxy with its own certificate authority |

## Extensions

| Key | Default | Does |
|---|---|---|
| `mcp.servers` | `{}` | Your [MCP servers](/code/extend/mcp#where-servers-are-kept). *Yours only* |
| `mcp.toolSearch` | `true` | `false` sends MCP tools in every request instead of behind tool search. *Yours only* |
| `enabledMcpjsonServers`, `disabledMcpjsonServers` | `[]` | A project's [`.mcp.json` servers](/code/extend/mcp#a-projects-mcpjson) approved or rejected. A folder's own approvals count once it's trusted |
| `enableAllProjectMcpServers` | `false` | Approve every server in a project's `.mcp.json` |
| `hooks` | `{}` | Your [hooks](/code/extend/hooks), by event |
| `disableAllHooks` | `false` | Turn off every hook except a managed policy's |
| `allowedHttpHookUrls` | any | Where HTTP hooks may send (`*` is a wildcard; `[]` allows none). Every settings file's lists count together |
| `httpHookAllowedEnvVars` | none | The variables an HTTP hook's headers may use, as well as the hook's own `allowedEnvVars` |
| `enabledPlugins` | `{}` | Plugins turned on or off, by `plugin@marketplace` |
| `pluginConfigs` | `{}` | Options for each plugin. Your own file and a managed policy only |
| `extraKnownMarketplaces` | `{}` | Marketplaces to add, by name, with their `source` |
| `agent` | none | The [custom agent](/code/guides/subagents#custom-agents) new chats run as |
| `enableWorkflows` | `true` | `false` turns [workflows](/code/guides/subagents#workflows) off |
| `disableWorkflows` | none | `true` turns workflows off |
| `workflowSizeGuideline` | `"medium"` | How many agents workflows aim for: `"small"`, `"medium"`, `"large"`, `"unrestricted"` |

## Git

| Key | Default | Does |
|---|---|---|
| `worktree.baseRef` | `"fresh"` | Where a new worktree starts: `fresh` (the origin's default branch) or `head` (the current commit) |
| `worktree.symlinkDirectories` | none | Folders linked into a new worktree instead of copied, such as `["node_modules"]` |
| `worktree.sparsePaths` | none | Paths a new worktree checks out alone |
| `includeGitInstructions` | `true` | `false` leaves git guidance out of the shell tool's instructions |
| `prStatusFooterEnabled` | `true` | Show the branch's pull request in the footer |
| `prUrlTemplate` | none | Send the footer's pull request link elsewhere, with `{host}`, `{owner}`, `{repo}`, `{number}` and `{url}` |

## Terminal

| Key | Default | Does |
|---|---|---|
| `tui` | `"default"` | `"fullscreen"` for the fullscreen renderer |
| `statusLine` | none | `{"type": "command", "command": "...", "padding": 1, "refreshInterval": 10}`: [your own status line](/code/configure/terminal#your-own-status-line) |
| `subagentStatusLine` | none | `{"type": "command", "command": "..."}`: a line for each running agent in `/tasks` |
| `copyOnSelect` | `true` | In fullscreen, copy a selection when you let go |
| `copyFullResponse` | `false` | `/copy` takes the whole reply |
| `promptSuggestionEnabled` | `true` | Suggest your next message after a reply |
| `awaySummaryEnabled` | `true` | Leave a recap in a chat you come back to |
| `spinnerTipsEnabled` | `true` | Show tips while Aristra Code works |
| `terminalProgressBarEnabled` | `true` | A progress bar in the terminal's tab while a step runs |
| `permissionExplainerEnabled` | `true` | Ctrl+E explains a command on its approval |
| `disableDeepLinkRegistration` | none | `"disable"`: don't register the `aristra-cli://` link handler |

## Runtime and privacy

`runtime`, `approvals`, `telemetry` and `web` are read from your own file and a managed policy only; a project's file can't change them. `runtime.maxRunningTurns` and `runtime.notifications` come from your own file only.

| Key | Default | Does |
|---|---|---|
| `runtime.idleExitMinutes` | `10` | Idle minutes before the runtime stops (1 to 1440) |
| `runtime.keepRunningAfterClientsLeave` | `true` | A turn keeps running after every surface has closed |
| `runtime.maxRunningTurns` | no limit | How many turns may run at once; the rest wait |
| `runtime.notifications` | `true` | Post a notification when nobody attached can show one |
| `memory.enabled` | `true` | New chats start with memory on |
| `web.keylessFallback` | `true` | When Aristra's search can't serve (your balance used up, or the service down), searches go to the free public search of Exa, Parallel, Firecrawl or Keenable, with only the search words sent (those services may keep them). `false` keeps them on your key or Aristra |
| `remoteControl.allowStart` | `false` | Let the web and phone start chats on this computer (needs an Aristra plan). *Yours only* |
| `remoteControl.startFolders` | `[]` | The trusted folders they may start chats in; never the home folder, a hidden folder in it or the root. *Yours only* |
| `telemetry.usage` | `true` | Content-free usage events |
| `telemetry.errors` | `true` | Error reports |
| `credentials.store` | `auto` | Where secrets are kept: `auto`, `keychain`, `file`. *Yours only* |
| `ui.theme` | `system` | Aristra Desktop's appearance: `system`, `light`, `dark` |
| `ui.notifications` | `true` | Aristra Desktop's notifications |

## Managed policy only

These keys count only in a [managed policy](/code/configure/managed-policy): `permissions.allowManagedPermissionRulesOnly`, `permissions.disableBypassPermissionsMode`, `sandbox.network.allowManagedDomainsOnly`, `sandbox.filesystem.allowManagedReadPathsOnly`, `allowedMcpServers`, `deniedMcpServers`, `allowManagedHooksOnly`, `strictKnownMarketplaces` (or `allowedMarketplaces`), `blockedMarketplaces`, `pluginTrustMessage` and `disableSideloadFlags`.
