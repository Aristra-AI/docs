## Zed and other ACP editors

`aristra acp` serves an editor over the [Agent Client Protocol](https://agentclientprotocol.com). The editor starts it for you.

In Zed, add Aristra as an agent server in your settings:

```json
{
  "agent_servers": {
    "Aristra": { "command": "aristra", "args": ["acp"] }
  }
}
```

Then start an Aristra thread from Zed's agent panel. The first time, Zed asks you to sign in, which opens Aristra's sign-in page in your browser.

An editor thread is an ordinary Aristra Code chat on this computer: `aristra sessions` lists it, Aristra Desktop shows it, and its approvals can be answered from any surface.

| In the editor | What happens |
|---|---|
| A new thread | A new chat in the editor's folder, with your default model and mode |
| The mode menu | Manual, Accept edits, Plan, Auto and Read only. A mode chosen elsewhere reaches the editor too |
| Your prompt | A turn. Linked files and images are attached; pasted resources are quoted |
| The thread | The reply and reasoning stream in; each step shows as a tool call with its command, diff and output |
| A permission request | Each approval, with Yes, the answer that saves a rule, and No |
| Stop | Stops the turn |
| Opening an old thread | Replays the chat's history |

Aristra Code uses its own tools (and its own sandbox, when you turn it on), not the editor's file system or terminal, and its own MCP servers from your settings, not the editor's.

<Tip>
To keep an editor's chats apart from your own (a test account, for example), add `"env": {"ARISTRA_HOME": "/path/to/home"}` to the agent server.
</Tip>

## Open Aristra Code from your editor

Aristra Desktop's **Open in** button opens a chat's folder in VS Code, Cursor, Zed, Windsurf or Xcode, and each changed file in **Review** opens at its first change.

## Links that open a terminal

An `aristra-cli://open` link opens a terminal with Aristra Code in a folder and a prompt waiting in the composer:

```text
aristra-cli://open?cwd=/Users/you/code/site&q=Review%20the%20open%20issues
aristra-cli://open?repo=acme/site&q=Fix%20the%20failing%20build
```

| Parameter | Means |
|---|---|
| `cwd` | The folder, as an absolute path |
| `repo` | Instead of `cwd`, a GitHub `owner/repo`: the clone you last used it in, else your home folder |
| `q` | The prompt, up to 5,000 characters. It is put in the composer and never sent until you press Enter |

The folder's trust question is asked as for any folder. Aristra Code registers the link handler the first time you run it interactively; set `disableDeepLinkRegistration` to `"disable"` to turn that off.
