Tools are the actions Aristra Code can take. Each call goes through your [permissions](/configure/permissions): it runs, asks you, goes to Auto mode's reviewer, or is refused. In permission rules, use the tool's name (`shell(npm test:*)`, `edit(/src/**)`) or Claude Code's names (`Bash`, `Edit`, `WebFetch`).

Some tools are sent to the model only when it searches for them, to keep each request small. They are marked *on demand*.

## Files

| Tool | Does | Asks in Manual |
|---|---|---|
| `read_file` | Read a file, or a range of its lines. Images too, and PDFs, Word, Excel, PowerPoint, OpenDocument, RTF and EPUB files as their text, read on your computer | No, in the chat's folders |
| `list_dir` | List a folder | No, in the chat's folders |
| `glob` | Find files by pattern (100 at a time, with "Showing N of M") | No, in the chat's folders |
| `grep` | Search file contents | No, in the chat's folders |
| `edit_file` | Replace text in a file. The file must have been read first, and an edit to a file changed since is refused | Yes |
| `write_file` | Create or overwrite a file | Yes |
| `apply_patch` | Apply a patch in Codex's format. GPT models get it in place of `edit_file` and `write_file` | Yes |
| `notebook_edit` | Replace, insert or delete one cell of a Jupyter notebook | Yes |

An edit that breaks a file's syntax is reported back to the model. Files in UTF-16 and other encodings keep their encoding. The edit tools never write into a Word, Excel, PowerPoint, OpenDocument, RTF or EPUB file, or over a PDF, since the model saw only their text: Aristra Code changes those with a library through a command.

## Commands and background work

| Tool | Does |
|---|---|
| `shell` | Run a command in the [sandbox](/configure/sandbox). It may run in the background, or ask to run outside the sandbox with a reason |
| `process_list`, `process_read`, `process_stop` | List, read and stop background commands, agents, workflow runs and monitors |
| `monitor` | Run a script whose output lines arrive in the chat as events, for 5 to 30 minutes |
| `cron_create`, `cron_delete`, `cron_list` | Schedule prompts in this chat, once or on a cron schedule (*on demand*) |
| `schedule_wakeup` | Pick when to look again, for a self-paced `/loop` |
| `schedule_task` | Save a [scheduled task](/guides/background#scheduled-tasks) on this computer, or change one. Always asks you first (*on demand*) |
| `scheduled_tasks` | List the saved scheduled tasks, or pause, resume, run or remove one (*on demand*) |
| `session_search` | Search, read or list your past chats on this computer, to pick up earlier work. Not in an incognito chat or one with memory off (*on demand*) |
| `push_notification` | Send you a notification on this computer, when you're away |
| `enter_worktree`, `exit_worktree` | Move the chat into a git worktree and back, only when you or your instructions ask (*on demand*) |

## Asking you

| Tool | Does |
|---|---|
| `ask_user_question` | Ask you one to four multiple-choice questions. Always asked, in every mode |
| `enter_plan_mode`, `exit_plan_mode` | Enter plan mode, and ask you to approve the plan |

## The web

| Tool | Does |
|---|---|
| `web_fetch` | Read a page, fetched from your computer. Pages are cached for 15 minutes |
| `web_search` | Search the web: with your own Brave key if you set one, else through Aristra (fast search, free up to a daily limit, or Brave at $0.0075 a search; see [Usage and prices](/account/usage)). When Aristra's search cannot serve (the day's free searches used up, or the service down), the free public search of Exa, Parallel, Firecrawl or Keenable answers, with only the search words sent (those services may keep them); turn that off with `web.keylessFallback: false` in settings. Up to 200 searches per chat |
| `cloud_browser_*` | A browser Aristra runs in the cloud, for pages that need one |
| `browser_*` | Aristra Desktop's browser panel: navigate, read, find, click, type, scroll, select and manage tabs, with your consent per site |

## What a result looks like to the model

A tool result over 50,000 characters, or over the tool's own limit, is saved to a file the model can open, and the model sees a 2,000-character preview. Content from outside (pages, files, tool output) reaches the model marked as untrusted data, and values that look like secrets are masked.
