A project keeps one piece of work together: its chats, its files, its instructions and what Aristra learns about it. Chats you start in a project use the project's files, instructions and memory. Every account has projects: 3 on Free, 5 on Plus, 20 on Pro and 40 on Max. The Projects page shows how many you have left.

## Make a project

On the website, open **Projects** and choose **New project**. Say what you are working on, and add a description if you like. A new project is pinned to the sidebar. Projects are made on the website; Aristra Desktop and the terminal use the ones you have.

## A project's page

| | |
|---|---|
| **New chat** | A chat in the project |
| **Chats** | The project's chats |
| **Files** | Your [Files](/files), showing this project's |
| **Craft** | With a plan, the project's [Craft](/craft) docs |
| **Folders on your Macs** | The folders this project works in on each Mac, with the main one marked. A new chat in the project on that Mac starts in its main folder; the files stay on the Mac |
| **Pin** | Keep it in the sidebar, or take it out |

Beside the chats are the project's settings:

- **Instructions**: up to 4,000 characters that every chat in the project follows: who it is for, how to write, what to check.
- **API keys**: with a plan, keys for using the project from your own code.

The project's menu has **Edit details…** (its name, description and the repositories Aristra Desktop works in) and **Delete project…**.

## Projects in Aristra Desktop and the terminal

- In Aristra Desktop, signed in, a new chat offers a **Project** picker. A project chat runs in the cloud, with the project's instructions and memory, and on the Code tab it starts in the project's main folder when it has one on this Mac. The picker shows once you have a project.
- In Aristra Desktop's Code tab, choose a project and a folder for a new chat, then **Make it Launch's main folder** (for a project named Launch) under the message box.
- In the terminal, `aristra --cloud --project <name>` starts a cloud chat in a project. See [Cloud chats](/code/cloud-chats#projects).

## Memory in a project

What Aristra learns while you work in a project is kept in your memory with the project's name on it, and the **Pages** tab of [Memory](/memory) groups it by project.
