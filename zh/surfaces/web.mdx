[app.aristralabs.com](https://app.aristralabs.com)就是在任意浏览器中使用的Aristra，无论是在电脑上还是手机上。这里的对话由Aristra的云端智能体运行，并保存在你的账户中，所以它们与Aristra Desktop的Chat标签页和终端中的[云端对话](/zh/code/cloud-chats)是同一批对话。

## 侧边栏中有什么

| | 用途 | |
|---|---|---|
| **Chats** | 使用Aristra任意模型的[对话](/zh/chats)，从你的余额中扣费 | 所有账户 |
| **Projects** | [项目](/zh/projects)：一项工作的对话、文件、指令和记忆 | 所有账户 |
| **Files** | 你的账户保存的[文件](/zh/files) | 所有账户 |
| **Memory** | Aristra记住的关于你的内容。参见[记忆](/zh/memory) | 所有账户 |
| **Craft** | [Craft](/zh/craft)文档 | 需要套餐 |
| **Scheduled tasks** | 云端[定时任务](/zh/scheduled-tasks) | 需要套餐 |
| **Customize** | [Connectors](/zh/connectors)、Skills、Channels（[Telegram](/zh/surfaces/telegram)）和MCP | 需要套餐 |
| **Cloud computer** | 你的[云电脑](/zh/surfaces/cloud-computer) | 需要套餐或充值余额 |

没有套餐时，需要套餐的项目不会出现在侧边栏中；如果你从链接打开其中某个页面，页面会说明套餐会增加什么。套餐结束后，这些项目会保留，供你阅读和导出。余额用完时，消息框会提示你，并提供充值或开通套餐的选项。

## 你的账户

从侧边栏底部菜单中打开的**Settings**会打开你的账户页面：你的个人资料、个性化和记忆开关、账单、用量、设备、下载和导出。参见[你的账户与Aristra One](/zh/account/overview)。

## 你的电脑

在新对话下方，**Runs on Aristra Cloud**会列出你的云电脑以及登录了你账户的每台电脑。开通套餐后，选择其中一台可以：

- **关注并回复对话**，即你从Aristra Desktop或终端共享的对话，包括其中的审批。参见[Remote Control](/zh/code/remote-control)。
- **在电脑上开始对话**，在那台电脑允许的文件夹中进行。这项功能默认关闭，需要你在那台电脑上开启。参见[从网页版或手机在你的电脑上开始对话](/zh/code/remote-control)。

对话在那台电脑上运行，使用它的文件和工具，并使用Aristra的某个模型，费用先从你套餐的每月用量中扣除，然后从你的充值余额中扣除。

## 在手机上

在手机浏览器中打开app.aristralabs.com并登录。把它添加到主屏幕，就可以像应用一样打开它。上面提到的所有功能在手机上都能使用，包括为你电脑上的对话回复审批。

## 工作区

你的账户有一个个人工作区。邀请其他人需要团队工作区，目前还未推出。
