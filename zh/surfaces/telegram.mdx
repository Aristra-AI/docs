开通[套餐](/zh/account/plans)后，你可以通过Telegram给Aristra发消息。它是同一个Aristra，拥有你的记忆、你的文件和你连接的应用，它的回复和任何对话一样从你的余额中扣费。

## 连接Telegram

1. 在网站上打开**Customize › Channels**，在Telegram上选择**Connect**。
2. 选择**Open in Telegram**，或用手机扫描二维码，然后在Telegram中按**Start**。该链接只能使用一次，有效期5分钟。

同一张卡片上的**Disconnect**会让Aristra停止在那里回复。

## 你的Telegram对话

你与Aristra的Telegram私聊会延续你账户中的一个对话，名为**Aristra**。它不在网站的侧边栏中；**Chats**会列出它。发送`/new`可以开始一个单独的对话，它会显示在侧边栏中，并标记为来自Telegram；发送`/home`可以回去（`/home`用于你的私聊，不适用于群组）。Telegram群组会有它自己的对话。

Aristra可以读取你发送的语音消息。

| 命令 | |
|---|---|
| `/new` | 开始新对话 |
| `/home` | 回到你的主对话 |
| `/model` | 选择模型 |
| `/think` | 推理强度：off（快速），或low、medium、high |
| `/switch` | 为这个对话选择项目 |
| `/continue` | 继续一条因达到上限而暂停的回复 |
| `/settings` | 你的工作区和项目 |
| `/stop` | 停止正在进行的回复 |
| `/help` | 列出命令 |

## 发送到你的云电脑

有[云电脑](/zh/surfaces/cloud-computer)时，在它的页面上开启**Telegram messages go to this computer**。之后你的Telegram私聊就会在云电脑上运行，云电脑休眠时会被唤醒。发送`/new`可以在那里开始一个新对话。审批需要在网站上回复。

## 其他应用

WhatsApp、Slack和Discord在**Channels**下显示为即将推出。目前只有Telegram可用。
