Aristra是一个助手，只需一个账户。你可以在网页版或手机上、在Mac上的Aristra Desktop中、在终端里，或者通过Telegram与它交流。你在Aristra Cloud中的对话、Aristra对你的记忆以及你的文件，都会随你从一处带到另一处。

## Aristra能做什么

<CardGroup cols={2}>
  <Card title="回答、研究与写作" icon="magnifying-glass" href="/zh/chats">
    它会搜索网页、阅读页面，读取你的PDF、Word、Excel和PowerPoint文件，并与你一起写作。
  </Card>
  <Card title="替你完成工作" icon="chart-column" href="/zh/chats">
    它在自己的沙箱中运行代码来分析数据、生成文件（PDF、Word、Excel、PowerPoint、图表），还能生成图片。
  </Card>
  <Card title="记忆" icon="brain" href="/zh/memory">
    它会记住你告诉它的内容，每晚从你最近的对话中学习，并让你查看和修改其中的全部内容。
  </Card>
  <Card title="你的应用" icon="plug" href="/zh/connectors">
    开通套餐后，它可以在Gmail、Google Calendar、Google Drive、Slack、Notion、GitHub等应用中工作。
  </Card>
  <Card title="定时工作" icon="clock" href="/zh/scheduled-tasks">
    开通套餐后，它会在云端按设定的时间或在某件事发生时运行任务，即使你的电脑已经关机。
  </Card>
  <Card title="代码" icon="terminal" href="/zh/surfaces/aristra-code">
    Aristra Code在你的终端、Aristra Desktop和编辑器中，读取、编辑并运行你电脑上文件夹里的代码。
  </Card>
</CardGroup>

## 在哪里使用

你使用Aristra的每个地方都是一个使用端。各个使用端共用你的账户，所以Aristra Cloud中的对话在每个使用端都能看到。Aristra Code在你电脑上运行的对话会留在那台电脑上，除非你用Remote Control把它共享出去。

| 使用端 | 是什么 |
|---|---|
| [网页版和手机](/zh/surfaces/web) | [app.aristralabs.com](https://app.aristralabs.com)，可在任意浏览器和手机上使用。你的账户页面也在这里 |
| [Aristra Desktop](/zh/surfaces/desktop) | Mac应用：**Chat**标签页用于对话，**Code**标签页用于Aristra Code |
| [Aristra Code](/zh/surfaces/aristra-code) | 在你电脑上的文件夹中工作的Aristra：终端里的`aristra`命令、Aristra Desktop的Code标签页以及你的编辑器 |
| [Telegram](/zh/surfaces/telegram) | 开通套餐后，通过Telegram给Aristra发消息 |
| [云电脑](/zh/surfaces/cloud-computer) | 一台属于你自己、位于Aristra云端的Linux电脑，你自己的电脑关机时Aristra也能在上面工作。它需要套餐或你充值的金额；初始额度不能用于支付它 |

## 费用

每个账户都可以免费创建，并自带$1额度，用于Aristra的模型和工具。网页版上的对话按使用量从你的余额中扣费，每个账户都包含记忆功能和1 GB的文件存储空间。搭配你自己的模型时，Aristra Desktop和Aristra CLI可以免费使用：你自己的服务商密钥、你的ChatGPT套餐，或者你电脑上的模型都可以。参见[使用你自己的模型](/zh/own-models)。

套餐（Plus每月$20、Pro每月$100或Max每月$200）每月提供与价格等额的Aristra模型用量，此外还包括Craft、连接器、云端定时任务、Telegram，以及从网页版使用你的电脑。参见[你的账户与Aristra One](/zh/account/overview)和[套餐与定价](/zh/account/plans)。
