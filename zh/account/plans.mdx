## 你的用量用于支付什么

你套餐的每月用量，以及之后的[充值余额](/zh/account/credits)，用于支付：

- **Aristra的模型**：按每次调用使用的token计费，采用服务商自己的价格。每个模型的价格见[Models and prices](https://app.aristralabs.com/models)。
- **托管工具**：Brave搜索、网页读取、代码沙箱和云端浏览器、图片、转录和文档读取。参见[用量与价格](/zh/account/usage)。
- **云电脑**：它唤醒的时间，以及它的磁盘（无论唤醒还是休眠）。参见[云电脑](/zh/surfaces/cloud-computer)。

使用你自己的模型（你的密钥、你的ChatGPT套餐、你电脑上的模型）时，Aristra不收取任何费用。

<AccordionGroup>
  <Accordion title="我的用量何时重置？">
    每月在你的账单日重置。剩余的用量不会结转。你的充值余额是独立的：每笔充值有效期12个月，在当月用量用完后使用。
  </Accordion>
  <Accordion title="余额为零时会怎样？">
    Aristra会在下一个付费步骤之前停止，并告诉你。已经在运行的调用会完成并全额收费，所以你的余额可能会降到零以下几美分；你的下一笔扣款、充值或下个月的用量会先补上这部分。你可以[充值](/zh/account/credits)（$10起），用`/model`把对话切换到你自己的模型，或者等待重置。有套餐时，云电脑会进入休眠并保留磁盘。没有套餐时，充值余额用完后它会被停止，磁盘保留30天；在此期间充值即可让它恢复。
  </Accordion>
  <Accordion title="更换套餐时会怎样？">
    升级会立即生效，你会获得两个套餐每月用量的差额，按当前账单周期剩余时间的比例计算。降级会在账单周期结束时生效。届时，超出新套餐允许规格的云电脑会降为该套餐的最大规格；它的磁盘保持不变。
  </Accordion>
  <Accordion title="为什么Billing显示所有套餐都已满？">
    在Aristra One刚推出期间，套餐分批开放。一批名额满了之后，Billing会在你付款之前告诉你，不会收取任何费用。你的账户会照常运作，更多套餐很快就会开放。
  </Accordion>
  <Accordion title="我使用每月用量的速度有限制吗？">
    没有。它是一个总额，没有每日或每周限制。
  </Accordion>
</AccordionGroup>

## 订阅后

你的电脑会在几分钟内跟随账户的套餐。套餐开始的当天：

- **Aristra Desktop会询问一次**，是否把这台Mac上的对话共享到你的手机和网页版，以及是否允许云端对话读取这里的某个文件夹。每一项都是可选的。之后，同样的选项也可以在对话菜单（**Continue on phone and web**）和文件夹菜单（**Use from other devices**）中找到。
- **在终端中**，`/remote-control`会共享你当前所在的对话。

## 套餐结束后

你的账户会保留为Free账户，你创建的任何内容都不会被删除。

| | 会发生什么 |
|---|---|
| 对话 | 全部保留。网页版上的新对话从你的余额中扣费 |
| Craft | 全部保留，你可以继续写作，和每个账户一样 |
| 文件 | 全部保留，可以打开和下载。如果超过Free账户的1 GB，在你删除一些文件之前，新文件会被拒绝；系统不会替你删除任何文件 |
| 账户记忆 | 在每台设备上仍然属于你，Aristra也会继续学习，就像对每个账户一样 |
| 云电脑 | 继续使用你的充值余额运行，最高为Large（4 GB）；更大的规格会降为Large。余额用完后会被停止：磁盘保留30天，删除前一周你会收到一封邮件 |
| 公开的站点和应用 | 几分钟内变为私有：只有你能打开。分享名单和名字都会保留；续订后，在**Apps**中重新公开 |
| 云端定时任务和渠道 | 暂停。续订后会重新开始 |
| Remote Control和你的电脑 | 已共享的对话仍可阅读。从网页版关注、回复对话以及在你的电脑上开始对话的功能会停止，直到你续订 |
| 连接器 | 仍会列出。在你续订之前，你无法连接或修改它们 |
| 项目API密钥 | 停止工作，直到你续订 |
| 充值余额 | 仍然属于你。它可用于支付网页版上的对话，以及你电脑上使用的Aristra模型和工具 |
| Aristra Desktop和Aristra CLI | 继续搭配你自己的模型使用 |

在**Billing**上续订，即可恢复之前的一切。
