一个Aristra账户可以在任何地方使用。在你自己的电脑上使用Aristra是免费的。套餐会增加Aristra为你托管的内容。

## Aristra的组成部分

| 名称 | 是什么 |
|---|---|
| **Aristra One** | 你账户的套餐：Free、Plus、Pro或Max。它在网站上的页面会显示你的套餐、余额、用量和设备 |
| **网站** | [app.aristralabs.com](https://app.aristralabs.com)：在任意浏览器或手机上使用你的对话（从你的余额中扣费，或使用套餐），你的文件和记忆，开通套餐后还有Craft。参见[网页版和手机](/zh/surfaces/web) |
| **Aristra Desktop** | Mac应用：对话，以及Code标签页 |
| **Aristra CLI** | 终端中的`aristra`命令，适用于Mac或Linux机器 |
| **Aristra Code** | 编程智能体。你可以在Aristra Desktop的Code标签页、Aristra CLI、你的编辑器以及云电脑上使用它 |
| **Aristra Cloud** | Aristra托管的一切：Aristra的模型、云端智能体、云电脑、账户记忆（每个账户都有）、存储空间、连接器和云端定时任务 |

## 哪些是免费的

- **Aristra Desktop和Aristra CLI**，登录你的账户并搭配你自己的模型：你自己的服务商密钥、你的ChatGPT套餐，或在你电脑上运行的模型。参见[模型](/zh/code/configure/models)。
- 在你自己的文件夹中使用**Aristra Code**，以及在你电脑上运行的每一个工具。
- **你账户的记忆**，在每台设备上都可用：Aristra记住的关于你的内容，在你对话时保存，并每晚从你最近的对话中学习。保存、导入和搜索记忆都不收费。参见[记忆](/zh/memory)。
- Aristra Desktop和网页版中的**文件**，以及终端中的`/files`：你的对话生成、共享或收到的文件。在你的电脑上读取PDF、Word、Excel和PowerPoint文件。在云端，读取一页扫描页的费用为$0.006（使用视觉识别为$0.015）。
- **保存在你Mac上的Craft文档**，在Aristra Desktop中使用。有套餐时，它们可以移到你的账户中。
- **网页版和手机上对话中的网页搜索**。在你的电脑上，每次搜索从你的余额中扣除$0.0075；余额用完后，会改用免费的公共搜索（Exa、Parallel、Firecrawl或Keenable）来回答，除非你把它关闭。
- **$1初始额度**，在你创建账户时一次性发放。它可用于支付Aristra的模型和托管工具，让你在充值之前就能在网页版和手机上对话。
- 网站上的账户页面：Overview、Profile、Personalization、Billing、Usage、Devices、Downloads、Import and export、Permissions、Agent payments和Cloud computer。

没有套餐时，你也可以[为余额充值](/zh/account/credits)。充值可用于支付网页版和手机上的对话、你电脑上使用的Aristra模型和托管工具，以及云电脑。

## 套餐会增加什么

| | 免费账户 | 有套餐 |
|---|---|---|
| 在网页版和手机上 | 对话、项目和文件，从你的余额中扣费 | 全部功能：对话、项目、文件、Craft |
| Aristra的模型 | 所有模型，从你的余额中扣费 | 所有模型，从你的每月用量中扣费 |
| Remote Control和共享对话 | 否 | 是 |
| 云端对话 | 是，从你的余额中扣费 | 是 |
| 连接器、云端定时任务、渠道 | 否 | 是 |
| 云电脑 | 最高Large，用充值支付 | 是，最高为你套餐的规格 |
| 文件存储空间 | 1 GB | 10 GB起 |
| 账户中的Craft文档 | 否 | 是 |

各个套餐、它们的价格和限额见[套餐与定价](/zh/account/plans)。

## 你的账户页面

你账户的所有设置都在这些页面上。从侧边栏底部的菜单中打开**Settings**，或前往`app.aristralabs.com/account`。项目自己的设置（它的指令，以及有套餐时的API密钥）在项目的页面上。

| 页面 | 内容 |
|---|---|
| **Overview** | 你的账户有哪些内容，以及前往每个部分的入口 |
| **Profile** | 你的名字、邮箱和账户ID，以及删除账户 |
| **Personalization** | 主题和字体、Aristra自主行动的积极程度、记忆、你的时区和位置 |
| **Billing** | 以美元计的余额、充值、各个套餐及其对比、你在Stripe上的银行卡和发票 |
| **Usage** | 你的钱花在了哪里（按模型和按工具）、工具价格，以及Aristra使用的搜索 |
| **Devices** | 登录你账户的每台电脑，以及让其中一台退出登录 |
| **Downloads** | Aristra Desktop和Aristra CLI |
| **Import and export** | 以单个文件导出的账户数据，以及Aristra可以从中导入的来源 |
| **Permissions** | 云端的Aristra在询问你之前可以做什么，以及它的云端浏览器保持登录的网站 |
| **Agent payments** | 当你让Aristra购买东西时，它可以用来付款的钱包 |
| **Connectors** | 需要套餐：连接到你账户的应用。它会打开**Customize › Connectors** |
| **Cloud computer** | 你自己在Aristra Cloud中的机器，可以用套餐，也可以用充值：创建它、与它对话，以及它的设置 |
| **Scheduled tasks** | 需要套餐：Aristra在云端按计划运行的任务（网站侧边栏中的**Scheduled tasks**）。在你自己的电脑上它们是免费的 |
| **Storage** | 需要套餐：你的文件占用了账户多少空间 |
| **Workspace** | 你的工作区的名称和图标、成员以及审计日志。邀请其他人需要团队工作区，目前还未推出 |

无论是否有账户，任何人都可以查看[Models and prices](https://app.aristralabs.com/models)。
