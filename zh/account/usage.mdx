**Usage**页面（`app.aristralabs.com/account/usage`）显示你的钱花在了哪里。在Aristra CLI中，`/usage`会显示你的余额和当前对话的用量；Aristra Desktop中则有**Settings › Usage**。

## 页面显示什么

| | |
|---|---|
| **Spent** | 所选时间段（7、30或90天）的总额，以及其中有多少来自每月用量、充值余额和初始额度 |
| **Spending over time** | 每天一列，分为模型、工具和云电脑。将指针指向某一天可以查看它的数字，或打开**Show as a table** |
| **By model** | 每个模型：请求数、输入token、从缓存读取和写入缓存的token、输出token，以及费用 |
| **Tools and cloud** | 每个托管工具和你的云电脑：使用了多少，以及费用。免费的搜索会显示Free |
| **Recent tool calls** | 最近的调用，以及每次调用的费用 |
| **Download CSV** | 该时间段的每一行用量记录，附有以美元计的精确费用 |

总额四舍五入到分。单笔不足一分的费用在总额中显示为`<$0.01`，在它自己那一行中显示到小数点后四位（$0.0053），所以任何让你花了钱的项目都不会显示为$0.00。

## 模型价格

每个模型都按其服务商自己的价格收费：Aristra不加任何费用。每个模型每百万输入和输出token的价格见[Models and prices](https://app.aristralabs.com/models)。从缓存读取的输入费用更低。有些模型在提示词非常长时收费更高，但只针对那一次调用；页面会说明从多少token开始。

## 工具价格

| 工具 | 价格 |
|---|---|
| 网页搜索（Brave；也包括新闻、图片和视频搜索） | 在网页版和手机上的对话中不收费；从Aristra Desktop、CLI或云电脑搜索，每次$0.0075 |
| 沙箱中的shell命令，以及云端浏览器 | 每分钟$0.003。用Aristra的代码工具运行代码免费 |
| 网页读取 | 每页$0.01 |
| 图片生成 | 图片模型自身价格的1.5倍 |
| 转录 | 每分钟音频$0.001 |
| 文档页面读取 | 每页$0.006，使用视觉识别为$0.015 |
| 云电脑 | 唤醒期间每小时$0.0122到$0.0881，按规格而定 |
| 云电脑磁盘 | 每GB每月$0.18，无论唤醒还是休眠 |
| 连接器调用 | 暂不收费 |

实时价目表在Usage页面上。在你自己电脑上运行的工具（文件、shell、git、你的MCP服务器）不收费，你的记忆也不收费：保存、导入和搜索记忆，以及Aristra从你的对话中学习，都不收费。使用记忆的对话只需为它自己的token付费。失败的搜索或网页读取不收费；沙箱命令按运行时间收费，即使它失败了也一样。

## Aristra使用的搜索

Aristra使用Brave搜索网页。在网页版或手机上的对话中搜索不收费；从Aristra Desktop、CLI或云电脑搜索每次$0.0075，从你的余额中扣除。当那里的余额用完时，搜索会改用Exa、Parallel、Firecrawl或Keenable的免费公共搜索，只发送搜索词，除非你关闭这一功能（`web.keylessFallback`）。

在你自己的电脑上，你还可以设置**你自己的Brave密钥**（Aristra Desktop：**Settings › Tools & keys**）。设置后，总是优先使用你的密钥，Aristra不收取费用。如果无法读取该密钥，Aristra会告诉你：它不会悄悄切换到从你余额中扣费的搜索。在设置中删除该密钥，即可恢复使用Aristra的搜索。
