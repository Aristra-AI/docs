本指南带你从没有账户开始，到完成第一个对话，再到在Mac和手机上使用Aristra。[登录](/zh/quickstart)部分列出了每种登录方式的步骤。如果你想先在终端里写代码，请参见[Aristra Code快速入门](/zh/code/quickstart)。

<Steps>
  <Step title="创建账户">
    前往[app.aristralabs.com](https://app.aristralabs.com)，选择**Sign up**。

    - **在Aristra分批开放期间**，页面会显示**Join the waitlist**（如果名额已满，则显示**We are full for now**）。输入你的邮箱，然后选择**Join waitlist**。名额准备好后，Aristra会给你发邮件；在此之前你无需做任何事。
    - **通过邀请链接**，打开邀请邮件中的链接。它会直接带你进入表单，表单会使用邀请中的邮箱。
    - **注册开放后**，页面会显示**Create your account**。

    在**Create your account**页面上，输入你的姓名（可选）、邮箱、至少8个字符的密码，再输入一次密码。选择**Create account**。然后输入Aristra发送到你邮箱的验证码（使用邀请链接时会跳过这一步），再次选择**Create account**。**Send a new code**会重新发送一个验证码。

    新账户免费，并自带$1额度，用于Aristra的模型和工具，每个邮箱地址只有一次。
  </Step>

  <Step title="向Aristra介绍你自己">
    接下来是几个简短的页面：欢迎页、你来这里的目的（写作、研究、安排日常事务或构建工作流）、你的名字和你的空间，以及一个关于记忆的可选步骤。你的名字和**About you**备注之后可以在账户的**Profile**页面上修改。如果想改变Aristra与你交流的方式，在对话中告诉它就行。
  </Step>

  <Step title="开始对话">
    新对话页面会在消息框上方显示**Runs on Aristra Cloud**，还有几个可以作为开头的提示词，消息框下方则显示你还有多少钱可以花。输入你想要的内容，然后按Enter。

    - **选择模型**：在选择器中选择。**Auto**是不错的默认选项；每个账户都可以使用所有模型，每个模型都会标明它的费用高低。
    - **附加文件**：使用<strong>+</strong>附加PDF、Word、Excel和PowerPoint文件、图片、文本和代码，每条消息最多5个文件、50 MB。
    - **每条消息都会从你的余额中扣费**：先用初始额度，然后是套餐的每月用量或你的充值。参见[你的余额与充值](/zh/account/credits)。

    Aristra会搜索网页、读取你的文件、运行代码来生成文件和图表，并记住重要的事情。参见[对话](/zh/chats)。
  </Step>

  <Step title="在Mac上使用Aristra">
    打开你账户的**Downloads**页面，选择**Download for Mac**（支持Apple芯片和Intel）。打开Aristra Desktop并选择**Sign in**；具体步骤见[登录](/zh/quickstart)中的**Aristra Desktop**标签页。

    这个应用有两个标签页。**Chat**中的对话与网站上的相同。**Code**是Aristra Code，用于在Mac上的文件夹中工作。参见[Aristra Desktop](/zh/surfaces/desktop)。

    在Mac上，Aristra也可以使用你的ChatGPT套餐、你自己的API密钥，或者你电脑上的模型（例如Ollama）来运行。参见[使用你自己的模型](/zh/own-models)。
  </Step>

  <Step title="在手机上使用">
    在手机浏览器中打开app.aristralabs.com并登录。把它添加到主屏幕，就可以像应用一样打开它。
  </Step>
</Steps>

## 登录

你的Aristra账户在哪里都是同一个。网站和手机用你的邮箱登录。Aristra Desktop、终端和编辑器登录的是**一台电脑**：你先在这台电脑上发起登录，然后在网站上批准它，可以在你的浏览器中批准，也可以在任何已登录的手机或电脑上批准。

同一台电脑上的Aristra Desktop、终端和编辑器共用一次登录。在这台电脑上登录一次，它们就全都登录了。

<Tabs>
  <Tab title="网站">
    **使用密码**

    1. 前往[app.aristralabs.com](https://app.aristralabs.com)。页面会显示**Welcome back**。
    2. 输入你的**Email**和**Password**。
    3. 选择**Sign in**。

    **使用发送到邮箱的验证码**

    1. 在**Welcome back**页面上输入你的**Email**，密码留空。
    2. 在**Or continue with**下方，选择**Email me a sign-in code**。
    3. 在**Check your email**页面上，输入邮件中的**Code**，然后选择**Continue**。

    **如果你忘记了密码**

    1. 在**Welcome back**页面上，选择**Forgot your password?**
    2. 输入你的**Email**，然后选择**Send reset code**。
    3. 输入邮件中的**Code**和一个**New password**，然后选择**Reset password**。这样也会让你登录。

    在新的浏览器上登录时，输入密码后可能还会要求你输入邮件中的验证码，同样是在**Check your email**页面上。
  </Tab>

  <Tab title="Aristra Desktop">
    在你登录之前，Aristra Desktop会停留在**Sign in to Aristra**页面。如果你还没有账户，**Create an account**会在浏览器中打开注册页面。

    **在浏览器中**

    1. 选择**Sign in**。浏览器会打开Aristra的**Authorize Aristra Desktop**页面。如果你在那个浏览器中还没有登录网站，请先登录；之后会回到这个页面。
    2. 检查**Computer**和**Account**两行：它们写明了这台Mac以及它将加入的账户。
    3. 选择**Approve**。页面会显示**Computer connected**，应用会自动继续。你可以关闭这个标签页。

    如果页面没有打开，在应用中选择**Open the page again**。

    **使用验证码，在另一台设备上**

    当这台Mac的浏览器无法完成登录，或者你更想在手机上批准时，使用这种方式。

    1. 选择**Sign in**，然后选择**Use a code instead**。应用会显示一个八个字母的验证码，例如`BCDF-GHJK`，旁边有**Copy**。
    2. 在任意手机或电脑上，前往**app.aristralabs.com/desktop/device**，如果要求登录就先登录。应用中的**Open the page**会在这台Mac上打开该页面，并自动填入验证码。
    3. 输入验证码并选择**Continue**。
    4. 确认验证码和**Computer**与这台Mac一致，然后选择**Approve**。应用会自动继续。

    验证码在10分钟内有效。过期后，再次选择**Sign in**获取新的验证码。
  </Tab>

  <Tab title="终端">
    先安装Aristra Code：参见[Aristra Code快速入门](/zh/code/quickstart)。在未登录状态下第一次运行`aristra`时，它会要求你登录。你也可以随时登录：

    ```sh
    aristra login
    ```

    **在浏览器中**

    1. 选择**In your browser**（在有浏览器的电脑上是第一个选项），或运行`aristra login`。
    2. 浏览器会打开Aristra的**Authorize Aristra Code**页面。如果没有打开，请打开终端打印出的链接。
    3. 检查**Computer**和**Account**两行，然后选择**Approve**。
    4. 终端会显示**Signed in as**和你的邮箱。

    **使用验证码，在另一台设备上**

    1. 选择**With a code, on another device**，或运行`aristra login --device-code`。在等待浏览器登录时，你也可以按**c**切换为验证码。
    2. 终端会显示：Go to https://app.aristralabs.com/desktop/device and enter the code `BCDF-GHJK`（你的验证码会不同）。
    3. 在任意手机或电脑上打开该页面，如果要求登录就先登录，输入验证码并选择**Continue**。
    4. 确认验证码和**Computer**一致，然后选择**Approve**。

    **通过SSH，或在另一台机器上**

    通过SSH连接，或在没有图形界面的Linux上，会先提供验证码方式，因为那台电脑上没有浏览器。使用`aristra --remote <host>`时，另一台机器会作为它自己的电脑登录：在那台机器上用验证码登录，方法是选择**With a code, on another device**或输入`/login code`（`aristra --remote <host> login`总是使用验证码）。

    **在对话中**

    `/login`用于登录，`/login code`用于通过验证码登录，`/logout`用于退出登录。`aristra status`会显示这台电脑登录的是哪个账户。

    **脚本和CI**

    `aristra setup-token`会打印一个有效期为一年的令牌。在脚本运行的地方把它设置为`ARISTRA_TOKEN`。它会作为单独的一项显示在你的设备中，你也在那里撤销它。
  </Tab>

  <Tab title="编辑器">
    Zed以及其他支持Agent Client Protocol的编辑器，通过`aristra acp`运行Aristra Code。先把它添加到你的编辑器中：参见[编辑器](/zh/code/editors)。

    1. 在编辑器的智能体面板中开始一个Aristra对话。如果这台电脑还没有登录，编辑器会要求你登录。
    2. 选择**Sign in to Aristra**。浏览器会打开**Authorize Aristra**页面。
    3. 检查**Computer**和**Account**两行，然后选择**Approve**。编辑器会继续。

    登录会等待5分钟。如果这台电脑上的Aristra Desktop或终端已经登录，编辑器也就已经登录了，无需任何操作。
  </Tab>

  <Tab title="手机">
    1. 在手机浏览器中打开[app.aristralabs.com](https://app.aristralabs.com)。
    2. 和在网站上一样登录，使用密码或发送到邮箱的验证码。
    3. 可选：把页面添加到主屏幕，就可以像应用一样打开Aristra。

    手机也很适合用来批准电脑：打开**app.aristralabs.com/desktop/device**，输入电脑上显示的验证码。
  </Tab>
</Tabs>

### 批准一台电脑

批准页面会列出**Application**（**Aristra Desktop**、**Aristra Code in a terminal**，编辑器则只显示**Aristra**）、**Computer**以及它要加入的**Account**。电脑会加入网站当前登录的那个账户，所以在选择**Approve**之前，请检查**Account**这一行。

只批准你自己刚刚发起的登录。Aristra绝不会要求你批准某个验证码。**Deny**不会连接任何东西，那台电脑上的登录会自行过期。

已登录的电脑在你使用期间会一直保持登录。30天未使用的电脑会要求你重新登录。一个账户最多可以同时登录20台电脑和脚本令牌。登录已失效的不再计入。

### 退出登录

| 要退出的对象 | 操作 |
|---|---|
| 网站（在这个浏览器中） | 选择侧边栏底部你的名字，然后选择**Log out**。你的电脑仍保持登录 |
| 这台Mac | 在Aristra Desktop中打开账户菜单（左下角你的名字），选择**Sign out**。正在运行的对话会停止，包括这里和终端中的对话 |
| 这台电脑（在终端中） | 先停止正在运行的对话，然后运行`aristra logout`，或在对话中输入`/logout`。这台电脑上的Aristra Desktop也会退出登录 |
| 另一台电脑 | 在网站上打开**Settings › Devices**，选择它旁边的**Sign out**。它的对话和文件仍保留在它上面。你的云电脑则是在**Manage**中停止或删除 |
| 所有电脑 | 在Aristra Desktop中选择**Settings › Account › Sign out all**。每台电脑和脚本令牌都会退出登录，包括这台Mac。你的云电脑和网页会话保持不变 |
| 你的ChatGPT套餐 | 在终端中运行`aristra logout chatgpt`（或在对话中输入`/logout chatgpt`），或者在Aristra Desktop的**Settings › Models**中，在**ChatGPT plan**上选择**Sign out**。Aristra仍保持登录 |

退出Aristra登录后，那台电脑上的ChatGPT登录和API密钥仍会保留。同一个账户重新登录后，电脑上的对话会再次显示。

### 如果无法登录

<AccordionGroup>
  <Accordion title="The sign-in expired">
    浏览器登录的有效期为5分钟，验证码为10分钟。在电脑上重新发起登录（在Aristra Desktop中选择**Sign in**，在终端中运行`aristra login`），获取新的页面或验证码。
  </Accordion>
  <Accordion title="验证码不被接受">
    逐个检查每个字母。验证码只使用辅音字母，所以不会出现与0或1混淆的O或I，输入时带不带连字符都可以。如果10分钟内检查了10次验证码（每次**Continue**和**Approve**都算一次），请等几分钟，然后重新发起登录。
  </Accordion>
  <Accordion title="浏览器页面始终没有连到电脑">
    浏览器可能在另一台设备上，或者无法访问这台电脑。改用验证码：在Aristra Desktop中选择**Use a code instead**，在终端等待时按**c**，或在对话中输入`/login code`。
  </Accordion>
  <Accordion title="Revoke an existing device before connecting another">
    你的账户已经登录了20台电脑和脚本令牌。在网站的**Settings › Devices**中，退出你不再使用的那些，然后重新登录。
  </Accordion>
  <Accordion title="Your account is on the waitlist">
    Aristra会逐步放人进来。名额准备好后（Aristra会给你发邮件），在电脑上重新发起登录。
  </Accordion>
  <Accordion title="Sign out of the current Aristra account before signing in to another">
    一台电脑一次只能登录一个Aristra账户。先在这台电脑上退出登录，再用另一个账户登录。如果要用另一个账户批准，先在那个浏览器中退出网站。
  </Accordion>
</AccordionGroup>
