---
title: "项目"
description: "把一项工作的对话、文件、指令和记忆放在一起，并在你的每台Mac上为它设置一个主文件夹。"
---

项目把一项工作集中在一起：它的对话、它的文件、它的指令，以及Aristra了解到的关于它的内容。你在项目中开始的对话会使用项目的文件、指令和记忆。每个账户都有项目：Free为3个，Plus为5个，Pro为20个，Max为40个。Projects页面会显示你还能创建多少个。

## 创建项目

在网站上打开**Projects**，选择**New project**。说明你正在做的事情，如果愿意，还可以添加描述。新项目会固定在侧边栏中。项目在网站上创建；Aristra Desktop和终端使用你已有的项目。

## 项目页面

| | |
|---|---|
| **New chat** | 在项目中新建对话 |
| **Chats** | 项目的对话 |
| **Files** | 你的[Files](/zh/files)，显示这个项目的文件 |
| **Craft** | 项目的[Craft](/zh/craft)文档 |
| **Folders on your Macs** | 这个项目在每台Mac上工作的文件夹，主文件夹会有标记。在那台Mac上新建的项目对话会从它的主文件夹开始；文件保留在Mac上 |
| **Pin** | 把它保留在侧边栏中，或者移出 |

对话旁边是项目的设置：

- **Instructions**：最多4,000个字符，项目中的每个对话都会遵循：它为谁服务、怎样写、要检查什么。
- **API keys**：开通套餐后，用于从你自己的代码中使用这个项目的密钥。

项目菜单中有**Edit details…**（它的名称、描述以及Aristra Desktop在其中工作的仓库）和**Delete project…**。

## Aristra Desktop和终端中的项目

- 在Aristra Desktop中登录后，新对话会提供一个**Project**选择器。项目对话在云端运行，使用项目的指令和记忆；在Code标签页中，如果项目在这台Mac上有主文件夹，它会从主文件夹开始。只要你有项目，就会显示这个选择器。
- 在Aristra Desktop的Code标签页中，为新对话选择一个项目和一个文件夹，然后选择消息框下方的**Make it Launch's main folder**（以名为Launch的项目为例）。
- 在终端中，`aristra --cloud --project <name>`会在项目中开始一个云端对话。参见[云端对话](/zh/code/cloud-chats)。

## 项目中的记忆

你在项目中工作时Aristra学到的内容会保存在你的记忆中，并标上项目名称；[记忆](/zh/memory)的**Pages**标签页会按项目对它们分组。
