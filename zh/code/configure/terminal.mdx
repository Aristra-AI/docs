## 换行

Shift+Enter在Ghostty、kitty和WezTerm中开箱即可换行。在其他终端中，请运行：

```text
/terminal-setup
```

它会在VS Code、Cursor或Windsurf中添加Shift+Enter绑定（会先备份它们的按键绑定），或者在Apple的终端应用中开启“Use Option as Meta key”，这样Option+Enter就可以换行。Alt+Enter、Ctrl+J以及`\`后按Enter在任何地方都可以使用。

## 按键绑定

`~/.aristra/keybindings.json`可以修改Aristra Code的按键，格式与Claude Code的文件相同。`/keybindings`会创建包含所有绑定的文件并打开它；保存后稍等片刻，改动就会生效。

```json ~/.aristra/keybindings.json
{
  "bindings": [
    { "context": "Chat", "bindings": { "meta+s": "chat:stash", "ctrl+s": null } },
    { "context": "Global", "bindings": { "ctrl+f": "history:search" } }
  ]
}
```

按键的写法是在字母或`enter`、`escape`、`tab`、`up`、`pageup`等名称前加上`ctrl+`、`shift+`和`meta+`（或`alt+`、`option+`）。中间用空格分隔的两个按键是一个组合序列。把某个按键绑定为`null`会关闭它。Ctrl+C、Ctrl+D、Ctrl+M、Ctrl+[、Ctrl+I和Ctrl+H不能重新绑定（对终端来说，后四个分别是Enter、Esc、Tab和Backspace）。

| 上下文 | 何时 | 操作（默认按键） |
|---|---|---|
| `Global` | 始终 | `app:interrupt`（Ctrl+C）、`app:exit`（Ctrl+D）、`app:redraw`（Ctrl+L）、`app:toggleTodos`（Ctrl+T）、`app:toggleTranscript`（Ctrl+O）、`history:search`（Ctrl+R）、`abovePrompt:focus`（Ctrl+X Tab）、`app:diffFileListUp`（Ctrl+Up、Alt+Up）、`app:diffFileListDown`（Ctrl+Down、Alt+Down） |
| `Chat` | 输入框 | `chat:cancel`（Esc）、`chat:cycleMode`（Shift+Tab）、`chat:modelPicker`（Alt+P）、`chat:submit`（Enter）、`history:previous`（Up）、`history:next`（Down）、`chat:externalEditor`（Ctrl+G、Ctrl+X Ctrl+E）、`chat:stash`（Ctrl+S）、`chat:imagePaste`（Ctrl+V） |
| `HistorySearch` | Ctrl+R的搜索 | `historySearch:next`（Ctrl+R）、`historySearch:accept`（Esc、Tab）、`historySearch:execute`（Enter）、`historySearch:cancel`（Ctrl+C，固定） |
| `Task` | 有命令正在运行 | `task:background`（Ctrl+B） |
| `Confirmation` | 审批 | `confirm:yes`（Enter）、`confirm:no`（Esc）、`confirm:previous`（Up）、`confirm:next`（Down）、`confirm:nextField`（Tab）、`confirm:cycleMode`（Shift+Tab）、`confirm:toggleExplanation`（Ctrl+E） |
| `Scroll` | 全屏模式的对话记录 | `scroll:pageUp`（PgUp）、`scroll:pageDown`（PgDn）、`scroll:top`（Ctrl+Home）、`scroll:bottom`（Ctrl+End） |
| `DiffPanel` | 全屏模式的diff面板 | `app:cycleDiffBase`（Ctrl+X B） |
| `Pane` | diff面板获得按键时 | `pane:grow`（Ctrl+X Left、Ctrl+X Up）、`pane:shrink`（Ctrl+X Right、Ctrl+X Down）、`pane:close`（Ctrl+X X） |

行编辑按键（Ctrl+A、Ctrl+E、Ctrl+K、Ctrl+U、Ctrl+W、Ctrl+Y）遵循readline，不在该文件中。

## 你自己的状态行

`statusLine`会运行一条命令，并在输入框下方显示它的输出：

```json ~/.aristra/settings.json
{
  "statusLine": { "type": "command", "command": "~/bin/status.sh", "padding": 1, "refreshInterval": 10 }
}
```

该命令通过stdin以JSON形式读取对话（`session_id`、`cwd`、`permission_mode`、`session_name`、`model`、`workspace`、`version`、`context_window`、`effort`等），在对话发生变化时以及每隔`refreshInterval`秒重新运行，并有5秒时间作答。它的颜色会被保留。

`subagentStatusLine`（`{"type": "command", "command": …}`）对`/tasks`中的智能体行做同样的事。它读取同样的JSON，外加`columns`和`tasks`，并为每一行打印一行`{"id", "content"}`；`""`会隐藏某一行。

## 全屏

```text
/tui fullscreen      # saved in your settings
/tui default         # back to the classic renderer
```

`aristra --fullscreen`只在一次启动中使用它。全屏模式会占满整个屏幕，提供可滚动的对话记录、鼠标选择、对话记录界面（Ctrl+O）和diff面板（`/diff`）。参见[终端](/zh/code/terminal)。

## 显示设置

| 设置 | 默认值 | 作用 |
|---|---|---|
| `tui` | `"default"` | 设为`"fullscreen"`使用全屏渲染器 |
| `copyOnSelect` | `true` | 在全屏模式下，松开鼠标时复制所选内容 |
| `promptSuggestionEnabled` | `true` | 在回复之后建议你的下一条消息 |
| `awaySummaryEnabled` | `true` | 在你回到的对话中留下回顾 |
| `spinnerTipsEnabled` | `true` | 在Aristra Code工作时显示提示 |
| `prStatusFooterEnabled` | `true` | 在页脚中显示当前分支的拉取请求 |
| `terminalProgressBarEnabled` | `true` | 在某一步运行时，在终端的标签页中显示进度条（适用于Ghostty 1.2及更高版本、iTerm2 3.6.6及更高版本以及ConEmu） |
| `permissionExplainerEnabled` | `true` | 在命令的审批上按Ctrl+E解释该命令（只从你自己的`~/.aristra/settings.json`中读取） |
| `copyFullResponse` | `false` | `/copy`直接复制整条回复，而不询问要复制哪个代码块 |
| `prUrlTemplate` | 无 | 页脚中拉取请求链接打开的位置，可使用`{host}`、`{owner}`、`{repo}`、`{number}`和`{url}` |

终端相关的环境变量（`ARISTRA_NO_NOTIFY`、`ARISTRA_DISABLE_MOUSE`、`ARISTRA_SCROLL_SPEED`等）列在[环境变量](/zh/code/reference/environment)中。
