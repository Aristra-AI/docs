## 你的Aristra文件夹

Aristra Code保存的所有内容都在一个文件夹中：`~/.aristra`（或`ARISTRA_HOME`），由终端、Aristra Desktop和其他每个使用端共用。

```text
~/.aristra/
  settings.json                your settings
  AGENTS.md, rules/*.md        your instructions for every project
  keybindings.json             your terminal keys
  runtime.sqlite               every chat on this computer
  logs/runtime.log             the runtime's log, kept 7 days
  attachments/<chat>/          a chat's files: attachments, long outputs, checkpoints, cloud downloads
  exports/                     chats saved with /export
  diagnostics/                 support bundles
  credentials.enc              secrets, sealed with a key in your keychain (credentials.json when
                               credentials.store is file, or there is no keychain)
  sources.json                 the model sources you connected, and a custom endpoint's address (no secrets)
  memory/                      your memory as files, on a computer that keeps everything on its own disk
  skills/<name>/SKILL.md       your skills
  agents/                      your custom agents
  workflows/                   your saved workflows, and each run's script and journal
  plugins/                     installed plugins and marketplaces
  projects/<repository>/memory/  notes about each repository
  plans/                       plan mode's plans
  terminal/history.jsonl       prompts sent from the terminal
  hooks-approved.json          the hooks you approved
```

## 在项目中

```text
<folder>/
  AGENTS.md                    instructions for the project (checked in)
  AGENTS.local.md              your own instructions for it (not checked in)
  .aristra/
    settings.json              the project's settings (checked in)
    settings.local.json        yours, for the project (not checked in)
    AGENTS.md                  instructions, as AGENTS.md at the top of the folder
    rules/*.md                 rules, optionally for some paths
    skills/<name>/SKILL.md     the project's skills
    agents/                    the project's custom agents
    workflows/                 the project's saved workflows
    worktrees/<name>/          worktrees made with aristra -w and by agents
  .mcp.json                    the project's MCP servers (checked in)
```

## 其他位置

| 内容 | 位置 |
|---|---|
| 程序 | `~/.local/bin/aristra`，指向`~/.local/share/aristra/versions/<version>/`的链接 |
| 托管策略 | macOS：`/Library/Managed Preferences/`、`/Library/Application Support/Aristra/`。Linux：`/etc/aristra/` |
| 后台服务 | macOS：`~/Library/LaunchAgents/com.aristra.runtime.plist`。Linux：`~/.config/systemd/user/aristra-runtime.service` |
| 钥匙串项目 | macOS登录钥匙串，服务名为`Aristra-credentials`。Linux Secret Service，使用相同的属性 |

## 环境变量

运行时在启动时从启动它的应用（Aristra CLI或Aristra Desktop）获得变量。已经在运行的运行时会保留它启动时的变量：修改某个变量后，请运行`aristra runtime stop`，这样下一条命令会启动一个能看到新变量的运行时。如果Aristra Desktop处于打开状态，请先退出它，否则它可能会在没有你的变量的情况下重新启动运行时。只有本页列出的变量（以及代理、证书和区域设置相关的变量）会传递给运行时。安装了后台服务（`aristra service install`）时，由它启动的运行时看不到你的任何变量。

### 通用

| 变量 | 作用 |
|---|---|
| `ARISTRA_HOME` | 使用这个文件夹代替`~/.aristra` |
| `ARISTRA_TOKEN` | 用`aristra setup-token`生成的令牌登录，用于CI |
| `ARISTRA_LOG_LEVEL` | `DEBUG`、`INFO`（默认）、`WARNING`、`ERROR` |
| `ARISTRA_CREDENTIALS_STORE` | `auto`、`keychain`或`file` |
| `ARISTRA_MANAGED_SETTINGS_DIR` | 不存在管理员策略时使用的策略文件夹 |
| `ARISTRA_DISABLE_TELEMETRY` | `1`：不发送使用事件 |
| `ARISTRA_DISABLE_ERROR_REPORTING` | `1`：不发送错误报告 |
| `ARISTRA_DISABLE_NONESSENTIAL_TRAFFIC` | `1`：不发送使用事件、不发送错误报告，也不检查拉取请求状态 |
| `ARISTRA_SILENT_TURN_REMINDER`, `ARISTRA_SILENT_TURN_REMINDER_TURNS`, `ARISTRA_SILENT_TURN_REMINDER_TEXT` | 在连续几轮没有说明之后，提醒它说明自己正在做什么：`0`关闭提醒，多少轮之后提醒（默认5轮），以及提醒的文字 |
| `ARISTRA_TMPDIR` | 该文件夹下的`aristra-tmp-<uid>`子文件夹会作为每条命令的`$TMPDIR` |
| `OLLAMA_HOST` | Ollama监听的位置 |
| `BROWSER` | 打开登录页面的程序（在WSL上为`wslview`） |
| `VISUAL`, `EDITOR`, `PAGER` | 你的编辑器，以及Ctrl+O用来打开输出的程序 |
| `HTTP_PROXY`, `HTTPS_PROXY`, `NO_PROXY`, `SSL_CERT_FILE`, `NODE_EXTRA_CA_CERTS`等 | 运行时自己的请求会遵循`SSL_CERT_FILE`和代理变量；`NODE_EXTRA_CA_CERTS`会传递给命令 |

### 终端

| 变量 | 作用 |
|---|---|
| `ARISTRA_NO_NOTIFY` | 任意值：不发送终端通知 |
| `ARISTRA_NO_FLICKER` | `1`：本次启动使用全屏渲染器；`0`保留经典渲染器 |
| `IS_SANDBOX` | `1`：在你信任的容器中，允许以root身份运行Bypass permissions |
| `ARISTRA_REMOTE` | 要在其上运行的主机，与`--remote <host>`的设置相同 |
| `NO_COLOR`, `FORCE_COLOR` | 关闭终端的颜色，或强制开启 |
| `ARISTRA_DISABLE_ALTERNATE_SCREEN` | `1`：始终使用经典渲染器 |
| `ARISTRA_DISABLE_MOUSE`, `ARISTRA_DISABLE_MOUSE_CLICKS` | 在全屏模式下，把鼠标（或鼠标点击）交给终端处理 |
| `ARISTRA_SCROLL_SPEED` | 全屏模式下鼠标滚轮每格滚动的行数 |
| `ARISTRA_ENABLE_PROMPT_SUGGESTION` | `0`：不建议下一条消息 |
| `ARISTRA_IDLE_THRESHOLD_MINUTES`, `ARISTRA_IDLE_TOKEN_THRESHOLD` | 对于闲置的大型对话，何时出现“new task? /new”提示（默认为75分钟和100,000个token） |

### 对话和工具

| 变量 | 作用 |
|---|---|
| `ARISTRA_AUTO_COMPACT_WINDOW` | 自动压缩窗口，优先于`autoCompactWindow` |
| `ARISTRA_MAX_TURNS` | `aristra run`中每一轮的模型调用轮数 |
| `ARISTRA_MAX_STRUCTURED_OUTPUT_RETRIES` | 获取`--json-schema`答案的尝试次数（默认5次） |
| `ARISTRA_DISABLE_GIT_INSTRUCTIONS` | `1`：把git指导从shell工具中去掉 |
| `ARISTRA_DISABLE_WORKFLOWS` | `1`：关闭工作流 |
| `ARISTRA_ENABLE_TASKS` | `false`：使用更简单的待办列表，而不是任务工具 |
| `ARISTRA_ENABLE_TODO_TOOLS` | `1`：向所有模型提供任务工具（默认只有较旧的模型使用它们；当前的模型不需要它们也能规划） |
| `ARISTRA_SUBAGENT_EFFORT` | 当调用和定义都没有设置推理强度时，子智能体使用的推理强度 |
| `ARISTRA_DISABLE_AGENT_PROGRESS_SUMMARIES` | `1`：不为子智能体显示进度标签 |
| `ARISTRA_WEBFETCH_CACHE_TTL_MS` | 获取的网页缓存多长时间（默认15分钟） |
| `ARISTRA_WEBFETCH_DEADLINE_MS` | 获取网页的时限（默认5分钟） |
| `ARISTRA_MAX_WEB_SEARCHES_PER_SESSION` | 每个对话的搜索次数（默认200次） |
| `ARISTRA_WEB_SEARCH_REFILLS_PER_HOUR` | 搜索次数恢复的速度（默认每小时约100次） |
| `ARISTRA_MAX_RETRIES` | 失败的模型调用重试多少次（默认10次，最多15次） |
| `ARISTRA_RETRY_WATCHDOG` | `1`：对于无人监视的运行，等待服务商故障恢复而不是失败：最多尝试300次（过载或速率限制不计入次数），等待时间逐步退避到5分钟，单次等待最长6小时。`ARISTRA_RETRY_WATCHDOG_SCOPE=capacity`会把这一行为限定于过载和速率限制；`ARISTRA_RETRY_WATCHDOG_MAX_WAIT_MS`为总等待时间设置上限（默认没有上限） |
| `ARISTRA_STOP_HOOK_BLOCK_CAP` | `Stop`钩子最多可以连续让一轮继续多少次（默认8次；`0`表示没有限制） |
| `ARISTRA_DISABLE_SUBSTITUTION_RM_PROMPT`, `ARISTRA_DISABLE_MOUNTED_DRIVE_RM_PROMPT` | 关闭针对`rm`的两项安全提示 |
| `ARISTRA_DISABLE_NOTIFICATION_PRESENCE_CHECK` | 即使你在电脑前，也让Aristra Code自己的通知发送出来 |

### MCP服务器

| 变量 | 作用 |
|---|---|
| `ARISTRA_MCP_TOOL_IDLE_TIMEOUT` | 一次调用在没有响应的情况下可以持续的毫秒数（`0`表示不限制；程序服务器默认30分钟，地址服务器默认5分钟） |
| `ARISTRA_MCP_AUTO_BACKGROUND_MS` | 长时间调用何时转到后台（默认120秒；`0`表示从不） |

### 插件

| 变量 | 作用 |
|---|---|
| `ARISTRA_DISABLE_OFFICIAL_MARKETPLACE_AUTOINSTALL` | 首次启动时不添加Anthropic的插件市场 |
| `ARISTRA_DISABLE_AUTOUPDATER` | 不在后台更新插件 |
| `ARISTRA_FORCE_AUTOUPDATE_PLUGINS` | 即使设置了`ARISTRA_DISABLE_AUTOUPDATER`，也更新插件 |
| `ARISTRA_PLUGIN_AUTOUPDATE_DELAY_MS` | 启动后多久更新插件（默认为前10分钟内的一个随机时刻） |
| `ARISTRA_PLUGIN_GIT_TIMEOUT_MS` | 插件git操作的时限（默认120秒） |

### 安装

| 变量 | 作用 |
|---|---|
| `ARISTRA_NON_INTERACTIVE` | `1`：安装脚本不询问任何问题 |
| `ARISTRA_INSTALL_ALLOW_SUDO` | `1`：允许安装脚本通过sudo为root安装 |

### 由Aristra Code设置

| 变量 | 位置 |
|---|---|
| `ARISTRA_PROJECT_DIR`, `CLAUDE_PROJECT_DIR`, `ARISTRA_HOME` | 在钩子的环境中 |
| `${ARISTRA_SKILL_DIR}`, `${CLAUDE_SKILL_DIR}` | 在技能正文中被替换为技能的文件夹 |
| `${CLAUDE_PLUGIN_ROOT}` | 在插件的钩子和MCP服务器中，表示插件的文件夹 |
| `${CLAUDE_PLUGIN_DATA}`, `CLAUDE_PLUGIN_OPTION_<KEY>` | 在插件的钩子和MCP服务器中，表示插件的数据文件夹和它的选项 |
| `ARISTRA_MCP_SERVER_NAME`, `ARISTRA_MCP_SERVER_URL` | 在MCP服务器的`headersHelper`中 |
| `TMPDIR`, `TERM=dumb`, `PAGER=cat`, `GIT_PAGER=cat`, `NO_COLOR=1`, `GIT_EDITOR=true` | 在每条命令的环境中 |

## 退出状态

| 状态 | 含义 |
|---|---|
| `0` | 完成 |
| `1` | 有操作失败；原因输出在stderr中 |
| `2` | 用法错误 |
| `3` | `aristra run`：已完成，但有一步因为没有人可以批准而被拒绝 |
| `130` | `aristra run`：被Ctrl+C中断 |
