Remote Control会把在你电脑上运行的对话共享到你的Aristra账户，这样你就可以从手机或app.aristralabs.com阅读对话、发送消息和回复审批。代码和命令留在你的电脑上；只有对话内容会传输。

<Note>
Remote Control与在Aristra服务器上运行的[云端对话](/zh/code/cloud-chats)不同。使用Remote Control时，工作由你的电脑完成。
</Note>

Remote Control随[套餐](/zh/account/plans)提供，因为共享的对话保存在你的账户中。没有套餐时，你开启它时终端和Aristra Desktop会提示你。

## 开启

<Tabs>
  <Tab title="终端">
    在对话中运行：

    ```text
    /remote-control
    ```

    请在你发送第一条消息之后，在这台电脑上的对话中运行它；云端对话本来就在网页版上。Aristra Code会打印出对话的链接。`/rc`是简写，`/remote-control off`会停止共享。
  </Tab>
  <Tab title="Aristra Desktop">
    右键点击在这台Mac上运行的对话，选择**Continue on phone and web**。侧边栏中已共享的对话会带有手机图标。选择**Stop sharing to phone and web**即可停止。
  </Tab>
</Tabs>

Remote Control要求这台电脑已使用设备密钥登录。如果没有，菜单会提示你：请在这台电脑上重新登录。

## 你可以从手机和网页版做什么

- 在对话运行时阅读它，包括其中的步骤。
- 发送消息。在回复进行期间发送的消息会等待，在回复结束后运行，就像在Aristra Desktop中用⌘Enter排队的消息一样。
- 停止正在进行的回复。
- 批准或拒绝步骤。从另一台设备允许某一步时，需要在那台设备上重新进行登录验证；不会提供“don't ask again”类的答复；要求输入密钥等机密信息的问题只能在你的电脑上回答；在你电脑上给出的答复优先。
- 在你的电脑提供的模式和模型中，切换对话的模式和模型。切换到较宽松的模式之前，需要先重新进行登录验证。
- 为消息附加文件。

## 你的电脑不在线时

终端关闭或运行时停止时，已共享的对话仍然保持共享。在此期间你从手机或网页版发送的内容会等待，并标记为等待中，在你的电脑恢复后运行。对话记录会一直保留在你的账户中，直到你删除它，即使停止共享之后也是如此。

## 从网页版或手机在你的电脑上开始对话

你还可以在不在电脑旁边时，在你的某台电脑上开始一个新对话。在app.aristralabs.com上，选择新对话上方的**Runs on Aristra Cloud**，然后选择那台电脑。在它的页面上选择一个文件夹并输入你的消息。对话会在那台电脑上运行，使用它的文件、shell和工具，使用从你的余额中扣费的Aristra模型，并像任何共享对话一样保存到你的账户中。这需要套餐，并且那台电脑已使用设备密钥登录。

在你**在电脑本身上**允许之前，什么都无法开始。这项功能默认关闭，网站永远无法开启它。

<Tabs>
  <Tab title="Aristra Desktop">
    打开**Settings › General › From the web and phone**，开启**Start chats on this Mac from the web and phone**。然后开启允许对话开始的每个文件夹。
  </Tab>
  <Tab title="终端">
    ```text
    /remote-control computer on
    /remote-control folder on
    ```

    第一条命令为这台电脑开启该功能。第二条允许你当前所在的文件夹。`/remote-control computer`会显示允许了哪些内容，把`on`换成`off`即可撤销其中任何一项。
  </Tab>
</Tabs>

| 规则 | 含义 |
|---|---|
| **文件夹必须先被信任** | 在电脑上打开该文件夹中的对话并信任它。不受信任的文件夹无法被允许 |
| **有些文件夹永远不会被允许** | 你的主文件夹本身、其中的隐藏文件夹，以及磁盘的根目录 |
| **网站只显示文件夹名称，绝不显示路径** | 它看到的是文件夹的名称。路径留在你的电脑上 |
| **电脑会检查每次启动** | 每次都会在电脑上重新检查开关、文件夹、信任状态和模式 |
| **不能从另一台设备绕过权限** | 你可以选择Manual、Accept edits、Plan或Auto，或者保留电脑自己的默认模式 |
| **电脑必须在线** | 启动需要电脑开机并已连接。之后你发送的消息会等待它，就像任何共享对话一样 |

审批会在对话中、网页版上和电脑上等待；以最先给出的答复为准。当有对话从另一台设备开始时，电脑会显示一条通知。

## 始终可以访问的电脑

[云电脑](/zh/surfaces/cloud-computer)是你自己位于Aristra云端的电脑。你可以从网页版和手机在它上面开始对话，它会为你的消息而唤醒，所以它永远不会不在线。

## 连接方式

你的电脑与Aristra保持一个出站HTTPS连接，并用它的设备令牌和设备密钥进行身份验证。你的电脑上没有任何监听服务，来自手机或网页版的每个请求最多只运行一次。
