Aristra, c'est un seul assistant avec un seul compte. Parlez-lui sur le web ou sur votre téléphone, dans Aristra Desktop sur votre Mac, dans votre terminal ou depuis Telegram. Vos chats dans Aristra Cloud, ce qu'Aristra retient de vous et vos fichiers vous suivent de l'un à l'autre.

## Où l'utiliser

Chaque endroit où vous utilisez Aristra est une surface. Elles partagent votre compte : un chat dans Aristra Cloud se retrouve donc dans chacune d'elles. Un chat qu'Aristra Code exécute sur votre ordinateur reste sur cet ordinateur, sauf si vous le partagez avec Remote Control.

| Surface | Ce que c'est |
|---|---|
| [Le web et votre téléphone](/fr/surfaces/web) | [app.aristralabs.com](https://app.aristralabs.com), dans n'importe quel navigateur et sur votre téléphone. Les pages de votre compte s'y trouvent aussi |
| [Aristra Desktop](/fr/surfaces/desktop) | L'app pour Mac : un onglet **Chat** pour vos conversations et un onglet **Code** pour Aristra Code |
| [Aristra Code](/fr/surfaces/aristra-code) | Aristra qui travaille dans des dossiers de votre ordinateur : la commande `aristra` dans votre terminal, l'onglet Code d'Aristra Desktop et votre éditeur |
| [Telegram](/fr/surfaces/telegram) | Écrivez à Aristra depuis Telegram, avec un forfait |
| [Ordinateur cloud](/fr/surfaces/cloud-computer) | Un ordinateur Linux à vous dans le cloud d'Aristra, sur lequel Aristra travaille pendant que votre propre ordinateur est éteint. Il nécessite un forfait ou de l'argent que vous avez ajouté ; le crédit de bienvenue ne le paie pas |

## Ce que ça coûte

Créer un compte est gratuit, et chaque compte démarre avec un crédit de $1 pour les modèles et les outils d'Aristra. Les chats sur le web sont payés au fur et à mesure depuis votre solde, et votre mémoire ainsi que 1 Go de fichiers sont inclus avec chaque compte. Aristra Desktop et l'Aristra CLI sont gratuits avec un modèle à vous : votre propre clé de fournisseur, votre forfait ChatGPT ou un modèle sur votre ordinateur. Consultez [Utiliser votre propre modèle](/fr/own-models).

Un forfait (Plus à $20, Pro à $100 ou Max à $200 par mois) ajoute chaque mois ce montant en consommation des modèles d'Aristra, ainsi que Craft, les connecteurs, les tâches planifiées dans le cloud, Telegram et l'utilisation de vos ordinateurs depuis le web. Consultez [Votre compte et Aristra One](/fr/account/overview) et [Forfaits et tarifs](/fr/account/plans).
