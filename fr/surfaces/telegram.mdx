Avec un [forfait](/fr/account/plans), vous pouvez écrire à Aristra depuis Telegram. C'est le même Aristra, avec votre mémoire, vos fichiers et vos apps connectées, et ses réponses sont payées depuis votre solde comme n'importe quel chat.

## Connecter Telegram

1. Sur le site web, ouvrez **Customize › Channels** et choisissez **Connect** sur Telegram.
2. Choisissez **Open in Telegram**, ou scannez le QR code avec votre téléphone, puis appuyez sur **Start** dans Telegram. Le lien ne fonctionne qu'une fois, pendant 5 minutes.

**Disconnect**, sur la même carte, empêche Aristra d'y répondre.

## Votre chat Telegram

Votre chat Telegram privé avec Aristra prolonge un chat de votre compte, nommé **Aristra**. Il n'est pas dans la barre latérale du site web ; **Chats** le liste. Envoyez `/new` pour démarrer un chat distinct, qui apparaît dans la barre latérale marqué comme venant de Telegram, et `/home` pour revenir (`/home` sert à votre chat privé, pas à un groupe). Un groupe Telegram a son propre chat.

Aristra lit les notes vocales que vous envoyez.

| Commande | |
|---|---|
| `/new` | Démarrer un nouveau chat |
| `/home` | Revenir à votre chat principal |
| `/model` | Choisir le modèle |
| `/think` | Raisonnement : off (rapide), ou low, medium ou high |
| `/switch` | Choisir un projet pour ce chat |
| `/continue` | Reprendre une réponse qui s'est interrompue à sa limite |
| `/settings` | Votre espace de travail et votre projet |
| `/stop` | Arrêter la réponse en cours |
| `/help` | Les commandes |

## L'envoyer vers votre ordinateur cloud

Avec un [ordinateur cloud](/fr/surfaces/cloud-computer), activez **Telegram messages go to this computer** sur sa page. Votre chat Telegram privé s'exécute alors dessus, en le réveillant s'il est en veille. Envoyez `/new` pour y démarrer un nouveau chat. Les approbations se donnent sur le site web.

## Autres apps

WhatsApp, Slack et Discord sont listés sous **Channels** comme bientôt disponibles. Pour l'instant, seul Telegram fonctionne.
