[app.aristralabs.com](https://app.aristralabs.com), c'est Aristra dans n'importe quel navigateur, sur un ordinateur ou un téléphone. Les chats y sont exécutés par l'agent cloud d'Aristra et conservés dans votre compte : ce sont donc les mêmes chats que dans l'onglet Chat d'Aristra Desktop et que les [chats cloud](/fr/code/cloud-chats) du terminal.

## Ce que contient la barre latérale

| | À quoi ça sert | |
|---|---|---|
| **Chats** | Des [chats](/fr/chats) avec n'importe quel modèle d'Aristra, payés depuis votre solde | Tous les comptes |
| **Projects** | Les [projets](/fr/projects) : les chats, les fichiers, les instructions et la mémoire d'un travail | Tous les comptes |
| **Files** | Les [fichiers](/fr/files) que conserve votre compte | Tous les comptes |
| **Memory** | Ce qu'Aristra retient de vous. Consultez [Mémoire](/fr/memory) | Tous les comptes |
| **Craft** | Les documents [Craft](/fr/craft) | Tous les comptes |
| **Scheduled tasks** | Les [tâches planifiées](/fr/scheduled-tasks) dans le cloud | Avec un forfait |
| **Customize** | Les [connecteurs](/fr/connectors), Skills, Channels ([Telegram](/fr/surfaces/telegram)) et MCP | Avec un forfait |
| **Cloud computer** | Votre [ordinateur cloud](/fr/surfaces/cloud-computer) | Avec un forfait ou un solde rechargé |

Sans forfait, les éléments qui en nécessitent un ne figurent pas dans la barre latérale, et leurs pages indiquent ce qu'apporte un forfait si vous en ouvrez une depuis un lien. Après la fin d'un forfait, ils restent, en lecture et à l'export. Quand votre solde est épuisé, la zone de message vous le signale et propose une recharge ou un forfait.

## Votre compte

**Settings**, depuis le menu en bas de la barre latérale, ouvre les pages de votre compte : votre profil, la personnalisation et les interrupteurs de mémoire, la facturation, la consommation, les appareils, les téléchargements et l'export. Consultez [Votre compte et Aristra One](/fr/account/overview).

## Vos ordinateurs

Sous un nouveau chat, **Runs on Aristra Cloud** liste votre ordinateur cloud et tous les ordinateurs connectés à votre compte. Avec un forfait, choisissez-en un pour :

- **Suivre un chat et y répondre** quand vous l'avez partagé depuis Aristra Desktop ou le terminal, y compris ses approbations. Consultez [Remote Control](/fr/code/remote-control).
- **Démarrer un chat sur un ordinateur**, dans un dossier que cet ordinateur autorise. Cette option est désactivée tant que vous ne l'activez pas, sur cet ordinateur. Consultez [Démarrer un chat sur votre ordinateur depuis le web ou un téléphone](/fr/code/remote-control).

Le chat s'exécute sur cet ordinateur, avec ses fichiers et ses outils, sur l'un des modèles d'Aristra, payé par la consommation mensuelle de votre forfait puis par votre solde rechargé.

## Sur un téléphone

Ouvrez app.aristralabs.com dans le navigateur de votre téléphone et connectez-vous. Ajoutez-le à votre écran d'accueil pour l'ouvrir comme une app. Tout ce qui précède y fonctionne, y compris répondre aux demandes d'approbation des chats sur votre ordinateur.

## Espaces de travail

Votre compte a un espace de travail personnel. Inviter d'autres personnes nécessite un espace de travail d'équipe, qui n'est pas encore disponible.
