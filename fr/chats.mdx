Un chat sur le site web, sur votre téléphone ou dans l'onglet Chat d'Aristra Desktop s'exécute dans Aristra Cloud et est conservé dans votre compte : c'est donc le même chat partout où vous vous connectez. Les chats dans un dossier de votre ordinateur sont des chats [Aristra Code](/fr/surfaces/aristra-code).

## Démarrer un chat

- **Sur le web ou sur votre téléphone :** **New chat** dans la barre latérale d'[app.aristralabs.com](https://app.aristralabs.com).
- **Dans Aristra Desktop :** un nouveau chat dans la vue **Chat**. Vous devez être connecté.
- **De n'importe où sur votre Mac :** appuyez sur **⌥Space** pour la saisie rapide, tapez, puis appuyez sur Enter.
- **Dans un [projet](/fr/projects) :** démarrez-le depuis le projet, et il utilise les instructions, les fichiers et la mémoire du projet.
- **Depuis Telegram :** avec un forfait. Consultez [Telegram](/fr/surfaces/telegram).

## Choisir le modèle

Le sélecteur de modèle dans la zone de message, à côté du bouton d'envoi, liste les modèles d'Aristra : Claude Haiku, Sonnet et Opus 5.5, GPT-6 Luna, GPT-6.1 Terra et GPT-6.1 Sol, et Gemini 3.5 Flash-Lite, 3.8 Flash et 3.1 Pro. **Auto** utilise Gemini 3.8 Flash. Chaque modèle indique son coût ($ à $$$), et certains vous laissent choisir l'intensité de leur réflexion (Low, Medium, High et, sur certains, Extra High et Max). Tous les modèles sont ouverts à tous les comptes.

Chaque message est payé depuis votre solde : d'abord le crédit de bienvenue d'un nouveau compte, puis la consommation mensuelle d'un forfait, puis les recharges. Les prix se trouvent sur [Models and prices](https://app.aristralabs.com/models). Quand votre solde est épuisé, la zone de message vous le signale et propose une recharge ou un forfait.

## Ce qu'Aristra peut faire dans un chat

| | |
|---|---|
| **Chercher et lire sur le web** | Cherche sur le web, dans les actualités, les images et les vidéos, et lit des pages. Le menu **+** contient des interrupteurs pour **Web search** et **URL extraction** |
| **Lire vos fichiers** | Les pièces jointes, les fichiers de votre compte, et les PDF page par page |
| **Exécuter du code** | Dans son propre bac à sable Linux : analyse des données et produit des fichiers PDF, Word, Excel et PowerPoint ainsi que des graphiques. Une application web qu'il y démarre reçoit une [adresse privée](/fr/sites) |
| **Créer des images** | Choisissez **Create image** dans le menu **+**, avec un style |
| **Montrer des choses** | Des graphiques et des diagrammes, la météo, des cartes, des tableaux comparatifs et des brouillons d'e-mail (il ne peut pas les envoyer) |
| **Retenir** | Enregistre, met à jour et oublie des souvenirs au fil de vos échanges. Consultez [Mémoire](/fr/memory) |
| **Vous demander** | Une question, ou un court formulaire, quand il a besoin de votre réponse |
| **Travailler dans vos apps** | Avec un forfait, les apps que vous avez connectées. Consultez [Connecteurs](/fr/connectors) |
| **Rédiger des documents** | Des documents [Craft](/fr/craft) à côté du chat |
| **Planifier du travail** | Avec un forfait, des [tâches planifiées](/fr/scheduled-tasks) |

## Joindre des fichiers

Choisissez **+**, puis **Upload files or images**, ou **Attach from Files** pour un fichier déjà dans votre compte. Un message peut contenir jusqu'à 5 fichiers, de 50 Mo chacun et de 50 Mo au total. Aristra lit les PDF (pages numérisées comprises), Word, Excel, PowerPoint, le texte, CSV, JSON, le code et les images.

Un fichier que vous joignez est conservé avec son chat, et compte dans votre [stockage](/fr/files), jusqu'à ce que vous supprimiez le chat.

## Modifier et régénérer

Survolez un message pour le modifier, ou une réponse pour la régénérer. Chaque version est conservée : des flèches sur le message permettent de passer de l'une à l'autre.

## Chats incognito

Choisissez l'icône de fantôme en haut du chat sur le web, ou sur un nouveau chat dans l'onglet Chat d'Aristra Desktop. Dans le terminal, lancez `aristra --cloud --incognito`. Un chat incognito :

- N'apparaît pas dans votre liste de chats, et rien de ce qu'il contient n'est enregistré dans votre mémoire ni appris par la suite.
- Peut quand même utiliser ce qu'Aristra retient déjà de vous, tant que Memory est activé.
- Ne peut plus être rouvert une fois que vous l'avez quitté.
- Est supprimé 30 jours après son dernier message.

## Retrouver un chat

- **Sur le web :** la page **Chats** liste tous les chats et les retrouve par titre. **⌘K** ouvre vos chats récents, vos projets et des actions. **⌘F** cherche des mots dans le chat ouvert.
- **Dans Aristra Desktop :** **⌘K** retrouve les chats par titre, les dossiers et les commandes, ainsi que des mots dans les messages des chats de ce Mac.

## Exporter ou supprimer

Le menu d'un chat contient **Rename**, **Export as Markdown**, **Copy transcript (Markdown)** et **Delete**. Supprimer un chat le supprime avec ses fichiers. Pour récupérer une copie de tous vos chats d'un coup, consultez [Export](/fr/account/export).

Un chat ne peut pas être partagé sous forme de lien public. Pour partager quelque chose qu'Aristra a écrit, publiez un document [Craft](/fr/craft) ou un fichier créé par Aristra : **Publish** sur sa carte lui donne un lien public.

## Voix

Dans Aristra Desktop, le bouton micro de la zone de message accepte jusqu'à 10 minutes de dictée et la tape pour vous, payée depuis votre solde à $0.001 la minute. Sur [Telegram](/fr/surfaces/telegram), Aristra lit les notes vocales.
