Ce guide vous mène de l'absence de compte à un premier chat, puis à Aristra sur votre Mac et sur votre téléphone. [Se connecter](/fr/quickstart) donne les étapes pour chaque point d'entrée. Pour commencer plutôt par du code dans un terminal, consultez le [démarrage rapide d'Aristra Code](/fr/code/quickstart).

<Steps>
  <Step title="Créez votre compte">
    Rendez-vous sur [app.aristralabs.com](https://app.aristralabs.com) et choisissez **Sign up**.

    - **Tant qu'Aristra ouvre par vagues**, la page affiche **Join the waitlist** (ou **We are full for now**, quand toutes les places sont prises). Saisissez votre adresse e-mail et choisissez **Join waitlist**. Aristra vous écrit quand votre place est prête ; vous n'avez rien d'autre à faire d'ici là.
    - **Avec un lien d'invitation**, ouvrez le lien de votre e-mail d'invitation. Il vous mène directement au formulaire, qui reprend l'adresse e-mail de l'invitation.
    - **Une fois les inscriptions ouvertes**, la page affiche **Create your account**.

    Sur **Create your account**, saisissez votre nom (facultatif), votre adresse e-mail, un mot de passe d'au moins 8 caractères, puis à nouveau le mot de passe. Choisissez **Create account**. Saisissez ensuite le code qu'Aristra envoie à votre adresse e-mail (un lien d'invitation vous épargne cette étape) et choisissez de nouveau **Create account**. **Send a new code** en envoie un autre.

    Un nouveau compte est gratuit et démarre avec un crédit de $1 pour les modèles et les outils d'Aristra, une seule fois par adresse e-mail.
  </Step>

  <Step title="Présentez-vous à Aristra">
    Quelques écrans courts suivent : un accueil, ce qui vous amène (écrire, faire des recherches, organiser vos journées ou créer des workflows), votre nom et votre espace, et une étape facultative sur la mémoire. Vous pourrez modifier plus tard votre nom et la note **About you** sur la page **Profile** de votre compte. Pour changer la façon dont Aristra vous parle, dites-le-lui dans un chat.
  </Step>

  <Step title="Lancez un chat">
    L'écran de nouveau chat affiche **Runs on Aristra Cloud** au-dessus de la zone de message, quelques prompts pour démarrer et, sous la zone, le montant dont vous disposez. Tapez ce que vous voulez et appuyez sur Enter.

    - **Choisissez le modèle** dans le sélecteur. **Auto** est un bon choix par défaut ; tous les modèles sont ouverts à tous les comptes, et chacun indique son coût.
    - **Joignez des fichiers** avec **+** : PDF, fichiers Word, Excel et PowerPoint, images, texte et code, jusqu'à 5 fichiers et 50 Mo par message.
    - **Chaque message est payé** depuis votre solde : d'abord votre crédit de bienvenue, puis la consommation mensuelle d'un forfait ou vos recharges. Consultez [Votre solde et vos recharges](/fr/account/credits).

    Aristra fait des recherches sur le web, lit vos fichiers, exécute du code pour produire des fichiers et des graphiques, et retient ce qui compte. Consultez [Chats](/fr/chats).
  </Step>

  <Step title="Installez Aristra sur votre Mac">
    Ouvrez la page **Downloads** de votre compte et choisissez **Download for Mac** (Apple silicon et Intel). Ouvrez Aristra Desktop et choisissez **Sign in** ; les étapes se trouvent sous [Se connecter](/fr/quickstart), dans l'onglet **Aristra Desktop**.

    L'app a deux onglets. **Chat** contient les mêmes chats que le site web. **Code** est Aristra Code, pour travailler dans des dossiers de votre Mac. Consultez [Aristra Desktop](/fr/surfaces/desktop).

    Sur votre Mac, Aristra peut aussi fonctionner avec votre forfait ChatGPT, votre propre clé API ou un modèle sur votre ordinateur, comme Ollama. Consultez [Utiliser votre propre modèle](/fr/own-models).
  </Step>

  <Step title="Utilisez-le sur votre téléphone">
    Ouvrez app.aristralabs.com dans le navigateur de votre téléphone et connectez-vous. Ajoutez-le à votre écran d'accueil pour l'ouvrir comme une app.
  </Step>
</Steps>

## Se connecter

Votre compte Aristra est le même partout. Le site web et votre téléphone se connectent avec votre adresse e-mail. Aristra Desktop, le terminal et les éditeurs connectent **un ordinateur** : vous commencez sur l'ordinateur, puis vous l'approuvez sur le site web, dans votre navigateur ou sur n'importe quel téléphone ou ordinateur où vous êtes connecté.

Aristra Desktop, le terminal et vos éditeurs partagent une seule connexion sur un même ordinateur. Connectez-vous une fois sur cet ordinateur, et tous sont connectés.

<Tabs>
  <Tab title="Site web">
    **Avec votre mot de passe**

    1. Rendez-vous sur [app.aristralabs.com](https://app.aristralabs.com). La page affiche **Welcome back**.
    2. Saisissez votre **Email** et votre **Password**.
    3. Choisissez **Sign in**.

    **Avec un code envoyé à votre adresse e-mail**

    1. Sur **Welcome back**, saisissez votre **Email**. Laissez le mot de passe vide.
    2. Sous **Or continue with**, choisissez **Email me a sign-in code**.
    3. Sur **Check your email**, saisissez le **Code** reçu par e-mail et choisissez **Continue**.

    **Si vous avez oublié votre mot de passe**

    1. Sur **Welcome back**, choisissez **Forgot your password?**
    2. Saisissez votre **Email** et choisissez **Send reset code**.
    3. Saisissez le **Code** reçu par e-mail et un **New password**, puis choisissez **Reset password**. Cela vous connecte aussi.

    Une connexion depuis un nouveau navigateur peut aussi vous demander, après votre mot de passe, un code reçu par e-mail, sur le même écran **Check your email**.
  </Tab>

  <Tab title="Aristra Desktop">
    Aristra Desktop s'ouvre sur **Sign in to Aristra** tant que vous n'êtes pas connecté. Si vous n'avez pas encore de compte, **Create an account** ouvre la page d'inscription dans votre navigateur.

    **Dans votre navigateur**

    1. Choisissez **Sign in**. Votre navigateur ouvre la page **Authorize Aristra Desktop** d'Aristra. Si vous n'êtes pas connecté au site web dans ce navigateur, connectez-vous d'abord ; la page revient ensuite.
    2. Vérifiez les lignes **Computer** et **Account** : elles indiquent ce Mac et le compte qu'il va rejoindre.
    3. Choisissez **Approve**. La page affiche **Computer connected**, et l'app continue d'elle-même. Vous pouvez fermer l'onglet.

    Si la page ne s'est pas ouverte, choisissez **Open the page again** dans l'app.

    **Avec un code, sur un autre appareil**

    Utilisez cette méthode quand le navigateur de ce Mac ne parvient pas à terminer la connexion, ou si vous préférez approuver sur votre téléphone.

    1. Choisissez **Sign in**, puis **Use a code instead**. L'app affiche un code de huit lettres, comme `BCDF-GHJK`, avec **Copy**.
    2. Sur n'importe quel téléphone ou ordinateur, rendez-vous sur **app.aristralabs.com/desktop/device** et connectez-vous si on vous le demande. **Open the page** dans l'app l'ouvre sur ce Mac avec le code déjà rempli.
    3. Saisissez le code et choisissez **Continue**.
    4. Vérifiez que le code et le **Computer** correspondent à ce Mac, puis choisissez **Approve**. L'app continue d'elle-même.

    Le code est valable 10 minutes. Passé ce délai, choisissez de nouveau **Sign in** pour en obtenir un nouveau.
  </Tab>

  <Tab title="Terminal">
    Installez d'abord Aristra Code : consultez le [démarrage rapide d'Aristra Code](/fr/code/quickstart). La première fois que vous lancez `aristra` sans être connecté, il vous demande de vous connecter. Vous pouvez aussi vous connecter à tout moment :

    ```sh
    aristra login
    ```

    **Dans votre navigateur**

    1. Choisissez **In your browser** (le premier choix sur un ordinateur doté d'un navigateur), ou lancez `aristra login`.
    2. Votre navigateur ouvre la page **Authorize Aristra Code** d'Aristra. Sinon, ouvrez le lien que le terminal affiche.
    3. Vérifiez les lignes **Computer** et **Account**, puis choisissez **Approve**.
    4. Le terminal affiche **Signed in as** suivi de votre adresse e-mail.

    **Avec un code, sur un autre appareil**

    1. Choisissez **With a code, on another device**, ou lancez `aristra login --device-code`. Pendant qu'une connexion par navigateur attend, vous pouvez aussi appuyer sur **c** pour passer à un code.
    2. Le terminal affiche : Go to https://app.aristralabs.com/desktop/device and enter the code `BCDF-GHJK` (votre code est différent).
    3. Sur n'importe quel téléphone ou ordinateur, ouvrez cette page, connectez-vous si on vous le demande, saisissez le code et choisissez **Continue**.
    4. Vérifiez que le code et le **Computer** correspondent, puis choisissez **Approve**.

    **Par SSH, ou sur une autre machine**

    Par SSH, ou sous Linux sans écran, le code est proposé en premier, puisque cet ordinateur n'a pas de navigateur. Avec `aristra --remote <host>`, l'autre machine se connecte comme un ordinateur à part entière : connectez-vous-y avec un code, en choisissant **With a code, on another device** ou en tapant `/login code` (`aristra --remote <host> login` en utilise toujours un).

    **Dans un chat**

    `/login` vous connecte, `/login code` vous connecte avec un code, et `/logout` vous déconnecte. `aristra status` indique à quel compte cet ordinateur est connecté.

    **Scripts et CI**

    `aristra setup-token` affiche un jeton valable un an. Définissez-le comme `ARISTRA_TOKEN` là où le script s'exécute. Il apparaît dans vos appareils comme une entrée à part, et c'est là que vous le révoquez.
  </Tab>

  <Tab title="Éditeurs">
    Zed et les autres éditeurs qui parlent l'Agent Client Protocol exécutent Aristra Code avec `aristra acp`. Ajoutez-le d'abord à votre éditeur : consultez [Éditeurs](/fr/code/editors).

    1. Démarrez un fil Aristra dans le panneau d'agent de l'éditeur. Si cet ordinateur n'est pas encore connecté, l'éditeur vous demande de vous connecter.
    2. Choisissez **Sign in to Aristra**. Votre navigateur ouvre la page **Authorize Aristra**.
    3. Vérifiez les lignes **Computer** et **Account**, puis choisissez **Approve**. L'éditeur continue.

    La connexion attend 5 minutes. Si Aristra Desktop ou le terminal est déjà connecté sur cet ordinateur, l'éditeur l'est aussi, et vous n'avez rien à faire.
  </Tab>

  <Tab title="Téléphone">
    1. Ouvrez [app.aristralabs.com](https://app.aristralabs.com) dans le navigateur de votre téléphone.
    2. Connectez-vous comme sur le site web, avec votre mot de passe ou un code envoyé à votre adresse e-mail.
    3. Facultatif : ajoutez la page à votre écran d'accueil pour ouvrir Aristra comme une app.

    Votre téléphone est aussi un bon endroit pour approuver un ordinateur : ouvrez **app.aristralabs.com/desktop/device** et saisissez le code que l'ordinateur affiche.
  </Tab>
</Tabs>

### Approuver un ordinateur

La page d'approbation indique l'**Application** (**Aristra Desktop**, **Aristra Code in a terminal**, ou simplement **Aristra** pour un éditeur), le **Computer** et l'**Account** qu'il rejoint. L'ordinateur rejoint le compte auquel le site web est connecté, quel qu'il soit : vérifiez donc la ligne **Account** avant de choisir **Approve**.

N'approuvez qu'une connexion que vous avez lancée vous-même, à l'instant. Aristra ne vous demandera jamais d'approuver un code. **Deny** ne connecte rien, et la connexion sur cet ordinateur expire d'elle-même.

Un ordinateur connecté le reste tant que vous l'utilisez. Un ordinateur inutilisé pendant 30 jours vous demande de vous reconnecter. Un compte peut avoir 20 ordinateurs et jetons de script connectés à la fois. Ceux dont la connexion a expiré ne comptent plus.

### Se déconnecter

| Pour vous déconnecter de | Faites ceci |
|---|---|
| Le site web, dans ce navigateur | Choisissez votre nom en bas de la barre latérale, puis **Log out**. Vos ordinateurs restent connectés |
| Ce Mac | Dans Aristra Desktop, ouvrez le menu du compte (votre nom, en bas à gauche) et choisissez **Sign out**. Les chats en cours s'arrêtent, ici et dans le terminal |
| Cet ordinateur, dans un terminal | Arrêtez d'abord les chats en cours, puis lancez `aristra logout`, ou `/logout` dans un chat. Aristra Desktop se déconnecte aussi sur cet ordinateur |
| Un autre ordinateur | Sur le site web, ouvrez **Settings › Devices** et choisissez **Sign out** à côté de cet ordinateur. Ses chats et ses fichiers y restent. Votre ordinateur cloud, lui, s'arrête ou se supprime depuis **Manage** |
| Tous les ordinateurs d'un coup | Dans Aristra Desktop, **Settings › Account › Sign out all**. Tous les ordinateurs et les jetons de script se déconnectent, ce Mac compris. Votre ordinateur cloud et vos sessions web restent tels quels |
| Votre forfait ChatGPT | `aristra logout chatgpt` dans un terminal (ou `/logout chatgpt` dans un chat), ou **Sign out** sur **ChatGPT plan** dans **Settings › Models** d'Aristra Desktop. Aristra reste connecté |

Se déconnecter d'Aristra conserve votre connexion ChatGPT et vos clés API sur cet ordinateur. Les chats d'un ordinateur réapparaissent quand le même compte se reconnecte.

### Si la connexion ne fonctionne pas

<AccordionGroup>
  <Accordion title="La connexion a expiré">
    Une connexion par navigateur dure 5 minutes et un code 10 minutes. Relancez la connexion sur l'ordinateur (**Sign in** dans Aristra Desktop, `aristra login` dans un terminal) pour obtenir une nouvelle page ou un nouveau code.
  </Accordion>
  <Accordion title="Le code n'est pas accepté">
    Vérifiez chaque lettre. Les codes n'utilisent que des consonnes : il n'y a donc ni O ni I à confondre avec 0 ou 1, et vous pouvez taper le code avec ou sans le tiret. Après 10 vérifications de code en 10 minutes (chaque **Continue** et chaque **Approve** compte), attendez quelques minutes et relancez la connexion.
  </Accordion>
  <Accordion title="La page du navigateur n'atteint jamais l'ordinateur">
    Le navigateur est peut-être sur un autre appareil, ou ne peut pas joindre cet ordinateur. Passez à un code : **Use a code instead** dans Aristra Desktop, **c** pendant que le terminal attend, ou `/login code` dans un chat.
  </Accordion>
  <Accordion title="Revoke an existing device before connecting another">
    Votre compte a 20 ordinateurs et jetons de script connectés. Dans **Settings › Devices** sur le site web, déconnectez ceux que vous n'utilisez plus, puis reconnectez-vous.
  </Accordion>
  <Accordion title="Your account is on the waitlist">
    Aristra fait entrer les gens progressivement. Une fois votre place prête (Aristra vous envoie un e-mail), relancez la connexion sur l'ordinateur.
  </Accordion>
  <Accordion title="Sign out of the current Aristra account before signing in to another">
    Un ordinateur est connecté à un seul compte Aristra à la fois. Déconnectez-vous d'abord sur cet ordinateur, puis connectez-vous avec l'autre compte. Pour approuver avec un autre compte, déconnectez-vous d'abord du site web dans ce navigateur.
  </Accordion>
</AccordionGroup>
