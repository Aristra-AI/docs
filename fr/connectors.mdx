Un connecteur relie l'une de vos apps à votre compte Aristra, pour qu'Aristra puisse la lire et y agir : retrouver un e-mail, ajouter un événement à l'agenda, mettre à jour une page Notion, ouvrir une issue GitHub. Les connecteurs sont inclus avec un [forfait](/fr/account/plans).

## Les apps

Gmail, Google Calendar, Google Drive, Google Docs, Google Sheets, Outlook, Slack, Discord, Notion, Airtable, Linear, Jira, Trello, GitHub, Sentry, Datadog, Databricks, Supabase, Figma, Canva, Dropbox, Calendly, Zoom, YouTube, HubSpot, Attio, Mailchimp, Stripe, LinkedIn, Facebook, Reddit et X.

## Connecter une app

1. Sur le site web, ouvrez **Customize › Connectors**.
2. Choisissez une app, puis **Connect**.
3. Connectez-vous à l'app sur sa propre page et autorisez l'accès. Vous revenez sur Connectors une fois l'opération terminée.

Une app dont l'accès a expiré affiche **Needs reconnect** ; choisissez **Reconnect**. **Disconnect** supprime l'accès d'Aristra à cette app.

Pour chacune des actions d'une app, vous pouvez choisir **Always allow**, **Needs approval** ou **Blocked**.

## Où Aristra les utilise

- **Les chats** sur le site web, sur votre téléphone, dans l'onglet Chat d'Aristra Desktop et sur [Telegram](/fr/surfaces/telegram).
- **[Aristra Code](/fr/surfaces/aristra-code)** sur votre ordinateur, une fois connecté. Ce sont les serveurs d'Aristra qui font chaque appel : les connexions aux apps n'atteignent donc jamais votre ordinateur.
- **Les [tâches planifiées](/fr/scheduled-tasks)**, qui peuvent aussi démarrer quand quelque chose se produit dans une app connectée.

## Serveurs MCP pour les chats

Sous **Customize › Connectors**, vous pouvez aussi ajouter votre propre serveur MCP par son adresse, avec des en-têtes ou la connexion propre au serveur. Tant que vous ne lui faites pas confiance, Aristra demande votre accord avant chaque exécution de l'un de ses outils ; une fois que vous lui faites confiance, ses outils en lecture seule s'exécutent sans demander. Vos chats sur le site web et sur Telegram l'utilisent.

Les serveurs MCP et les skills pour Aristra Code se configurent sur votre ordinateur. Consultez [Serveurs MCP](/fr/code/extend/mcp) et [Skills](/fr/code/extend/skills).

## Utiliser Aristra depuis d'autres apps d'IA

**Customize › MCP** vous donne une adresse à coller dans ChatGPT, Claude ou un autre assistant qui accepte un connecteur personnalisé, pour qu'il puisse utiliser votre mémoire et vos fichiers Aristra. Son utilisation est payée depuis votre solde.
