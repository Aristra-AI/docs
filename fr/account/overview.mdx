Un seul compte Aristra fonctionne partout. Aristra sur votre propre ordinateur est gratuit. Un forfait ajoute ce qu'Aristra héberge pour vous.

## Les parties d'Aristra

| Nom | Ce que c'est |
|---|---|
| **Aristra One** | Le forfait de votre compte : Free, Plus, Pro ou Max. Ses pages sur le site web affichent votre forfait, votre solde, votre consommation et vos appareils |
| **Le site web** | [app.aristralabs.com](https://app.aristralabs.com) : vos chats dans n'importe quel navigateur ou sur un téléphone (payés depuis votre solde, ou avec un forfait), vos fichiers, votre mémoire et Craft. Consultez [Le web et votre téléphone](/fr/surfaces/web) |
| **Aristra Desktop** | L'app pour Mac : les chats, et l'onglet Code |
| **Aristra CLI** | La commande `aristra` dans un terminal, sur un Mac ou une machine Linux |
| **Aristra Code** | L'agent de code. Vous l'utilisez dans l'onglet Code d'Aristra Desktop, dans l'Aristra CLI, dans votre éditeur et sur un ordinateur cloud |
| **Aristra Cloud** | Tout ce qu'Aristra héberge : les modèles d'Aristra, l'agent cloud, un ordinateur cloud, la mémoire du compte (celle de chaque compte), le stockage, les connecteurs et les tâches planifiées dans le cloud |

## Ce qui est gratuit

- **Aristra Desktop et l'Aristra CLI**, connectés à votre compte, avec un modèle à vous : votre propre clé de fournisseur, votre forfait ChatGPT ou un modèle qui tourne sur votre ordinateur. Consultez [Modèles](/fr/code/configure/models).
- **Aristra Code** dans vos propres dossiers, avec tous les outils qui s'exécutent sur votre ordinateur.
- **La mémoire de votre compte**, sur tous vos appareils : ce qu'Aristra retient de vous, enregistré pendant vos chats et appris chaque nuit à partir de vos chats récents. L'enregistrer, l'importer et y chercher ne coûte rien. Consultez [Mémoire](/fr/memory).
- **Files** dans Aristra Desktop, sur le web, et `/files` dans le terminal : ce que vos chats ont produit, partagé ou reçu. La lecture des fichiers PDF, Word, Excel et PowerPoint sur votre ordinateur. Dans le cloud, la lecture d'une page numérisée coûte $0.006 ($0.015 avec la vision).
- **Craft**, sur le site web et dans Aristra Desktop : des documents que vous écrivez avec Aristra ou vous-même, conservés dans votre compte. Consultez [Craft](/fr/craft).
- **La recherche web dans les chats sur le web et sur votre téléphone**. Depuis votre ordinateur, une recherche coûte $0.0075 sur votre solde et, une fois votre solde épuisé, une recherche publique gratuite (Exa, Parallel, Firecrawl ou Keenable) répond, sauf si vous la désactivez.
- **Un crédit de bienvenue de $1**, une seule fois, à la création de votre compte. Il paie les modèles d'Aristra et les outils hébergés : vous pouvez donc discuter sur le web et sur votre téléphone avant de recharger.
- Les pages de votre compte sur le site web : Overview, Profile, Personalization, Billing, Usage, Devices, Downloads, Import and export, Permissions, Agent payments et Cloud computer.

Vous pouvez aussi [recharger votre solde](/fr/account/credits) sans forfait. Il paie les chats sur le web et sur votre téléphone, les modèles d'Aristra et les outils hébergés sur votre ordinateur, ainsi qu'un ordinateur cloud.

## Ce qu'ajoute un forfait

| | Compte gratuit | Avec un forfait |
|---|---|---|
| Sur le web et le téléphone | Chats, projets, fichiers et Craft, avec les chats payés depuis votre solde | Tout : chats, projets, fichiers, Craft |
| Modèles d'Aristra | Tous les modèles, sur votre solde | Tous les modèles, sur votre consommation mensuelle |
| Remote Control et chats partagés | Non | Oui |
| Chats dans le cloud | Oui, payés depuis votre solde | Oui |
| Connecteurs, tâches planifiées dans le cloud, canaux | Non | Oui |
| Ordinateur cloud | Jusqu'à Large, payé par les recharges | Oui, jusqu'à la taille de votre forfait |
| Stockage des fichiers | 1 Go | À partir de 10 Go |
| Documents Craft dans votre compte | Oui | Oui |

Les forfaits, leurs prix et leurs limites sont sur [Forfaits et tarifs](/fr/account/plans).

## Les pages de votre compte

Tous les paramètres de votre compte se trouvent sur ces pages. Ouvrez **Settings** depuis le menu en bas de la barre latérale, ou rendez-vous sur `app.aristralabs.com/account`. Les paramètres propres à un projet (ses instructions et, avec un forfait, ses clés API) se trouvent sur la page du projet.

| Page | Ce qu'elle contient |
|---|---|
| **Overview** | Ce que contient votre compte, et l'accès à chacune de ses parties |
| **Profile** | Votre nom, votre adresse e-mail et l'identifiant de votre compte, et la suppression de votre compte |
| **Personalization** | Le thème et la police, la facilité avec laquelle Aristra agit de lui-même, la mémoire, votre fuseau horaire et votre localisation |
| **Billing** | Votre solde en dollars, la recharge, les forfaits et leur comparaison, votre carte et vos factures sur Stripe |
| **Usage** | Où est passé votre argent, par modèle et par outil, les prix des outils, et la recherche qu'utilise Aristra |
| **Devices** | Tous les ordinateurs connectés à votre compte, et la déconnexion de l'un d'eux |
| **Downloads** | Aristra Desktop et l'Aristra CLI |
| **Import and export** | Les données de votre compte dans un seul fichier, et les sources depuis lesquelles Aristra peut importer |
| **Permissions** | Ce qu'Aristra peut faire dans le cloud avant de vous demander, et les sites auxquels son navigateur cloud reste connecté |
| **Agent payments** | Le portefeuille avec lequel Aristra peut payer quand vous lui demandez d'acheter quelque chose |
| **Connectors** | Avec un forfait : les apps liées à votre compte. La page ouvre **Customize › Connectors** |
| **Cloud computer** | Votre propre machine dans Aristra Cloud, avec un forfait ou avec des recharges : la créer, discuter avec elle, et ses paramètres |
| **Scheduled tasks** | Avec un forfait : les tâches qu'Aristra exécute dans le cloud selon un calendrier (**Scheduled tasks**, dans la barre latérale du site web). Sur votre propre ordinateur, elles sont gratuites |
| **Storage** | Avec un forfait : la part de l'espace de votre compte qu'occupent vos fichiers |
| **Workspace** | Le nom et l'icône de votre espace de travail, ses membres et son journal d'audit. Inviter d'autres personnes nécessite un espace de travail d'équipe, qui n'est pas encore disponible |

Tout le monde peut consulter [Models and prices](https://app.aristralabs.com/models), avec ou sans compte.
