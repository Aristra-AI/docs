Un nouveau compte reçoit aussi un [crédit de bienvenue](/fr/account/credits) de $1, une seule fois. Il paie les modèles et les outils : vous pouvez donc essayer les chats sur le web avant de recharger.

Choisissez ou changez de forfait sur **Billing**, à `app.aristralabs.com/account/billing`. Le paiement passe par Stripe.

## Ce que paie votre consommation

La consommation mensuelle de votre forfait, puis votre [solde rechargé](/fr/account/credits), paient :

- **Les modèles d'Aristra**, selon les tokens qu'utilise un appel, au prix du fournisseur. Le prix de chaque modèle se trouve sur [Models and prices](https://app.aristralabs.com/models).
- **Les outils hébergés** : la recherche Brave, la lecture de pages web, le bac à sable de code et le navigateur cloud, les images, la transcription et la lecture de documents. Consultez [Consommation et prix](/fr/account/usage).
- **Un ordinateur cloud** : le temps pendant lequel il est actif, et son disque, qu'il soit actif ou en veille. Consultez [Ordinateur cloud](/fr/surfaces/cloud-computer).

Un modèle à vous (votre clé, votre forfait ChatGPT, un modèle sur votre ordinateur) ne coûte rien sur Aristra.

<AccordionGroup>
  <Accordion title="Quand ma consommation se renouvelle-t-elle ?">
    À votre date de facturation, chaque mois. La consommation restante n'est pas reportée. Votre solde rechargé est distinct : chaque recharge dure 12 mois et est utilisée une fois la consommation du mois épuisée.
  </Accordion>
  <Accordion title="Que se passe-t-il à zéro ?">
    Aristra s'arrête avant la prochaine étape payante et vous le signale. Un appel déjà en cours se termine et est facturé en entier : votre solde peut donc passer quelques centimes sous zéro ; votre prochain prélèvement, votre prochaine recharge ou le mois suivant couvre d'abord ce montant. [Rechargez](/fr/account/credits) à partir de $10, passez le chat sur un modèle à vous avec `/model`, ou attendez le renouvellement. Avec un forfait, un ordinateur cloud se met en veille et conserve son disque. Sans forfait, quand votre solde rechargé est épuisé, il est arrêté et son disque est conservé 30 jours ; une recharge pendant cette période le fait revenir.
  </Accordion>
  <Accordion title="Que se passe-t-il quand je change de forfait ?">
    Une montée en gamme prend effet immédiatement, et vous recevez la différence entre les consommations mensuelles des deux forfaits, au prorata du temps restant dans la période de facturation. Une descente en gamme prend effet à la fin de la période de facturation. Un ordinateur cloud plus grand que ce qu'autorise le nouveau forfait passe alors à la plus grande taille autorisée ; son disque reste tel quel.
  </Accordion>
  <Accordion title="Pourquoi Billing indique-t-il que tous les forfaits sont pris ?">
    Les forfaits ouvrent par vagues tant qu'Aristra One est récent. Quand une vague est complète, Billing vous le signale avant le paiement, et rien n'est facturé. Votre compte continue de fonctionner tel quel, et d'autres forfaits ouvriront bientôt.
  </Accordion>
  <Accordion title="Y a-t-il une limite à la vitesse à laquelle je peux utiliser ma consommation mensuelle ?">
    Non. C'est un montant unique, sans limite quotidienne ni hebdomadaire.
  </Accordion>
</AccordionGroup>

## Quand vous vous abonnez

Vos ordinateurs suivent le forfait du compte en quelques minutes. Le jour où un forfait démarre :

- **Aristra Desktop propose, une seule fois,** de partager les chats de ce Mac avec votre téléphone et le web, et de laisser les chats dans le cloud lire un dossier de ce Mac. Chaque option est facultative. Plus tard, les mêmes choix se trouvent dans le menu d'un chat (**Continue on phone and web**) et dans le menu d'un dossier (**Use from other devices**).
- **Dans le terminal**, `/remote-control` partage le chat dans lequel vous êtes.

## Après la fin d'un forfait

Votre compte reste, en tant que compte Free, et rien de ce que vous avez créé n'est supprimé.

| | Ce qui se passe |
|---|---|
| Chats | Tous toujours là. Les nouveaux chats sur le web sont payés depuis votre solde |
| Craft | Tout reste là, et vous continuez à écrire, comme chaque compte |
| Fichiers | Tous toujours là, à ouvrir et à télécharger. Au-delà du 1 Go d'un compte Free, les nouveaux fichiers sont refusés jusqu'à ce que vous en supprimiez ; rien n'est supprimé à votre place |
| Mémoire du compte | Toujours à vous sur tous vos appareils, et Aristra continue d'apprendre, comme pour tous les comptes |
| Ordinateur cloud | Continue de fonctionner sur votre solde rechargé, jusqu'à Large (4 Go) ; un ordinateur plus grand passe à Large. Quand il ne reste plus rien, il est arrêté : son disque est conservé 30 jours, et vous recevez un e-mail une semaine avant sa suppression |
| Sites et applications publics | Privés en quelques minutes : vous seul pouvez les ouvrir. Leurs personnes et leurs noms sont conservés ; après le renouvellement, rendez-les de nouveau publics dans **Apps** |
| Tâches planifiées dans le cloud et canaux | En pause. Elles redémarrent quand vous renouvelez |
| Remote Control et vos ordinateurs | Les chats partagés restent lisibles. Suivre des chats, y répondre et en démarrer sur vos ordinateurs depuis le web s'arrête jusqu'à ce que vous renouveliez |
| Connecteurs | Toujours listés. Vous ne pouvez ni les connecter ni les modifier jusqu'à ce que vous renouveliez |
| Clés API de projet | Cessent de fonctionner jusqu'à ce que vous renouveliez |
| Solde rechargé | Toujours à vous. Il paie les chats sur le web ainsi que les modèles et les outils d'Aristra sur votre ordinateur |
| Aristra Desktop et l'Aristra CLI | Continuent de fonctionner avec votre propre modèle |

Renouvelez sur **Billing** pour tout retrouver comme avant.
