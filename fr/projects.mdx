Un projet regroupe un travail : ses chats, ses fichiers, ses instructions et ce qu'Aristra apprend à son sujet. Les chats que vous démarrez dans un projet utilisent les fichiers, les instructions et la mémoire du projet. Chaque compte a des projets : 3 avec Free, 5 avec Plus, 20 avec Pro et 40 avec Max. La page Projects indique combien il vous en reste.

## Créer un projet

Sur le site web, ouvrez **Projects** et choisissez **New project**. Indiquez ce sur quoi vous travaillez, et ajoutez une description si vous le souhaitez. Un nouveau projet est épinglé dans la barre latérale. Les projets se créent sur le site web ; Aristra Desktop et le terminal utilisent ceux que vous avez.

## La page d'un projet

| | |
|---|---|
| **New chat** | Un chat dans le projet |
| **Chats** | Les chats du projet |
| **Files** | Vos [Files](/fr/files), filtrés sur ceux de ce projet |
| **Craft** | Avec un forfait, les documents [Craft](/fr/craft) du projet |
| **Folders on your Macs** | Les dossiers dans lesquels ce projet travaille sur chaque Mac, avec le dossier principal signalé. Un nouveau chat du projet sur ce Mac démarre dans son dossier principal ; les fichiers restent sur le Mac |
| **Pin** | Le garder dans la barre latérale, ou l'en retirer |

À côté des chats se trouvent les paramètres du projet :

- **Instructions** : jusqu'à 4 000 caractères que chaque chat du projet suit : à qui il s'adresse, comment écrire, quoi vérifier.
- **API keys** : avec un forfait, des clés pour utiliser le projet depuis votre propre code.

Le menu du projet contient **Edit details…** (son nom, sa description et les dépôts dans lesquels travaille Aristra Desktop) et **Delete project…**.

## Les projets dans Aristra Desktop et le terminal

- Dans Aristra Desktop, une fois connecté, un nouveau chat propose un sélecteur **Project**. Un chat de projet s'exécute dans le cloud, avec les instructions et la mémoire du projet, et dans l'onglet Code il démarre dans le dossier principal du projet quand celui-ci en a un sur ce Mac. Le sélecteur apparaît dès que vous avez un projet.
- Dans l'onglet Code d'Aristra Desktop, choisissez un projet et un dossier pour un nouveau chat, puis **Make it Launch's main folder** (pour un projet nommé Launch) sous la zone de message.
- Dans le terminal, `aristra --cloud --project <name>` démarre un chat cloud dans un projet. Consultez [Chats cloud](/fr/code/cloud-chats).

## La mémoire dans un projet

Ce qu'Aristra apprend pendant que vous travaillez dans un projet est conservé dans votre mémoire avec le nom du projet, et l'onglet **Pages** de [Mémoire](/fr/memory) le regroupe par projet.
