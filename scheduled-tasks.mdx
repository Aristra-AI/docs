A scheduled task is work Aristra runs for you in the cloud, at set times or when something happens, while your computer is off: a morning summary of your inbox, a weekly report, a reply drafted when an email arrives. Scheduled tasks in the cloud come with a [plan](/account/plans), and each run is paid from your balance like a chat.

Tasks can also run on your own computer, for free, in a folder: see [Background work](/code/guides/background#scheduled-tasks). And a [cloud computer](/surfaces/cloud-computer) can keep its own tasks.

## Make a task

- **On the website:** **Scheduled tasks** in the sidebar, then **Add**: **On a schedule** or **When something happens**.
- **In a chat:** ask in plain words ("every weekday at 8, summarize my unread email") and approve the task Aristra shows you.
- **In Aristra Desktop:** the task form, with **In the cloud** chosen.

A task on a schedule has a title, a schedule (once, hourly, daily, weekdays or weekly, in your time zone) and a prompt. Under the advanced options:

| Option | What it does |
|---|---|
| **Project** | The project whose files, instructions and memory the task uses. Without one, it knows only your profile |
| **Connectors** | The connected apps it may use |
| **Updates** | Where results go: the website's notifications, email or Telegram |
| **Run limit** | Run until you stop it, or a number of times |
| **Runs on** | Aristra's cloud agent, or your cloud computer if you have one |
| **Auto-retry** | How many times a failed run is tried again |
| **Validation** | What a run must meet to count as done |

## When something happens

A task can start when something happens in a connected app (a new email in Gmail, a message in Slack, a payment in Stripe, a new issue in GitHub, and more), or when another task finishes. It then runs Aristra with your prompt, or a fixed list of app actions with no AI. Connect the app first; see [Connectors](/connectors).

## Runs

- Each task has one chat, and each run is added to it. **View this run in chat** opens it.
- A run works on its own, in Auto mode. A step that needs your approval waits on its card in the task's chat, and you are told.
- A run with nothing new to report says so quietly: it is kept, and nothing is sent to you.
- A run can start up to about two minutes after its time.

## When a run fails

Before each run, Aristra checks your plan, then your balance. A run that could not start or that failed tells you, where the task's updates go, with the reason.

After three failures in a row, the task stops, and the third notice says so: it is paused when your balance or plan was the cause, and turned off otherwise. Turn it back on under **Scheduled tasks** once the cause is fixed. After a plan ends, each run is refused with a notice until the task is paused.
