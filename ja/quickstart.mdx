このガイドでは、アカウントの作成から最初のチャット、さらに Mac とスマートフォンで Aristra を使うところまでを説明します。どの方法でのサインイン手順も[サインイン](/ja/quickstart)にあります。ターミナルでのコーディングから始める場合は、[Aristra Code のクイックスタート](/ja/code/quickstart)を参照してください。

<Steps>
  <Step title="アカウントを作成する">
    [app.aristralabs.com](https://app.aristralabs.com) を開き、**Sign up** を選択します。

    - **Aristra を段階的に公開している間**は、ページに **Join the waitlist** が表示されます（すべての枠が埋まっている場合は **We are full for now**）。メールアドレスを入力して **Join waitlist** を選択します。順番が来ると Aristra からメールが届きます。それまでは何もする必要はありません。
    - **招待リンクがある場合**は、招待メールのリンクを開きます。フォームに直接移動し、メールアドレスは招待から自動で入力されます。
    - **登録の受付が始まっている場合**は、ページに **Create your account** が表示されます。

    **Create your account** で、名前（任意）、メールアドレス、8 文字以上のパスワード、確認用のパスワードを入力し、**Create account** を選択します。次に、Aristra からメールで届いたコードを入力し（招待リンクの場合は不要です）、もう一度 **Create account** を選択します。**Send a new code** を選択すると、コードを再送できます。

    新しいアカウントは無料で、Aristra のモデルとツールに使える $1 のクレジットが付いてきます。このクレジットはメールアドレスごとに 1 回だけです。
  </Step>

  <Step title="Aristra に自己紹介する">
    続いて短い画面がいくつか表示されます。ウェルカム画面、利用目的（文章作成、リサーチ、日々の段取り、ワークフローの構築）、名前とスペース、メモリに関する任意のステップです。名前と **About you** のメモは、あとからアカウントの **Profile** ページで変更できます。Aristra の話し方を変えたいときは、チャットでそう伝えてください。
  </Step>

  <Step title="チャットを始める">
    新しいチャットの画面には、メッセージ欄の上に **Runs on Aristra Cloud**、最初のプロンプトの候補がいくつか、そしてメッセージ欄の下に使える残高が表示されます。やりたいことを入力して Enter キーを押します。

    - **モデルはピッカーで選びます**。既定には **Auto** がおすすめです。どのアカウントでもすべてのモデルを使え、それぞれのモデルにコストの目安が表示されます。
    - **ファイルを添付する**には **+** を使います。PDF、Word、Excel、PowerPoint のファイル、画像、テキスト、コードを、1 メッセージあたり 5 ファイル、50 MB まで添付できます。
    - **メッセージごとに残高から支払われます**。最初にスタータークレジット、次にプランの毎月の利用枠またはチャージした残高が使われます。[残高とチャージ](/ja/account/credits)を参照してください。

    Aristra はウェブを検索し、ファイルを読み、コードを実行してファイルやグラフを作り、大切なことを覚えておきます。[チャット](/ja/chats)を参照してください。
  </Step>

  <Step title="Mac で Aristra を使う">
    アカウントの **Downloads** ページを開き、**Download for Mac** を選択します（Apple シリコンと Intel に対応）。Aristra Desktop を開いて **Sign in** を選択します。手順は[サインイン](/ja/quickstart)の **Aristra Desktop** タブにあります。

    アプリには 2 つのタブがあります。**Chat** にはウェブサイトと同じチャットがあります。**Code** は Aristra Code で、Mac 上のフォルダーで作業するためのものです。[Aristra Desktop](/ja/surfaces/desktop) を参照してください。

    Mac では、ChatGPT のプラン、自分の API キー、Ollama などコンピューター上のモデルでも Aristra を動かせます。[自分のモデルを使う](/ja/own-models)を参照してください。
  </Step>

  <Step title="スマートフォンで使う">
    スマートフォンのブラウザーで app.aristralabs.com を開いてサインインします。ホーム画面に追加すると、アプリのように開けます。
  </Step>
</Steps>

## サインイン

Aristra のアカウントはどこでも同じです。ウェブサイトとスマートフォンでは、メールアドレスでサインインします。Aristra Desktop、ターミナル、エディターでは、**コンピューター単位で**サインインします。まずそのコンピューターでサインインを始め、次にウェブサイトで承認します。承認は、そのブラウザーでも、サインイン済みの別のスマートフォンやコンピューターでもかまいません。

1 台のコンピューター上の Aristra Desktop、ターミナル、エディターは、1 つのサインインを共有します。そのコンピューターで一度サインインすれば、すべてがサインイン済みになります。

<Tabs>
  <Tab title="ウェブサイト">
    **パスワードでサインインする**

    1. [app.aristralabs.com](https://app.aristralabs.com) を開きます。ページに **Welcome back** が表示されます。
    2. **Email** と **Password** を入力します。
    3. **Sign in** を選択します。

    **メールで届くコードでサインインする**

    1. **Welcome back** で **Email** を入力します。パスワードは空のままにします。
    2. **Or continue with** の下にある **Email me a sign-in code** を選択します。
    3. **Check your email** で、メールに記載された **Code** を入力し、**Continue** を選択します。

    **パスワードを忘れた場合**

    1. **Welcome back** で **Forgot your password?** を選択します。
    2. **Email** を入力して **Send reset code** を選択します。
    3. メールに記載された **Code** と **New password** を入力し、**Reset password** を選択します。これでサインインも完了します。

    新しいブラウザーでサインインすると、パスワードのあとに、同じ **Check your email** 画面でメールに届くコードを求められることがあります。
  </Tab>

  <Tab title="Aristra Desktop">
    Aristra Desktop は、サインインするまで **Sign in to Aristra** 画面で開きます。まだアカウントがない場合は、**Create an account** を選択するとブラウザーで登録ページが開きます。

    **ブラウザーでサインインする**

    1. **Sign in** を選択します。ブラウザーで Aristra の **Authorize Aristra Desktop** ページが開きます。そのブラウザーでウェブサイトにサインインしていない場合は、先にサインインしてください。サインインすると元のページに戻ります。
    2. **Computer** と **Account** の行を確認します。この Mac の名前と、Mac を追加するアカウントが表示されています。
    3. **Approve** を選択します。ページに **Computer connected** と表示され、アプリは自動的に次へ進みます。タブは閉じてかまいません。

    ページが開かなかった場合は、アプリで **Open the page again** を選択します。

    **別のデバイスでコードを使ってサインインする**

    この Mac のブラウザーでサインインを完了できない場合や、スマートフォンで承認したい場合に使います。

    1. **Sign in** を選択し、続けて **Use a code instead** を選択します。アプリに `BCDF-GHJK` のような 8 文字のコードと **Copy** が表示されます。
    2. 任意のスマートフォンかコンピューターで **app.aristralabs.com/desktop/device** を開き、求められたらサインインします。アプリで **Open the page** を選択すると、コードが入力された状態でこの Mac 上にページが開きます。
    3. コードを入力して **Continue** を選択します。
    4. コードと **Computer** がこの Mac と一致していることを確認し、**Approve** を選択します。アプリは自動的に次へ進みます。

    コードの有効期間は 10 分です。期限が切れたら、もう一度 **Sign in** を選択して新しいコードを取得します。
  </Tab>

  <Tab title="ターミナル">
    まず Aristra Code をインストールします。[Aristra Code のクイックスタート](/ja/code/quickstart)を参照してください。サインアウトした状態で初めて `aristra` を実行すると、サインインを求められます。いつでも次のコマンドでサインインできます。

    ```sh
    aristra login
    ```

    **ブラウザーでサインインする**

    1. **In your browser**（ブラウザーのあるコンピューターでは最初の選択肢）を選択するか、`aristra login` を実行します。
    2. ブラウザーで Aristra の **Authorize Aristra Code** ページが開きます。開かない場合は、ターミナルに表示されたリンクを開きます。
    3. **Computer** と **Account** の行を確認し、**Approve** を選択します。
    4. ターミナルに **Signed in as** とメールアドレスが表示されます。

    **別のデバイスでコードを使ってサインインする**

    1. **With a code, on another device** を選択するか、`aristra login --device-code` を実行します。ブラウザーでのサインインを待っている間に **c** を押して、コードに切り替えることもできます。
    2. ターミナルに「Go to https://app.aristralabs.com/desktop/device and enter the code `BCDF-GHJK`」と表示されます（コードは人によって異なります）。
    3. 任意のスマートフォンかコンピューターでそのページを開き、求められたらサインインしてから、コードを入力して **Continue** を選択します。
    4. コードと **Computer** が一致していることを確認し、**Approve** を選択します。

    **SSH 経由、または別のマシンでサインインする**

    SSH 経由や、ディスプレイのない Linux では、そのコンピューターにブラウザーがないため、最初からコードを使います。`aristra --remote <host>` を使う場合、相手のマシンはそれ自体が 1 台のコンピューターとしてサインインします。そのマシンで **With a code, on another device** を選択するか `/login code` と入力して、コードでサインインしてください（`aristra --remote <host> login` では常にコードを使います）。

    **チャットの中でサインインする**

    `/login` でサインイン、`/login code` でコードを使ってサインイン、`/logout` でサインアウトします。`aristra status` を実行すると、このコンピューターがどのアカウントにサインインしているかを確認できます。

    **スクリプトと CI**

    `aristra setup-token` を実行すると、1 年間有効なトークンが表示されます。スクリプトを実行する環境で、これを `ARISTRA_TOKEN` に設定します。トークンはデバイスの一覧に独立した項目として表示され、そこで取り消せます。
  </Tab>

  <Tab title="エディター">
    Zed をはじめ、Agent Client Protocol に対応したエディターは、`aristra acp` で Aristra Code を実行します。まずエディターに追加してください。[エディター](/ja/code/editors)を参照してください。

    1. エディターのエージェントパネルで Aristra のスレッドを開始します。このコンピューターがまだサインインしていない場合は、エディターからサインインを求められます。
    2. **Sign in to Aristra** を選択します。ブラウザーで **Authorize Aristra** ページが開きます。
    3. **Computer** と **Account** の行を確認し、**Approve** を選択します。エディターでの作業が続行されます。

    サインインの待ち時間は 5 分です。このコンピューターの Aristra Desktop かターミナルがすでにサインインしていれば、エディターもサインイン済みなので、何もする必要はありません。
  </Tab>

  <Tab title="スマートフォン">
    1. スマートフォンのブラウザーで [app.aristralabs.com](https://app.aristralabs.com) を開きます。
    2. ウェブサイトと同じように、パスワードかメールで届くコードでサインインします。
    3. 任意：ページをホーム画面に追加すると、Aristra をアプリのように開けます。

    スマートフォンは、コンピューターを承認する場所としても便利です。**app.aristralabs.com/desktop/device** を開き、コンピューターに表示されたコードを入力します。
  </Tab>
</Tabs>

### コンピューターを承認する

承認ページには、**Application**（**Aristra Desktop**、**Aristra Code in a terminal**、エディターの場合は **Aristra** のみ）、**Computer**、そしてコンピューターを追加する **Account** が表示されます。コンピューターは、ウェブサイトでサインインしているアカウントに追加されます。**Approve** を選択する前に、**Account** の行を確認してください。

承認するのは、自分自身がたった今始めたサインインだけにしてください。Aristra がコードの承認を求めることはありません。**Deny** を選択すると何も接続されず、そのコンピューターでのサインインは自動的に期限切れになります。

サインインしたコンピューターは、使っている間はサインインしたままです。30 日間使われなかったコンピューターでは、もう一度サインインを求められます。1 つのアカウントで同時にサインインできるのは、コンピューターとスクリプト用トークンを合わせて 20 個までです。サインインの期限が切れたものは数に含まれません。

### サインアウト

| サインアウトする対象 | 方法 |
|---|---|
| このブラウザーのウェブサイト | サイドバー下部の自分の名前を選択し、**Log out** を選択します。コンピューターはサインインしたままです |
| この Mac | Aristra Desktop でアカウントメニュー（左下の自分の名前）を開き、**Sign out** を選択します。この Mac とそのターミナルで実行中のチャットは停止します |
| このコンピューター（ターミナル） | 実行中のチャットを先に停止してから、`aristra logout` を実行するか、チャットで `/logout` と入力します。このコンピューターの Aristra Desktop もサインアウトします |
| 別のコンピューター | ウェブサイトで **Settings › Devices** を開き、そのコンピューターの横にある **Sign out** を選択します。チャットとファイルはそのコンピューターに残ります。クラウドコンピューターは、代わりに **Manage** から停止または削除します |
| すべてのコンピューター | Aristra Desktop で **Settings › Account › Sign out all** を選択します。この Mac を含むすべてのコンピューターとスクリプト用トークンがサインアウトします。クラウドコンピューターとウェブのセッションはそのままです |
| ChatGPT のプラン | ターミナルで `aristra logout chatgpt` を実行する（チャットでは `/logout chatgpt`）か、Aristra Desktop の **Settings › Models** にある **ChatGPT plan** で **Sign out** を選択します。Aristra はサインインしたままです |

Aristra からサインアウトしても、そのコンピューターの ChatGPT のサインインと API キーは残ります。コンピューター上のチャットは、同じアカウントで再びサインインすると、また表示されます。

### サインインできない場合

<AccordionGroup>
  <Accordion title="The sign-in expired">
    ブラウザーでのサインインは 5 分、コードは 10 分で期限が切れます。コンピューターでサインインをやり直して（Aristra Desktop では **Sign in**、ターミナルでは `aristra login`）、新しいページかコードを取得してください。
  </Accordion>
  <Accordion title="コードが受け付けられない">
    1 文字ずつ確認してください。コードには子音しか使われないため、0 や 1 と紛らわしい O や I はありません。ダッシュは入れても入れなくてもかまいません。10 分間にコードの確認が 10 回に達した場合（**Continue** と **Approve** はそれぞれ 1 回と数えます）は、数分待ってからサインインをやり直してください。
  </Accordion>
  <Accordion title="ブラウザーのページがコンピューターに届かない">
    ブラウザーが別のデバイスにあるか、このコンピューターに接続できない可能性があります。コードに切り替えてください。Aristra Desktop では **Use a code instead**、ターミナルでは待機中に **c**、チャットでは `/login code` を使います。
  </Accordion>
  <Accordion title="Revoke an existing device before connecting another">
    アカウントにサインインしているコンピューターとスクリプト用トークンが 20 個に達しています。ウェブサイトの **Settings › Devices** で、使わなくなったものをサインアウトしてから、もう一度サインインしてください。
  </Accordion>
  <Accordion title="Your account is on the waitlist">
    Aristra は少しずつ利用者を受け入れています。順番が来たら（Aristra からメールが届きます）、コンピューターでサインインをやり直してください。
  </Accordion>
  <Accordion title="Sign out of the current Aristra account before signing in to another">
    1 台のコンピューターがサインインできる Aristra アカウントは一度に 1 つです。先にそのコンピューターでサインアウトしてから、別のアカウントでサインインしてください。別のアカウントで承認したい場合は、先にそのブラウザーでウェブサイトからサインアウトしてください。
  </Accordion>
</AccordionGroup>
