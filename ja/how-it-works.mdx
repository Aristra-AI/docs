## アカウント

Aristra のアカウントには、どこにでも付いてくるものが保存されています。クラウドのチャット、[メモリ](/ja/memory)、[ファイル](/ja/files)、[プロジェクト](/ja/projects)、[Craft](/ja/craft) のドキュメント、[接続したアプリ](/ja/connectors)、そして残高とプランです。サインインしたどのサーフェスからも、同じアカウントにアクセスします。

## チャットが実行される場所

チャットは次の 3 か所のいずれかで実行されます。

| | Aristra Cloud | 自分のコンピューター | 自分のクラウドコンピューター |
|---|---|---|---|
| 実行するもの | Aristra のクラウドエージェント | Mac または Linux マシン上の Aristra Runtime | Aristra のクラウドにある自分専用のコンピューター上の Aristra Runtime |
| 開始する場所 | ウェブサイト、スマートフォン、Aristra Desktop（Chat タブと、クラウドで実行するよう設定した Code タブのチャット）、`aristra --cloud` を付けたターミナル、プランがあれば Telegram とスケジュールタスク | ターミナル、Aristra Desktop の Code タブ（On this Mac）、エディター | ウェブサイト上のそのコンピューターのページ、Telegram、そのコンピューター自身のスケジュールタスク |
| 作業の対象 | 専用のサンドボックス、ウェブ、アカウントのファイル、接続したアプリ | 自分のフォルダー、シェル、ツール | そのコンピューター自身のディスク、シェル、ツール |
| モデル | Aristra のモデル | どれでも可。Aristra のモデル、自分のキー、ChatGPT のプラン、コンピューター上のモデル | Aristra のモデル、または ChatGPT のプラン |
| 支払い | 残高 | Aristra のモデルは残高から。自分のモデルなら無料 | プランの毎月の利用枠かチャージした残高（スタータークレジットは使えません）。モデル、起動している時間、ディスク（起動中もスリープ中も）が対象です |
| 保存先 | アカウント | コンピューター上（`~/.aristra`） | アカウント。選択すればそのコンピューター自身のディスク |

Aristra Cloud のチャットは、どのサーフェスでも同じチャットです。ウェブで始めたチャットは、Aristra Desktop の Chat タブにも、ターミナルの[クラウドチャット](/ja/code/cloud-chats)にも表示されます。

コンピューター上のチャットは、そのコンピューターにとどまります。プランがあれば、[Remote Control](/ja/code/remote-control) でウェブとスマートフォンに共有でき、作業はコンピューター上で続きます。

## Aristra Code

[Aristra Code](/ja/surfaces/aristra-code) は、コンピューター上のフォルダーで作業する Aristra です。ファイルを読んで編集し、コマンドを実行し、git を扱います。許可していない操作の前には確認を求めます。ターミナル、Aristra Desktop の Code タブ、エディターはすべて、コンピューター上の同じランタイムとやり取りするため、どこかで始めたチャットは他の場所にも表示されます。詳しくは [Aristra Code のしくみ](/ja/code/how-it-works)を参照してください。

## 付いてくるもの、とどまるもの

- **メモリ**はアカウントに保存され、オフにしない限り、どのサーフェスでも、サインインして始めたすべてのチャットに反映されます。[メモリ](/ja/memory)を参照してください。
- **プロフィール**（名前、職業、**About you**）は、Memory のスイッチの状態にかかわらず、サインインして始めたすべてのチャットの最初に使われます。例外は、Memory がオフのときのシークレットチャットと、メモリを自身のディスクに保存するクラウドコンピューターです。他の人が参加しているチャットでは、名前と職業だけが使われます。
- アカウントの**ファイル**は、ウェブサイト、Aristra Desktop、ターミナルの `/files` に表示されます。Mac 上のファイルがアカウントに入るのは、アカウントに保存したときだけです。[ファイル](/ja/files)を参照してください。
- **コンピューター上のチャット**は、Remote Control で共有しない限りアカウントには入りません。そのため、Aristra が毎晩チャットから学習するときにも読まれません。

## 支払い

Aristra のモデルとホスト型ツールの料金は残高から支払われます。最初に新規アカウントの $1 のスタータークレジット、次にプランの毎月の利用枠、その次にチャージした残高が使われます。自分のモデル（[自分のモデルを使う](/ja/own-models)）には、Aristra での料金はかかりません。[残高とチャージ](/ja/account/credits)を参照してください。
