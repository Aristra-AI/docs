Aristra は、あなた自身のこと、作業の進め方の好み、取り組んでいることを伝えると覚えておくので、同じことを繰り返し伝える必要はありません。メモリはアカウントに保存されるため、ウェブ、スマートフォン、Aristra Desktop、ターミナルのチャットに反映されます。プランの有無にかかわらず、すべてのアカウントで使え、料金もかかりません。メモリを使うチャットで支払うのは、そのチャット自体のトークン分だけです。

## プロフィール

アカウントの **Profile** ページにある名前、職業、**About you** のメモは、Memory のスイッチの状態にかかわらず、すべてのチャットの最初に使われます。ただし、Memory がオフのときのシークレットチャットは例外です。他の人が参加しているチャットでは、名前と職業だけが使われます。これらはあなたが入力したものなので、Aristra が学習したものではなく、設定として扱われます。

## チャット中に保存されるもの

残しておく価値のあること（訂正、長く続く好み、あなたに関する事実、決めたこと、「これを覚えておいて」という依頼）を伝えると、Aristra はすぐに保存し、チャットでそのことを知らせます。訂正したり依頼したりすると、メモリを更新または削除します。キーやパスワードなどの秘密情報は決して保存せず、センシティブな情報は依頼したときだけ保存します。また、ウェブページやファイルから保存するよう指示された内容は保存しません。他の人が参加しているチャットでは、メモリは書き込まれません。

自分から頼むこともできます。たとえば「短い回答が好みだと覚えておいて」「勤務先のことは忘れて」のように伝えます。

## 過去のチャットからの学習

Aristra は毎晩、前回確認してから以降のアカウント内のチャットを読み、あとで役立つことを残します。あなたに関する事実、好みの回答のしかた、決めたことや計画などです。1 晩に保存する新規または更新のメモリは最大 15 件です。それぞれにはあなたの発言が引用され、元になったチャットの名前が示されます。新しいメモリが、内容の変わった古いメモリを置き換えることもあります。

また、すべてのチャットの最初に使われるあなたの要約も書き直します。要約には、取り組んでいること、未完了の事柄、最近決めたことや話題が含まれます。

- 最初の晩は、直近 30 日分を読みます。
- **Memory** と **Search and reference past chats** の両方がオンである必要があり、どちらかがオフの間は何も読みません。両方がオンに戻ると、その期間のチャットも読みます。
- シークレットチャット、他の人が参加しているチャット、スケジュールタスク自体のチャット、削除したチャット、Memory がオフの状態で始めたチャットは読みません。コンピューターにだけ保存されているチャットはアカウントにないため、これも読みません。
- チャットは、読み取りのために Anthropic のバッチサービスに送られます。Aristra は、結果を保存した時点でその晩のバッチを Anthropic 側から削除します。Anthropic がバッチを 29 日より長く保持することはありません。料金はかかりません。

## メモリをオフにする

アカウントには 2 つのスイッチがあります。ウェブサイトでは **Personalization** の下、Aristra Desktop では **Settings › Memory** の下にあります。

- **Memory**：オフの間は、何も使われず、何も保存されません。オンに戻すと、履歴に残っているチャットから学習することがあります。
- **Search and reference past chats**：Memory がオンのとき、Aristra が以前のチャットを検索し、役立つときに参照できるようにします。Memory がオフの間は、ChatGPT と同じようにオフと表示され、Memory をオンにすると元の状態に戻ります。

チャットには、開始時の Memory のスイッチの状態が記録されます。Memory をオフにすると、すべてのチャットに即座に反映されます。オンに戻した場合は、そのあとで始めたチャットに反映されます。

## シークレットチャット

シークレットチャットが学習に使われることはなく、メモリにも何も保存されません。ウェブと Aristra Desktop の Chat タブでは、Aristra がすでに覚えていることは使えます。ターミナルでは、`aristra --cloud --incognito` で Aristra Cloud のシークレットチャットを始められ、同じように動作します。[Aristra Code](/ja/code/guides/memory) がコンピューター上で実行するチャットには、シークレットモードはありません。[チャット](/ja/chats)を参照してください。

## メモリを読む、変更する

ウェブサイトのサイドバーで **Memory** を開きます（Aristra Desktop では **Settings › Memory › See and edit your memory**）。

| タブ | 内容 |
|---|---|
| **Summary** | すべてのチャットの最初に使われる、あなたの要約。編集できます |
| **Memories** | Aristra が覚えているすべてのこと。上部の **Learned from your chats** には、毎晩学習した内容が、元のチャットへのリンクと **Forget** とともに一覧表示されます |
| **Pages** | プロジェクト、リポジトリ、フォルダー、トピックごとにまとめたメモリ |
| **Profile** | プロフィール |

## インポート

Memory ページの **Import** を使うと、別のアシスタントが覚えているあなたのことを取り込めます。ChatGPT、Claude などのアシスタントに貼り付けるプロンプトが表示されるので、その回答を貼り付けるかアップロードします。1 日に取り込めるのは、その日に Aristra が保存した分も含めて 500 件までです。インポートしたメモリは、翌晩に要約に反映されます。

Aristra Desktop の **Settings › Memory** では、Mac 上で Codex と Claude Code が覚えている内容をインポートしたり、メモリのコピーを `~/Aristra/memory` にファイルとして保存したりもできます。

## Aristra Code のメモリ

Aristra Code は同じアカウントのメモリを使い、さらにリポジトリごとのメモを残し、`AGENTS.md` ファイルを読みます。[指示とメモリ](/ja/code/guides/memory)を参照してください。
