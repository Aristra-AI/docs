[app.aristralabs.com](https://app.aristralabs.com) は、コンピューターでもスマートフォンでも、どのブラウザーからでも使える Aristra です。ここでのチャットは Aristra のクラウドエージェントで実行され、アカウントに保存されます。そのため、Aristra Desktop の Chat タブやターミナルの[クラウドチャット](/ja/code/cloud-chats)と同じチャットになります。

## サイドバーの項目

| | 用途 | |
|---|---|---|
| **Chats** | Aristra のどのモデルでも使える[チャット](/ja/chats)。料金は残高から支払われます | すべてのアカウント |
| **Projects** | [プロジェクト](/ja/projects)。1 つの作業のチャット、ファイル、指示、メモリ | すべてのアカウント |
| **Files** | アカウントに保存された[ファイル](/ja/files) | すべてのアカウント |
| **Memory** | Aristra が覚えているあなたのこと。[メモリ](/ja/memory)を参照してください | すべてのアカウント |
| **Craft** | [Craft](/ja/craft) のドキュメント | プランが必要 |
| **Scheduled tasks** | クラウドの[スケジュールタスク](/ja/scheduled-tasks) | プランが必要 |
| **Customize** | [コネクター](/ja/connectors)、スキル、チャネル（[Telegram](/ja/surfaces/telegram)）、MCP | プランが必要 |
| **Cloud computer** | 自分の[クラウドコンピューター](/ja/surfaces/cloud-computer) | プランかチャージした残高が必要 |

プランがない場合、プランが必要な項目はサイドバーに表示されません。リンクからそれらのページを開くと、プランで追加されるものが表示されます。プランが終了しても項目は残り、読み取りとエクスポートができます。残高がなくなると、メッセージ欄にその旨が表示され、チャージかプランへの加入を案内されます。

## アカウント

サイドバー下部のメニューにある **Settings** を選択すると、アカウントのページが開きます。プロフィール、パーソナライズとメモリのスイッチ、請求、使用量、デバイス、ダウンロード、エクスポートがあります。[アカウントと Aristra One](/ja/account/overview) を参照してください。

## 自分のコンピューター

新しいチャットの下にある **Runs on Aristra Cloud** には、クラウドコンピューターと、アカウントにサインインしているすべてのコンピューターが一覧表示されます。プランがあれば、コンピューターを選んで次のことができます。

- Aristra Desktop やターミナルから共有した**チャットを追いかけて応答する**。承認にも応答できます。[Remote Control](/ja/code/remote-control) を参照してください。
- そのコンピューターが許可しているフォルダーで、**コンピューター上のチャットを始める**。この機能は、そのコンピューターでオンにするまではオフです。[ウェブやスマートフォンからコンピューター上のチャットを始める](/ja/code/remote-control)を参照してください。

チャットはそのコンピューター上で、そのファイルとツールを使い、Aristra のモデルのいずれかで実行されます。料金はプランの毎月の利用枠から、その次にチャージした残高から支払われます。

## スマートフォンの場合

スマートフォンのブラウザーで app.aristralabs.com を開いてサインインします。ホーム画面に追加すると、アプリのように開けます。コンピューター上のチャットの承認への応答も含め、ここまで説明したことはすべてスマートフォンで使えます。

## ワークスペース

アカウントには個人用のワークスペースがあります。他の人を招待するにはチームワークスペースが必要ですが、まだ提供されていません。
