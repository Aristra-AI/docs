[プラン](/ja/account/plans)があれば、Telegram から Aristra にメッセージを送れます。メモリ、ファイル、接続したアプリを備えた同じ Aristra で、返信の料金は他のチャットと同じように残高から支払われます。

## Telegram を接続する

1. ウェブサイトで **Customize › Channels** を開き、Telegram の **Connect** を選択します。
2. **Open in Telegram** を選択するか、スマートフォンで QR コードをスキャンし、Telegram で **Start** を押します。リンクは 1 回限りで、有効期間は 5 分です。

同じカードの **Disconnect** を選択すると、Aristra は Telegram で応答しなくなります。

## Telegram のチャット

Aristra との Telegram の個人チャットは、アカウント内の **Aristra** という名前の 1 つのチャットとして続いていきます。このチャットはウェブサイトのサイドバーには表示されず、**Chats** に一覧表示されます。`/new` を送ると別のチャットが始まり、Telegram からのチャットという印付きでサイドバーに表示されます。`/home` を送ると元のチャットに戻ります（`/home` は個人チャット用で、グループでは使えません）。Telegram のグループには、それぞれ専用のチャットが作られます。

Aristra は、送られたボイスメッセージを読み取ります。

| コマンド | |
|---|---|
| `/new` | 新しいチャットを始める |
| `/home` | メインのチャットに戻る |
| `/model` | モデルを選ぶ |
| `/think` | 推論の設定。オフ（高速）、low、medium、high |
| `/switch` | このチャットのプロジェクトを選ぶ |
| `/continue` | 上限に達して一時停止した返信を再開する |
| `/settings` | ワークスペースとプロジェクト |
| `/stop` | 実行中の返信を停止する |
| `/help` | コマンドの一覧 |

## クラウドコンピューターに送る

[クラウドコンピューター](/ja/surfaces/cloud-computer)がある場合は、そのページで **Telegram messages go to this computer** をオンにします。すると、Telegram の個人チャットがクラウドコンピューター上で実行されるようになり、スリープ中なら起動します。`/new` を送ると、そこで新しいチャットを始められます。承認にはウェブサイトで応答します。

## その他のアプリ

WhatsApp、Slack、Discord は、**Channels** に近日提供予定として表示されています。現在使えるのは Telegram だけです。
