Aristra Desktop は Mac 用（Apple シリコンと Intel）の Aristra アプリです。アカウントの **Downloads** ページからダウンロードし、ブラウザーかコードでサインインします。サイドバーには 2 つのタブがあります。

- **Chat**：フォルダーを使わない[チャット](/ja/chats)と、ファイル、Craft。これらのチャットは Aristra Cloud で実行され（この Mac に保存したドキュメントの横で開くチャットは、この Mac で実行されます）、アカウントに保存されます。そのため、ウェブサイトやスマートフォンと同じチャットになります。料金は[残高](/ja/account/credits)から支払われ、新規アカウントのスタータークレジット、プランの毎月の利用枠、その次にチャージした残高の順に使われます。
- **Code**：[Aristra Code](/ja/code/desktop)。フォルダーとそのチャット、そしてコーディング中にチャットの横で使うものすべてがあります。

サイドバー上部のスイッチか、**⌥⌘←** と **⌥⌘→** でタブを切り替えます。表示していないほうのタブには、そのタブのチャットが応答を待っているとき（琥珀色）や作業中のとき（緑）、または Code タブに未読のスケジュール実行があるとき（アクセントカラー）に、ドットが表示されます。検索、通知、Dock のどこからチャットを開いても、そのチャットのタブに移動します。

Aristra Desktop には Aristra Code が含まれているため、Aristra CLI を別途インストールする必要はありません。どちらも同じランタイムと同じ `~/.aristra` フォルダーを使います。ターミナルで始めたチャットは Code タブに表示され、その逆も同じです。

## チャットを始める

Chat タブの新しいチャットはクラウドで実行されるため、サインインが必要です。新しいチャットでは次のものを使えます。

- **Project**：[プロジェクト](/ja/projects)。チャットはその指示とメモリを使います。
- **Incognito**（新しいチャットの右上にあるゴーストアイコン）：履歴にもメモリにも残らず、この Mac にも何も保存されないチャット。[シークレットチャット](/ja/chats)を参照してください。
- **マイク**ボタン：最大 10 分の音声入力ができ、文字に起こして入力してくれます。料金は残高から支払われます。

**クイック入力**（どこからでも **⌥Space**、または **Aristra › Quick Entry**）を使うと、小さな入力欄が開きます。入力して Enter キーを押すと、ウィンドウを開かずにチャットを始められます。

## ファイルと Craft

**Files** には、この Mac 上のチャットで共有、作成、変更されたファイルと、サインインしていればアカウントのファイルが一覧表示されます。[ファイル](/ja/files)を参照してください。

**Craft** には、Aristra と一緒に、または自分で書いたドキュメントが保存されます。ドキュメントはアカウントに保存されます。Aristra Desktop がアカウントに接続できないときに作成したドキュメントは、移すまでこの Mac に保存されます。[Craft](/ja/craft) を参照してください。

## 自分の発言を探す

**⌘K** を押して入力します。名前が一致するチャットとコマンドの下にある **In messages** に、入力した語句を含むこの Mac 上のチャットでの発言が一覧表示されます。1 つ選ぶとそのチャットが開きます。検索はこの Mac 上で実行され、この Mac のチャットが対象です。ウェブサイトでは、Chats ページでクラウドチャットをタイトルで検索できます。

## プランとアカウント

**Settings › Aristra One**、アカウントメニュー（左下の自分の名前）の **Aristra One**、または **⌘K** の **Aristra One** を選択すると、ブラウザーの新しいタブで app.aristralabs.com 上のアカウントのページが開きます。プラン、残高、日ごとの支出、デバイス、クラウドコンピューター、エクスポートがあります。**Settings › Billing** にはプラン、プラン一覧、チャージが、**Settings › Usage** には残高と支出がドル単位で表示されます。有効なプランがない場合は、**See plans** でウェブサイトのプラン一覧が開きます。支払いは常に、ブラウザーで開く Stripe のページで行います。[プラン](/ja/account/plans)を参照してください。

## メモリ

**Settings › Memory** には、アカウントの Memory のスイッチ、**See and edit your memory**（ウェブサイトで開きます）、**Import from Codex and Claude Code**、そしてメモリのコピーを `~/Aristra/memory` にファイルとして保存する **Memory folder** があります。[メモリ](/ja/memory)を参照してください。

## キーボードショートカット

| キー | 操作 |
|---|---|
| ⌘N | 新しいチャット |
| ⌥⌘← / ⌥⌘→ | Chat / Code |
| ⌘K | チャット、そのメッセージ、コマンドを検索 |
| ⌘B | サイドバーの表示と非表示 |
| ⌘J | Terminal パネル |
| ⌥⌘B | Review パネル |
| ⇧⌘B | Browser パネル |
| ⌘, | 設定 |
| ⌥Space | どこからでもクイック入力（変更可能） |
| ⌘W | チャットウィンドウを閉じる |
| Return（または ⌘Return） | 送信（Settings › General の設定による） |
| ⇧Return | 改行 |
| ↑ | 空の入力欄で、直前のプロンプトを呼び出す |
| Esc | 作業中の Aristra を停止 |
| ⌘-クリック | リンクをもう一方の方法で開く |

Code タブでは、チャットの横のパネルを開くショートカットがさらにあります。[Aristra Desktop の Code タブ](/ja/code/desktop)を参照してください。
