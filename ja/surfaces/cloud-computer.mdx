クラウドコンピューターは、Aristra のクラウドにある自分専用の Linux マシンです。ターミナルや Aristra Desktop と同じ Aristra Code のエージェントが動いています。クラウドコンピューター上のチャットは、Mac 上のチャットと同じように動作します。本物のシェルがあり、ファイルは残り続け、自分でツールをインストールでき、時間のかかる処理を動かしたままにできます。何かを送ると起動するため、ウェブやスマートフォンから、プランがあれば Telegram からも、いつでもアクセスできます。

<Note>
クラウドコンピューターは[クラウドチャット](/ja/code/cloud-chats)とは別のものです。クラウドチャットは Aristra の共有クラウドエージェントで実行され、チャット間で引き継がれるのはアカウントの情報だけです。クラウドコンピューターは自分専用のマシンで、ファイルとインストールしたツールを保持するディスクがあります。
</Note>

## 作成する

クラウドコンピューターは残高で動きます。[プラン](/ja/account/plans)があればプランで、なければ[チャージ](/ja/account/credits)した残高で使えます。プランがあれば、残高が 0 より多ければ作成できます。プランがない場合は、チャージした残高が $2 以上必要です。スタータークレジットは含まれません。作成できる最大のサイズとディスクはプランで決まります。プランがない場合は、Large と 100 GB のディスクまでです。

1. アカウントの **Cloud computer**（`app.aristralabs.com/account/computer`）を開きます。作成、使用、管理はすべてここで行います。
2. サイズ、ディスク、データの保存先（後述）を選び、**Create cloud computer** を選択します。
3. 1 分ほどで準備が整い、ページに各ステップが表示されます。クラウドコンピューターのページから、または新しいチャットの **Where it runs** からチャットを始めます。

| サイズ | マシン | 起動中の料金 | 利用できるプラン |
|---|---|---|---|
| Small | 共有 CPU 2 個、メモリ 1 GB | 1 時間あたり $0.0122 | すべてのプランとチャージ |
| Medium（既定） | 共有 CPU 4 個、メモリ 2 GB | 1 時間あたり $0.0243 | すべてのプランとチャージ |
| Large | 共有 CPU 8 個、メモリ 4 GB | 1 時間あたり $0.0487 | すべてのプランとチャージ |
| Extra large | 共有 CPU 8 個、メモリ 8 GB | 1 時間あたり $0.0881 | Max |

ほとんどのエージェントの作業には Medium で十分です。Small はメッセージ、スクリプト、スケジュールタスクに向いています。ビルドやブラウザーには Large が適しています。起動中にサイズを変更すると、すぐに反映されます。コンピューターは数秒で再起動し、ディスク上のものはすべてそのまま残ります。スリープ中なら、新しいサイズで起動します。

**ディスク**は作成時に、5 GB から 5 GB 単位で選びます（変更しなければ 10 GB）。プランの上限まで拡張できます。上限は Plus で 25 GB、Pro と Max で 100 GB、チャージのみの場合は 100 GB です。縮小はできません。データを保持するため、コンピューターが起動中でもスリープ中でも、1 GB あたり月額 $0.18 がかかります。

モデルの呼び出しとツールの料金は、Aristra の他の場所と同じように課金されます。

## データの保存先

作成時に選び、あとからそのページで変更できます。変更は新しいメッセージから適用されます。

| | Saved to your account（既定） | Kept on the computer only |
|---|---|---|
| チャット | コンピューター上に保存され、各ターンはアカウントにも保存されます | コンピューター上にのみ保存されます |
| メモリ | アカウントのメモリ。Mac やウェブサイトと共有されます | コンピューター独自のメモリ。ディスク上のファイルに保存されます |
| アカウントのファイル、Craft、コネクター | アカウントのファイル。プランがあれば Craft とコネクター | 使われません。コンピューターにインストールしたツールは使えます |
| ウェブとスマートフォン | スリープ中でも、チャットの一覧に表示されます | 開いたときにコンピューターから読み込まれ、そのときにコンピューターが起動します |
| コンピューター自身がスケジュールするプロンプト | コンピューター上に保存され、返信はアカウントに保存されます | コンピューター上に保存され、返信もコンピューターに残ります |
| ウェブサイトのスケジュールタスク | タスクはアカウントにあり、各実行で始まるチャットもアカウントに保存されます | タスクはアカウントにあり、各実行で始まるチャットはコンピューターに残ります |
| ページで設定するコンピューター独自のスケジュールタスク | コンピューター上に保存され、各実行で始まるチャットはアカウントに保存されます | コンピューター上に保存され、各実行で始まるチャットもコンピューターに残ります |
| Telegram | Telegram の各チャットに対応するチャットがコンピューター上にあり、アカウントに保存されます | Telegram の各チャットに対応するチャットがコンピューター上にあり、そこにのみ保存されます |
| 削除した場合 | チャットとメモリはアカウントに残ります | コンピューター上のものはすべて失われます |

**Kept on the computer only** の場合、Aristra はメッセージと返信を中継しますが、その内容は何も保持しません。メッセージ、タイトル、検索用のエントリも保存しません。メッセージが Aristra のサーバーで待機するのは、コンピューターが受け取るまでの間だけです。返信は、開いているページが追いつけるよう、完了後最大 1 時間だけ待機します。ディスクが唯一のコピーになるため、削除する前にページの **Export chats and memory** を使ってください。

どちらのモードでも、Aristra のサーバーは、サインイン、残高、Aristra のモデルの呼び出し（請求のために数えますが、内容は保持しません）、ウェブ検索などの組み込みツール、Telegram、コンピューターの起動と停止を扱います。ウェブサイトで作成したスケジュールタスクは、ウェブサイトが実行するため、アカウントに保存されます。

**Kept on the computer only** に切り替えると、すでにアカウントにあるチャットのコピーを削除するかどうかをページで尋ねられます。元に戻すと、コンピューター上のチャットをアップロードするかどうかを尋ねられます。

## スリープと起動

- **2 分間アイドル状態が続くとスリープします**。アイドル状態とは、実行中の返信、待機中の承認、バックグラウンドのコマンド、あなたからの操作がいずれもない状態です。確認できないものは使用中とみなされるため、作業の途中でスリープすることはありません。
- **何かを送ると起動します**。ウェブ、スマートフォン、Telegram からのメッセージや、承認への応答です。スリープ中に送ったメッセージは待機し、起動すると応答されます。通常は数秒で起動します。Small、Medium、Large は、スリープ中も実行中だったものをメモリに保持します。Extra large は代わりにシャットダウンし、新しく起動するため、起動に少し時間がかかります。いずれの場合も、ファイルとチャットはディスクに残っています。
- **スケジュールしたプロンプトは、スリープ中でも予定どおり実行されます**。コンピューターはプロンプトをディスクに保存し、次の実行時刻だけを Aristra に伝えるので、Aristra はその直前にコンピューターを起動できます。Aristra がプロンプトの内容を知ることはありません。
- スリープ中に支払うのは、ディスクの料金だけです。
- 他の理由（クラッシュ、ホストのメンテナンス）で停止した場合は、自動的に再起動するか、次にスケジュールされたプロンプトかあなたの次のメッセージで起動します。

## どこからでも使う

- **ウェブとスマートフォン**：新しいチャットの **Where it runs** には、Aristra Cloud、クラウドコンピューター、その他のコンピューターが一覧表示されます。クラウドコンピューターを選ぶとアカウント内のそのページが開くので、そこでメッセージを送ります。**Saved to your account** の場合は通常のチャットページで、それ以外の場合はクラウドコンピューター専用のページでチャットが開きます。
- **Telegram**（プランが必要）：クラウドコンピューターのページで **Telegram messages go to this computer** をオンにします。すると、Aristra との個人チャットがクラウドコンピューター上で実行されます。`/new` を送ると、そこで新しいチャットを始められます。
- **スケジュールタスク**（プランが必要）：クラウドコンピューターで実行するよう設定したタスクは、実行のたびにそのプロンプトでチャットを始め、スリープ中なら起動します。タスク自体の履歴には各実行が始まったことが表示され、返信はチャットにあります。
- **コンピューター独自のスケジュールタスク**：ページの **Scheduled tasks** で、毎日、平日、週 1 回、毎時、1 回のみのいずれかで、自分のタイムゾーンの時刻に実行するプロンプトを設定します。コンピューターがタスクを保持し、実行のたびに起動して新しいチャットで実行します。そのチャットは **Read it** で開けます。プランは不要で、各実行の料金はチャットと同じように残高から支払われます。スリープ中に一覧を読むと、一時的に起動します。
- **Aristra Desktop**：アカウントに保存するクラウドコンピューターのチャットは、Code タブの **On other devices** に表示されます。クラウドコンピューターでチャットを始めるには、ウェブ上のそのページを使います。

## 独自のモデル

既定では、クラウドコンピューターは Aristra のモデルを使い、料金は残高から支払われます。**ChatGPT のプラン**で動かすこともできます。

1. クラウドコンピューターのページの **Your own model** で **Set up…** を選択します。
2. コンピューターが独自にサインインを始め、ページにコードが表示されます。OpenAI のページを開いてコードを入力します。
3. コンピューターがサインインを自分で完了し、そのサインイン情報を自身のディスクに保存します。

Aristra のサーバーはコードを中継するだけで、サインイン情報を見ることはありません。Aristra のモデルも引き続き残高から使えます。

## 支払い

- **起動中**の稼働時間は秒単位で課金されます。プランがあればプランの毎月の利用枠から、その次にチャージした残高から支払われます。
- **ディスク**は、コンピューターが起動中でもスリープ中でも課金されます。
- 残高が少なくなると、メールが届きます（1 日に最大 1 回）。
- **プランがある場合、残高が 0 になるとスリープします**。プランがある間は、コンピューター上のものは何も削除されません。[チャージ](/ja/account/credits)やプランの毎月のリセットで残高が戻ると、次のメッセージで自動的に起動します。その間のディスクの料金は、次に入金されたお金から差し引かれます。
- **プランがなく、チャージした残高がなくなった場合**は、コンピューターが停止し、ディスクは 30 日間保持されます。ディスクが削除される 1 週間前にメールが届きます。その期間内にチャージすれば、すべてがそのままの状態で戻ります。先にデータをエクスポートしておくこともできます。
- **プランが終了した場合**は、チャージした残高で動き続け、Extra large は Large に下がります。残高がなくなると、同じように停止し、ディスクは 30 日間保持されます。その期間内にプランを更新するかチャージすれば元に戻ります。
- **上限の小さいプランに変更した場合**は、更新時にサイズがそのプランの最大サイズまで下がります。ディスクはそのまま残りますが、それ以上拡張できなくなります。

## セキュリティ

- 各クラウドコンピューターは、それぞれ専用のプライベートネットワーク上にある独立したマシンです。Mac と同じく、公開 API を通さない限り、他のユーザーのマシンや Aristra のサーバーにはアクセスできません。
- Aristra Code は、`sudo` を使えない権限のないユーザーとして実行されます。ツールはホームフォルダーにインストールしてください（`pip install --user`、`npm install -g`、または `~/bin`）。
- コンピューター上では何も待ち受けていません。Mac と同じく、独自のデバイスキーで認証し、HTTPS でアカウントに外向きに接続します。
- Aristra の認証情報は一切保持しません。最初に作成されたときに 1 回限りのトークンでサインインし、数週間スリープしていた場合や別のホストに移った場合は、新しいトークンでサインインします。
