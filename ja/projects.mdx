title: "プロジェクト"

プロジェクトは、1 つの作業をまとめておく場所です。チャット、ファイル、指示、そして Aristra がその作業について学習したことを保持します。プロジェクトの中で始めたチャットは、プロジェクトのファイル、指示、メモリを使います。プロジェクトはすべてのアカウントで使え、Free では 3 個、Plus では 5 個、Pro では 20 個、Max では 40 個まで作成できます。Projects ページに残りの数が表示されます。

## プロジェクトを作成する

ウェブサイトで **Projects** を開き、**New project** を選択します。取り組んでいる内容を入力し、必要なら説明を追加します。新しいプロジェクトはサイドバーにピン留めされます。プロジェクトはウェブサイトで作成します。Aristra Desktop とターミナルでは、作成済みのプロジェクトを使います。

## プロジェクトのページ

| | |
|---|---|
| **New chat** | プロジェクト内のチャット |
| **Chats** | プロジェクトのチャット |
| **Files** | [ファイル](/ja/files)のうち、このプロジェクトのもの |
| **Craft** | プランがあれば、プロジェクトの [Craft](/ja/craft) のドキュメント |
| **Folders on your Macs** | 各 Mac でこのプロジェクトが作業するフォルダー。メインのフォルダーには印が付きます。その Mac でプロジェクト内の新しいチャットを始めると、メインフォルダーで始まります。ファイルは Mac に残ります |
| **Pin** | サイドバーに表示するか、サイドバーから外します |

チャットの横には、プロジェクトの設定があります。

- **Instructions**：プロジェクト内のすべてのチャットが従う、最大 4,000 文字の指示です。誰に向けたものか、どう書くか、何を確認するかなどを書きます。
- **API keys**：プランがあれば、自分のコードからプロジェクトを使うためのキーを作成できます。

プロジェクトのメニューには、**Edit details…**（名前、説明、Aristra Desktop が作業するリポジトリ）と **Delete project…** があります。

## Aristra Desktop とターミナルのプロジェクト

- サインインした Aristra Desktop では、新しいチャットに **Project** ピッカーが表示されます。プロジェクトのチャットはクラウドで実行され、プロジェクトの指示とメモリを使います。Code タブでは、この Mac にプロジェクトのメインフォルダーがあれば、そこでチャットが始まります。ピッカーは、プロジェクトを 1 つ以上作成すると表示されます。
- Aristra Desktop の Code タブでは、新しいチャットにプロジェクトとフォルダーを選び、メッセージ欄の下にある **Make it Launch's main folder**（Launch という名前のプロジェクトの場合）を選択します。
- ターミナルでは、`aristra --cloud --project <name>` でプロジェクト内のクラウドチャットを始めます。[クラウドチャット](/ja/code/cloud-chats)を参照してください。

## プロジェクトのメモリ

プロジェクトで作業している間に Aristra が学習したことは、プロジェクト名を付けてメモリに保存されます。[メモリ](/ja/memory)の **Pages** タブでは、プロジェクトごとにまとめて表示されます。
