---

ゴールとは、Aristra Code が停止する前に確認する条件です。ターンが終わろうとすると、小さなモデルがチャットを読み、ゴールが満たされているかどうかを判断します。満たされていなければ、その理由とともにターンが続きます。満たされていれば、ゴールは解除され、達成されたことが、かかった時間、ターン数、トークン数とともにチャットに表示されます。

```text
/goal all tests in packages/api pass and the linter is clean
/goal                # show the current goal
/goal clear          # remove it
```

ゴールは 4,000 文字までです。`/goal` は信頼したフォルダーでのみ使え、`disableAllHooks` が設定されている間は使えません。

Aristra Desktop では、チャットの `/` メニューで **Goal** を選択します。

## よいゴールを書く

ゴールは、意見の問題ではなく、Aristra Code が何かを実行して確認できるものにすると、いちばんうまく機能します。

| よい例 | 確認しにくい例 |
|---|---|
| `npm test` がスキップなしで通る | コードがきれいである |
| ビルドが成功し、バンドルが 200 KB 未満である | アプリが速い |
| ローカルサーバーで `/health` が 200 を返す | API が動く |

確認するためのコマンドを、ゴールか `AGENTS.md` で Aristra Code に伝えてください。そうすれば、各ターンで推測ではなく検証できます。

## 終わり方

- **達成**：ゴールは解除され、チャットにそのことが表示されます。
- **未達成**：確認で示された理由とともにターンが続きます。
- **達成不可能**：確認によってゴールに到達できないと判断された場合、ゴールは解除され、理由とともにターンが終わります。
- **8 回連続で未達成**（その間にツールの呼び出しがない場合）：それでもターンは終わり、ゴールは残ります。
- **確認の失敗**（30 秒以内に回答がない、または確認用のモデルが設定されていない）：ターンは終わり、ゴールは残ります。

チャットでバックグラウンドの作業がまだ実行中の場合、確認はその完了を待ちます。Esc キーでは通常どおりターンが停止します。ゴールは、自分で解除するか、達成されるか、確認で達成不可能と判断されるまで残ります。
