Aristra Code は、各チャットを 4 種類の情報を把握した状態で始めます。

| | 内容 | 書く人 |
|---|---|---|
| **指示ファイル** | `AGENTS.md` とルール。プロジェクトのビルド、テスト、レビューの方法 | 自分（または `/init`） |
| **アカウントのメモリ** | あなたが誰で、どう作業するのが好きか。すべてのデバイスで使え、すべてのアカウントにあります。[メモリ](/ja/memory)を参照してください | 伝えた内容をもとに Aristra Code が書きます |
| **ファイルのメモリ** | 同じ内容を、**Kept on the computer only** に設定したクラウドコンピューター上のファイルに保存したもの | 伝えた内容をもとに Aristra Code が書きます |
| **リポジトリのメモ** | このコンピューター上の 1 つのリポジトリについての訂正、進行中の作業、ものの置き場所 | 作業しながら Aristra Code が書きます |

サインインしていれば、メモリは Aristra のアカウントに保存されるため、ウェブ、スマートフォン、他のコンピューターにも引き継がれます。メモリの保持、保存、インポート、検索に料金はかかりません。メモリを使うチャットで支払うのは、そのチャット自体のトークン分だけです。

## 指示ファイル

`AGENTS.md` ファイルは、プロジェクトの進め方を Aristra Code に伝えます。ビルドとテストの方法、規約、避けるべきことなどです。他のコーディングエージェントが読むのと同じファイルです。ファイルは階層的に読み込まれ、あとのものほど優先されます。

| 階層 | ファイル |
|---|---|
| 組織のもの | [管理ポリシー](/ja/code/configure/managed-policy)と同じ場所にある `AGENTS.md` と `rules/*.md` |
| すべてのプロジェクトに適用する自分のもの | `~/.aristra/AGENTS.md` と `~/.aristra/rules/*.md` |
| ディスクの最上位からチャットのフォルダーまでの各フォルダー | `AGENTS.md`、`.aristra/AGENTS.md`、`.aristra/rules/*.md`（リポジトリにコミットするもの）、`AGENTS.local.md`（自分用で、コミットしないもの） |

Claude Code 用に設定したリポジトリは、そのまま使えます。Aristra の名前のファイルがない場所では、対応する Claude Code のファイルが代わりに読み込まれます（`AGENTS.md` の代わりに `CLAUDE.md`、`.claude/CLAUDE.md`、`.claude/rules/`、`CLAUDE.local.md`）。ルールのフォルダーは、サブフォルダーも含めて読み込まれます。

```text
/init       write this folder's AGENTS.md from the code
/memory     open an instruction file (or the repository's notes) in your editor
```

### 一部のファイルに適用するルール

ルールファイルは、フロントマターの `paths` で、一部のパスにだけ適用できます。

```markdown .aristra/rules/api.md
---
paths: src/api/**/*.ts
---

Every handler validates its input with the schemas in src/api/schemas.ts.
```

このルールは、Aristra Code が一致するファイルを初めて読んだときにモデルに渡されます。サブフォルダー自体の `AGENTS.md` も同じように動作し、Aristra Code がそのサブフォルダー内のファイルを初めて読んだときに読み込まれます。

### インクルード

指示ファイルに `@path` を書くと、別のファイル（そのファイルからの相対パス、`~/` から、または絶対パス）を、5 階層までインクルードできます。

```markdown AGENTS.md
See @docs/testing.md for how to run the test suites.
```

インクルードは、自分の `~/.aristra` のファイルを除き、チャットのフォルダー内に限られます。HTML コメントの行は除外されるため、ファイルを編集する人へのメモを残せます。

## アカウントのメモリ

チャットでメモリがオンのとき、各ターンは、Aristra のアカウントが覚えていることのうちその場面に関係するものから始まります。Aristra Code はメモリツールで物事を覚え、訂正し、忘れ、そのことをチャットで知らせます。ウェブサイトやスマートフォンと同じメモリです。保存のしかた、毎晩の学習、オフにする方法、編集方法は[メモリ](/ja/memory)で説明しています。

- **1 つのチャット**：チャットがメモリを読んで保存するのは、アカウントの Memory のスイッチがオンの間だけです。オフにすると、Aristra Desktop とターミナルのすべてのチャットで、1 分ほどで停止します。Aristra Desktop では、スイッチがオフの状態で始めたチャットは、あとでオンに戻してもメモリを使いません。ターミナルでは、設定で `memory.enabled: false` にすると、メモリがオフの状態でチャットが始まります。
- **シークレットチャット**：Aristra Code がコンピューター上で実行するチャットには、シークレットモードはありません。`aristra --cloud --incognito` で、Aristra Cloud のシークレットチャットを始められます。[メモリ](/ja/memory)を参照してください。
- Aristra Code がウェブページなどの外部のコンテンツを読んだあとに保存するメモリには、あなたの発言の引用が必要です。そのため、ページがメモリを仕込むことはできません。

## ファイルのメモリ

アカウントのメモリを使うには、サインインが必要です。サインアウトしている間、Aristra Code はあなたについて何も覚えません。**Kept on the computer only** に設定した[クラウドコンピューター](/ja/surfaces/cloud-computer)は、代わりに自身のディスク上のファイルに覚えておきます。

```text
~/.aristra/memory/
  MEMORY.md            the index, one line per note
  user_role.md         a note
  feedback_style.md
```

各チャットはインデックスと役立つメモを読み、Aristra Code は他のファイルと同じようにメモを書いたり訂正したりします。自分で読んだり編集したりすることもできます。メモはそのコンピューターにとどまり、アカウントには何も送られません。

メモリがすべてのアカウントに含まれるようになる前にファイルでメモリを保持していたコンピューターは、サインインした状態で初めてチャットを始めたときに、それらのメモをアカウントのメモリに取り込みます（初日は最大 500 件）。

## リポジトリのメモ

メモリがオンの間、Aristra Code は作業しながらリポジトリについてのメモを残します。あなたの訂正（「必ず最初にリンターを実行して」）、進行中の作業とその理由、コード以外の場所にあるものの置き場所などです。メモはリポジトリの外にある Markdown ファイルなので、`git status` には何も表示されません。

```text
~/.aristra/projects/<repository path, with dashes>/memory/   (for example -Users-you-code-app)
  MEMORY.md            the index, one line per note
  feedback_tests.md    a note
  project_launch.md
```

各ターンでは、インデックスと、明らかに役立つメモが最大 5 件、それぞれチャットごとに 1 回、作成からの経過時間とともに渡され、頼る前にコードを確認するよう注意書きが添えられます。メモはアカウントにもコピーされるため、他のコンピューターやそのリポジトリでのウェブのチャットでも参照されます。

メモには、コード、git、`AGENTS.md` にすでに書かれていることは書きません。Aristra Code を訂正したのに何も保存されなかった場合は、ターンのあとにあなたの発言を引用して教訓を保存し、そのことを知らせます。

## このコンピューター上の過去のチャット

以前の作業について尋ねると（「キャッシュについて何を決めたっけ？」「先週書いてくれたスクリプト」）、Aristra Code はこのコンピューター上の過去のチャットを検索し、読み、一覧表示して、話した内容を引用できます。検索するのはすでにこのコンピューターにあるものだけなので、プランの有無にかかわらず使え、どこにも何も送信されません。

シークレットチャット、メモリがオフのチャット、アカウントの **Memory** か **Search and reference past chats** がオフの間は使えません。また、シークレットチャットや今いるチャットが表示されることはありません。ウェブのチャットは、代わりにウェブ上で、アカウント設定の **Search and reference past chats** で検索されます。
