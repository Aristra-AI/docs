title: "クラウドチャット"
description: "Aristra のクラウドエージェントが実行し、アカウントに保存されるチャット。ターミナルや Aristra Desktop から始められ、必要に応じてコンピューター上のフォルダーで作業できます。"
---

クラウドチャットは Aristra のアカウントに保存され、Aristra のサーバーで実行されます。ウェブサイトやスマートフォンと同じエージェントです。Aristra Code では、コンピューター上のチャットと並べて、クラウドチャットの一覧表示、表示、開始、続行ができます。

チャット間でファイルやツールを保持するディスクを備えた、クラウド上の自分専用のマシンについては、[クラウドコンピューター](/ja/surfaces/cloud-computer)を参照してください。

クラウドチャットの料金は[残高](/ja/account/credits)から支払われます。最初に新規アカウントの $1 のスタータークレジット、次にプランの毎月の利用枠、その次にチャージした残高が使われます。残高がなくなると、新しいメッセージでその旨が表示されます。コンピューター上のチャットは、自分のモデルで引き続き使えます。

会話をアカウントに残したい（ウェブやスマートフォンにも表示したい）場合、クラウドエージェントのツール（ブラウザー、サンドボックス、接続したアカウント、Craft のドキュメント）を使いたい場合、コンピューターがスリープしている間も続くチャットが必要な場合は、クラウドチャットを使います。任意のモデルとコンピューターのサンドボックスを使ってフォルダーで作業する場合は、コンピューター上のチャットを使います。

| | コンピューター上 | クラウド |
|---|---|---|
| 実行するもの | このコンピューターの Aristra Runtime | Aristra のクラウドエージェント |
| 保存先 | このコンピューターの `~/.aristra` | Aristra のアカウント |
| モデル | 設定したどのソースでも | Aristra のモデル。ウェブサイトと同じように課金されます |
| ファイル | チャットのフォルダー。このコンピューターのサンドボックス内 | フォルダーを接続した場合はこのコンピューター上のフォルダー。それ以外はクラウドエージェント自体のサンドボックス |
| モード | Manual、Accept edits、Plan、Auto、Read only、Don't ask（許可した場合は Bypass permissions も） | ウェブサイトと同じく Manual か Auto |

## 始める

```sh
aristra --cloud                                        # a new cloud chat
aristra --cloud "draft the launch email"               # with a first message
aristra --cloud --folder ~/code/site "update the docs" # working in a folder on this computer
aristra --cloud --incognito                            # incognito
aristra --cloud --project "Q4 launch"                  # in a project
```

Aristra Desktop では、Code の新しいチャットのメッセージ欄の下でフォルダーと **In the cloud** を選ぶか、Chat タブでチャットを始めます。

クラウドチャットは Aristra のモデルで実行されます。`--source aristra -m <model>` でモデルを指定します（`aristra models --source aristra` で一覧を表示できます）。指定しない場合、既定のモデルが Aristra のモデルならそれを使い、そうでなければ Aristra の既定のモデルを使います。

## 一覧表示、表示、続行

```sh
aristra sessions --cloud                  # your account's chats, newest first
aristra resume <id>                       # open one
aristra run -r <id> "next step, please"   # one more turn from a script
```

クラウドチャットを開くと、ステップ、ファイル、ドキュメントを含むトランスクリプトがアカウントから読み込まれます。すでに進行中の実行は、リアルタイムで追いかけられます。Esc キーで実行をキャンセルします。`/rename` と `aristra sessions delete <id>` で、アカウント内のチャットの名前を変更したり削除したりできます。ウェブサイトで始めたチャットや削除したチャットは、2 分以内に表示されたり消えたりします。

## コンピューター上のフォルダー

クラウドチャットは、コンピューター上のフォルダーで作業できます。クラウドエージェントは、コンピューターを通じてそのフォルダー内のファイルを読み、検索し、変更します。フォルダーの外には何もしません。フォルダー内でコマンドを実行することはできません。

```sh
aristra --cloud --folder ~/code/site                        # start one in a folder
aristra sessions connect-folder <id> --folder ~/code/site   # give an existing cloud chat a folder here
```

- フォルダーへの呼び出しは、このコンピューターのルールに従って実行されます。フォルダーの中だけで、拒否ルールとシークレットファイルの除外が適用され、各変更は表示して承認されたとおりにだけ書き込まれます。承認はターミナル、Aristra Desktop、ウェブサイトに表示され、最初の回答が採用されます。
- このために、コンピューターは Aristra への外向きの接続を維持します。コンピューター上では何も待ち受けていません。
- コンピューターがスリープしている間は、チャットのフォルダーへの呼び出しは待機するか失敗し、クラウドエージェントがそのことを知らせます。
- 各フォルダーには、ウェブサイトやスマートフォンから操作するチャット用のレベルもあります。**Off**（既定）、**Read only**、**Read and edit** です。Aristra Desktop で、フォルダーのメニューの **Use from other devices** で設定します。Read only と Read and edit はプランに含まれます。

## シークレットチャット

`aristra --cloud --incognito` で始めたチャットは、アカウントの一覧にもメモリにも含まれません。チャットを離れると、コンピューターには何も残りません。フォルダーもプロジェクトもなく、最後のアクティビティから 30 日後にアカウントから削除されます。

## プロジェクト

`aristra --cloud --project <name>` を使うと、個人用ワークスペースのそのプロジェクトでチャットが始まり、ウェブサイトのプロジェクトの下に表示され、プロジェクトの指示とメモリが使われます。`--folder` を付けると、プロジェクトがそのフォルダーを記憶します。プロジェクトのメインフォルダーは、Aristra Desktop でプロジェクトの新しいチャットが始まる場所です。プロジェクトはウェブサイトで作成します。

## モードと質問

クラウドチャットは、**Manual** モード（設定で許可されていないステップの前に、エージェントが毎回確認）か **Auto** モード（そのようなステップを Aristra のレビュアーが判断）で動きます。チャットに選んだモードを使い、選んでいなければウェブサイトの設定にあるアカウントの既定を使います。Shift+Tab か `/mode` で切り替えると、選択はチャットに保持されます。

実行の途中でクラウドエージェントが何かを尋ねると（承認するステップ、選択肢のある質問、フォーム）、実行は一時停止し、質問は承認としてすべてのサーフェスに届きます。外部サイトへのリクエストは、チャットの残りの間許可できます。選択肢のある質問には、Aristra Desktop かウェブサイトで答えるのがいちばん簡単です。

## 添付

クラウドチャットに添付したファイルは、そのテキストとファイル自体が、チャットを削除するまでアカウントにチャットとともに保存されます。シークレットチャットでは何も保存されません。Aristra は、PDF、Word、Excel、PowerPoint、古い Office ファイル、OpenDocument、RTF、EPUB を読め、PDF のスキャンしたページを最大 100 ページまで無料で OCR で読み取ります。1 つのメッセージに添付できるのは 5 ファイルまで、合計 50 MB までです。

- 10 ページ以下の PDF は、モデルが PDF を受け付ける場合、そのままモデルに渡されるため、モデルはページの見た目も確認できます。
- 2,000 行以下かつ 100,000 文字以下のテキストは、そのままメッセージに含まれます。それより長いファイルは先頭部分が含まれ、残りはエージェントが必要なときに読みます。
- 以降のターンでも、エージェントはチャットで以前に添付したファイルを使えます。どのファイルでも読み直せ、PDF のページを画像として見ることもできます。

コンピューター上のチャットで添付したファイルは、チャットとともにコンピューター上に残ります（[チャット](/ja/code/guides/chats)を参照してください）。

## クラウドエージェントが作成したファイル

```sh
aristra sessions download <id>          # every file the chat's agent made
aristra sessions download <id> <key>    # one, by the key its step names
```

ファイルは `~/.aristra/attachments/` に保存され、そのパスが表示されます。

## クラウドチャットをコンピューターにコピーする

```sh
aristra sessions import <id>
aristra sessions import <id> --folder ~/code/site --source anthropic --model claude-sonnet-5-5
```

これにより、クラウドチャットがコンピューター上の新しいチャットにコピーされ、フォルダーで任意のモデルを使って続けられます。クラウドチャットは元のまま残ります。コピーは一方向で、コピーで行ったことがクラウドチャットに送り返されることはありません。
