## Aristra のフォルダー

Aristra Code が保存するものはすべて、1 つのフォルダー `~/.aristra`（または `ARISTRA_HOME`）にあり、ターミナル、Aristra Desktop、その他のすべてのサーフェスで共有されます。

```text
~/.aristra/
  settings.json                your settings
  AGENTS.md, rules/*.md        your instructions for every project
  keybindings.json             your terminal keys
  runtime.sqlite               every chat on this computer
  logs/runtime.log             the runtime's log, kept 7 days
  attachments/<chat>/          a chat's files: attachments, long outputs, checkpoints, cloud downloads
  exports/                     chats saved with /export
  diagnostics/                 support bundles
  credentials.enc              secrets, sealed with a key in your keychain (credentials.json when
                               credentials.store is file, or there is no keychain)
  sources.json                 the model sources you connected, and a custom endpoint's address (no secrets)
  memory/                      your memory as files, on a computer that keeps everything on its own disk
  skills/<name>/SKILL.md       your skills
  agents/                      your custom agents
  workflows/                   your saved workflows, and each run's script and journal
  plugins/                     installed plugins and marketplaces
  projects/<repository>/memory/  notes about each repository
  plans/                       plan mode's plans
  terminal/history.jsonl       prompts sent from the terminal
  hooks-approved.json          the hooks you approved
```

## プロジェクト内

```text
<folder>/
  AGENTS.md                    instructions for the project (checked in)
  AGENTS.local.md              your own instructions for it (not checked in)
  .aristra/
    settings.json              the project's settings (checked in)
    settings.local.json        yours, for the project (not checked in)
    AGENTS.md                  instructions, as AGENTS.md at the top of the folder
    rules/*.md                 rules, optionally for some paths
    skills/<name>/SKILL.md     the project's skills
    agents/                    the project's custom agents
    workflows/                 the project's saved workflows
    worktrees/<name>/          worktrees made with aristra -w and by agents
  .mcp.json                    the project's MCP servers (checked in)
```

## その他の場所

| 対象 | 場所 |
|---|---|
| プログラム | `~/.local/bin/aristra`。`~/.local/share/aristra/versions/<version>/` へのリンクです |
| 管理ポリシー | macOS：`/Library/Managed Preferences/`、`/Library/Application Support/Aristra/`。Linux：`/etc/aristra/` |
| バックグラウンドサービス | macOS：`~/Library/LaunchAgents/com.aristra.runtime.plist`。Linux：`~/.config/systemd/user/aristra-runtime.service` |
| キーチェーンの項目 | macOS のログインキーチェーンの、サービス `Aristra-credentials`。Linux では Secret Service の同じ属性 |

## 環境変数

変数は、ランタイムを起動したアプリ（Aristra CLI または Aristra Desktop）から、起動時にランタイムに渡されます。すでに動いているランタイムは、起動時の変数を保持し続けます。変数を変更したら `aristra runtime stop` を実行して、次のコマンドで変数を反映したランタイムが起動するようにしてください。Aristra Desktop を開いている場合は先に終了してください。そうしないと、変数なしでランタイムが再び起動されることがあります。ランタイムに渡されるのは、このページの変数（とプロキシ、証明書、ロケールの変数）だけです。バックグラウンドサービスをインストールしている場合（`aristra service install`）、サービスが起動するランタイムには自分の変数は一切渡されません。

### 一般

| 変数 | 効果 |
|---|---|
| `ARISTRA_HOME` | `~/.aristra` の代わりにこのフォルダーを使います |
| `ARISTRA_TOKEN` | CI 向けに、`aristra setup-token` のトークンでサインインします |
| `ARISTRA_LOG_LEVEL` | `DEBUG`、`INFO`（既定）、`WARNING`、`ERROR` |
| `ARISTRA_CREDENTIALS_STORE` | `auto`、`keychain`、`file` |
| `ARISTRA_MANAGED_SETTINGS_DIR` | 管理者のポリシーが存在しない場合に使うポリシーのフォルダー |
| `ARISTRA_DISABLE_TELEMETRY` | `1`：利用イベントを送信しません |
| `ARISTRA_DISABLE_ERROR_REPORTING` | `1`：エラーレポートを送信しません |
| `ARISTRA_DISABLE_NONESSENTIAL_TRAFFIC` | `1`：利用イベント、エラーレポート、プルリクエストのステータスの確認を行いません |
| `ARISTRA_SILENT_TURN_REMINDER`、`ARISTRA_SILENT_TURN_REMINDER_TURNS`、`ARISTRA_SILENT_TURN_REMINDER_TEXT` | 報告のないターンが続いたあとに、何をしているかを伝えるよう促す設定。`0` でオフ、何ターン後か（既定は 5）、その文面 |
| `ARISTRA_TMPDIR` | その中の `aristra-tmp-<uid>` サブフォルダーが、すべてのコマンドの `$TMPDIR` になるフォルダー |
| `OLLAMA_HOST` | Ollama が待ち受けている場所 |
| `BROWSER` | サインインページを開くプログラム（WSL では `wslview`） |
| `VISUAL`、`EDITOR`、`PAGER` | エディターと、Ctrl+O で出力を開くプログラム |
| `HTTP_PROXY`、`HTTPS_PROXY`、`NO_PROXY`、`SSL_CERT_FILE`、`NODE_EXTRA_CA_CERTS` など | `SSL_CERT_FILE` とプロキシの変数は、ランタイム自体のリクエストに適用されます。`NODE_EXTRA_CA_CERTS` はコマンドに渡されます |

### ターミナル

| 変数 | 効果 |
|---|---|
| `ARISTRA_NO_NOTIFY` | 任意の値：ターミナルの通知を表示しません |
| `ARISTRA_NO_FLICKER` | `1`：この起動でフルスクリーンレンダラーを使います。`0` では従来のものを使います |
| `IS_SANDBOX` | `1`：信頼できるコンテナー内で、Bypass permissions を root で実行できるようにします |
| `ARISTRA_REMOTE` | `--remote <host>` と同じように、実行するホストを指定します |
| `NO_COLOR`、`FORCE_COLOR` | ターミナルの色をオフにするか、強制的にオンにします |
| `ARISTRA_DISABLE_ALTERNATE_SCREEN` | `1`：常に従来のレンダラーを使います |
| `ARISTRA_DISABLE_MOUSE`、`ARISTRA_DISABLE_MOUSE_CLICKS` | フルスクリーンで、マウス（またはそのクリック）をターミナルに任せます |
| `ARISTRA_SCROLL_SPEED` | フルスクリーンで、マウスホイールの 1 目盛りあたりにスクロールする行数 |
| `ARISTRA_ENABLE_PROMPT_SUGGESTION` | `0`：次のメッセージの候補を表示しません |
| `ARISTRA_IDLE_THRESHOLD_MINUTES`、`ARISTRA_IDLE_TOKEN_THRESHOLD` | 大きなチャットがアイドル状態のときに「new task? /new」のヒントを表示する条件（既定は 75 分と 100,000 トークン） |

### チャットとツール

| 変数 | 効果 |
|---|---|
| `ARISTRA_AUTO_COMPACT_WINDOW` | 自動圧縮のウィンドウ。`autoCompactWindow` より優先されます |
| `ARISTRA_MAX_TURNS` | `aristra run` での 1 ターンあたりのモデルのラウンド数 |
| `ARISTRA_MAX_STRUCTURED_OUTPUT_RETRIES` | `--json-schema` の回答を試みる回数（既定は 5） |
| `ARISTRA_DISABLE_GIT_INSTRUCTIONS` | `1`：シェルツールから git に関する指示を除きます |
| `ARISTRA_DISABLE_WORKFLOWS` | `1`：ワークフローをオフにします |
| `ARISTRA_ENABLE_TASKS` | `false`：タスクツールの代わりに、より簡単な ToDo リストを使います |
| `ARISTRA_ENABLE_TODO_TOOLS` | `1`：すべてのモデルにタスクツールを提供します（既定では古いモデルにだけ渡され、現行のモデルはタスクツールなしで計画します） |
| `ARISTRA_SUBAGENT_EFFORT` | 呼び出しでも定義でも指定がない場合に、サブエージェントが使う推論の深さ |
| `ARISTRA_DISABLE_AGENT_PROGRESS_SUMMARIES` | `1`：サブエージェントの進捗ラベルを表示しません |
| `ARISTRA_WEBFETCH_CACHE_TTL_MS` | 取得したページをキャッシュする時間（既定は 15 分） |
| `ARISTRA_WEBFETCH_DEADLINE_MS` | ページの取得の期限（既定は 5 分） |
| `ARISTRA_MAX_WEB_SEARCHES_PER_SESSION` | 1 つのチャットでの検索回数（既定は 200） |
| `ARISTRA_WEB_SEARCH_REFILLS_PER_HOUR` | 検索回数が回復する速さ（既定は 1 時間あたり約 100） |
| `ARISTRA_MAX_RETRIES` | 失敗したモデルの呼び出しを再試行する回数（既定は 10、最大 15） |
| `ARISTRA_RETRY_WATCHDOG` | `1`：誰も見ていない実行で、失敗する代わりにプロバイダーの障害が終わるのを待ちます。最大 300 回試み（過負荷とレート制限は回数に含みません）、待ち時間は最大 5 分まで段階的に延び、1 回の待機は最大 6 時間です。`ARISTRA_RETRY_WATCHDOG_SCOPE=capacity` にすると過負荷とレート制限に限定し、`ARISTRA_RETRY_WATCHDOG_MAX_WAIT_MS` で待機全体の上限を設定します（既定では上限なし） |
| `ARISTRA_STOP_HOOK_BLOCK_CAP` | `Stop` フックがターンを続けさせられる連続回数（既定は 8。`0` で制限なし） |
| `ARISTRA_DISABLE_SUBSTITUTION_RM_PROMPT`、`ARISTRA_DISABLE_MOUNTED_DRIVE_RM_PROMPT` | `rm` に対する安全のための確認のうち 2 つをオフにします |
| `ARISTRA_DISABLE_NOTIFICATION_PRESENCE_CHECK` | コンピューターの前にいるときも、Aristra Code 自身の通知を表示します |

### MCP サーバー

| 変数 | 効果 |
|---|---|
| `ARISTRA_MCP_TOOL_IDLE_TIMEOUT` | 呼び出しが応答なしでいられるミリ秒数（`0` で制限なし。既定はプログラムのサーバーで 30 分、アドレスのサーバーで 5 分） |
| `ARISTRA_MCP_AUTO_BACKGROUND_MS` | 時間のかかる呼び出しがバックグラウンドに移るまでの時間（既定は 120 秒。`0` で移しません） |

### プラグイン

| 変数 | 効果 |
|---|---|
| `ARISTRA_DISABLE_OFFICIAL_MARKETPLACE_AUTOINSTALL` | 初回の起動時に Anthropic のマーケットプレイスを追加しません |
| `ARISTRA_DISABLE_AUTOUPDATER` | バックグラウンドでプラグインを更新しません |
| `ARISTRA_FORCE_AUTOUPDATE_PLUGINS` | `ARISTRA_DISABLE_AUTOUPDATER` が設定されていてもプラグインを更新します |
| `ARISTRA_PLUGIN_AUTOUPDATE_DELAY_MS` | 起動してからプラグインを更新するまでの時間（既定は最初の 10 分間のランダムな時点） |
| `ARISTRA_PLUGIN_GIT_TIMEOUT_MS` | プラグインの git 操作の制限時間（既定は 120 秒） |

### インストール

| 変数 | 効果 |
|---|---|
| `ARISTRA_NON_INTERACTIVE` | `1`：インストールスクリプトは何も尋ねません |
| `ARISTRA_INSTALL_ALLOW_SUDO` | `1`：インストールスクリプトが sudo で root 用にインストールできるようにします |

### Aristra Code が設定する変数

| 変数 | 場所 |
|---|---|
| `ARISTRA_PROJECT_DIR`、`CLAUDE_PROJECT_DIR`、`ARISTRA_HOME` | フックの環境 |
| `${ARISTRA_SKILL_DIR}`、`${CLAUDE_SKILL_DIR}` | スキルの本文で、そのスキルのフォルダーに置き換えられます |
| `${CLAUDE_PLUGIN_ROOT}` | プラグインのフックと MCP サーバーで、そのプラグインのフォルダー |
| `${CLAUDE_PLUGIN_DATA}`、`CLAUDE_PLUGIN_OPTION_<KEY>` | プラグインのフックと MCP サーバーで、そのデータフォルダーとオプション |
| `ARISTRA_MCP_SERVER_NAME`、`ARISTRA_MCP_SERVER_URL` | MCP サーバーの `headersHelper` |
| `TMPDIR`、`TERM=dumb`、`PAGER=cat`、`GIT_PAGER=cat`、`NO_COLOR=1`、`GIT_EDITOR=true` | すべてのコマンドの環境 |

## 終了ステータス

| ステータス | 意味 |
|---|---|
| `0` | 完了 |
| `1` | 何かが失敗した。理由は標準エラー出力にあります |
| `2` | 使い方の誤り |
| `3` | `aristra run`：完了したが、承認できる人がいなかったためステップが拒否された |
| `130` | `aristra run`：Ctrl+C で中断された |
