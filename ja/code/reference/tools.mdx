ツールは、Aristra Code が実行できる操作です。各呼び出しは[権限](/ja/code/configure/permissions)の設定を通り、実行されるか、確認を求めるか、Auto モードのレビュアーに回されるか、拒否されます。権限のルールでは、ツールの名前（`shell(npm test:*)`）、グループ（`read_file`、`list_dir`、`glob`、`grep` なら `read(...)`、`edit_file`、`write_file`、`notebook_edit`、`apply_patch` なら `edit(...)`）、または Claude Code の名前（`Bash`、`Edit`、`WebFetch`）を使います。

各リクエストを小さく保つため、一部のツールは、モデルが検索したときにだけモデルに送られます。それらには*オンデマンド*と記載しています。これは `mcp.toolSearch` がオン（既定）の間に適用されます。

## ファイル

| ツール | 動作 | Manual で確認を求めるか |
|---|---|---|
| `read_file` | ファイル、またはその一部の行を読みます。画像のほか、PDF、Word、Excel、PowerPoint、OpenDocument、RTF、EPUB のファイルも、コンピューター上でテキストとして読みます | いいえ（チャットのフォルダー内） |
| `list_dir` | フォルダーの中身を一覧表示します | いいえ（チャットのフォルダー内） |
| `glob` | パターンでファイルを探します（一度に 100 件。「Showing N of M」と表示） | いいえ（チャットのフォルダー内） |
| `grep` | ファイルの内容を検索します | いいえ（チャットのフォルダー内） |
| `edit_file` | ファイル内のテキストを置き換えます。先にファイルを読んでいる必要があります（新しい Claude のモデルは、読めるファイルならこれを省略することがあります）。読んだあとに変更されたファイルへの編集は、それでもちょうど 1 か所に適用できる場合を除き拒否されます | はい |
| `write_file` | ファイルを作成または上書きします | はい |
| `apply_patch` | Codex の形式のパッチを適用します。GPT のモデルには、`edit_file` と `write_file` の代わりにこれが渡されます | はい |
| `notebook_edit` | Jupyter ノートブックのセルを 1 つ置き換え、挿入、削除します（*オンデマンド*） | はい |

Python、JSON、TOML のファイルの構文を壊す編集は、モデルに報告されます。UTF-8 または UTF-16（リトルエンディアン、バイトオーダーマーク付き）のファイルはエンコーディングが保たれます。それ以外のエンコーディングのファイルは、編集ツールが拒否します。編集ツールは、Word、Excel、PowerPoint、OpenDocument、RTF、EPUB のファイルに書き込んだり、PDF を上書きしたりすることはありません。モデルが見たのはそのテキストだけだからです。Aristra Code は、それらをコマンドでライブラリを使って変更します。

## コマンドとバックグラウンド処理

| ツール | 動作 |
|---|---|
| `shell` | コマンドを実行します。[サンドボックス](/ja/code/configure/sandbox)がオンなら（既定はオフ）その中で実行します。バックグラウンドで実行したり、理由を添えてサンドボックスの外での実行を求めたりすることがあります |
| `process_list`、`process_read`、`process_stop` | バックグラウンドのコマンド、エージェント、ワークフローの実行、モニターを一覧表示、読み取り、停止します |
| `monitor` | 出力の行がイベントとしてチャットに届くスクリプトを、最大 30 分（既定は 5 分）実行します（*オンデマンド*） |
| `cron_create`、`cron_delete`、`cron_list` | このチャットで、1 回、または cron のスケジュールでプロンプトをスケジュールします（*オンデマンド*） |
| `schedule_wakeup` | 自分でペースを決める `/loop` で、次に確認する時刻を決めます |
| `schedule_task` | このコンピューターに[スケジュールタスク](/ja/code/guides/background)を保存するか、変更します。必ず先に確認を求めます（*オンデマンド*） |
| `scheduled_tasks` | 保存したスケジュールタスクを一覧表示するか、一時停止、再開、実行、削除します（*オンデマンド*） |
| `session_search` | 以前の作業を引き継ぐために、このコンピューター上の過去のチャットを検索、読み取り、一覧表示します。シークレットチャット、メモリがオフのチャット、アカウントの **Memory** か **Search and reference past chats** がオフの間は使えません（*オンデマンド*） |
| `push_notification` | 離れているときに、このコンピューターに通知を送ります（*オンデマンド*） |
| `enter_worktree`、`exit_worktree` | 自分や指示が求めた場合にだけ、チャットを git のワークツリーに移したり戻したりします（*オンデマンド*） |

## ウェブ

| ツール | 動作 |
|---|---|
| `web_fetch` | コンピューターから取得したページを読みます。ページは 15 分間キャッシュされます |
| `web_search` | ウェブを検索します。自分の Brave キーを設定していればそれを使い、なければ Aristra の検索を使います（残高から 1 回 $0.0075。[使用量と価格](/ja/account/usage)を参照してください）。Aristra の検索を使えない場合（残高を使い切った、またはサービスが停止している）は、Exa、Parallel、Firecrawl、Keenable のいずれかの無料の公開検索が使われ、送信されるのは検索語だけです（それらのサービスは検索語を保持することがあります）。設定で `web.keylessFallback: false` にするとオフにできます。1 つのチャットで最大 200 回まで検索できます |
| `cloud_browser_*` | ブラウザーが必要なページのために、Aristra がクラウドで動かすブラウザー |
| `browser_*` | Aristra Desktop のブラウザーパネル。サイトごとの同意のもとで、移動、戻る、読み取り、検索、クリック、入力、キー操作、スクロール、選択、タブの管理を行います |

## エージェントとワークフロー

| ツール | 動作 |
|---|---|
| `agent` | [サブエージェント](/ja/code/guides/subagents)かフォークをバックグラウンドで起動します |
| `send_message` | サブエージェント、またはこのコンピューター上で動いている自分の別のチャットに、名前を指定してメッセージを送ります（*オンデマンド*） |
| `list_agents` | このチャットのエージェントと、動いている自分の他のチャットを一覧表示します |
| `workflow` | [ワークフロー](/ja/code/guides/subagents)のスクリプト、または名前で指定した保存済みのワークフローを実行します |
| `skill` | 自分の[スキル](/ja/code/extend/skills)を 1 つ読み込みます |
| `task_create`、`task_get`、`task_update`、`task_list` | タスクリストが必要なモデルのために、チャットのタスクリストを管理します（`ARISTRA_ENABLE_TODO_TOOLS=1` でない限り、現行の Claude のモデルには渡されません）。`ARISTRA_ENABLE_TASKS=false` の場合は、代わりに `todo_write` を使います（*オンデマンド*） |
| `update_plan`、`wrap_up` | Aristra Desktop で作成したチャットで、入力欄の上に表示するタスクリストと、次のステップを含む締めくくりの要約 |

## メモリ、アカウントのファイル、Craft

| ツール | 動作 |
|---|---|
| `memory_save`、`memory_update`、`memory_forget`、`memory_search` | [アカウントのメモリ](/ja/code/guides/memory) |
| `library_search`、`library_read` | アカウントのファイル（ウェブサイトの **Files**） |
| `library_save` | 頼まれた場合にだけ、このコンピューター上のファイルのコピーをアカウントのファイルに保存します。もう一度保存すると、そのコピーを置き換えます |
| `craft_list`、`craft_create`、`craft_read`、`craft_edit`、`craft_comment` | Aristra Desktop での Craft のドキュメント |
| `present_files` | ファイルをカードとして表示します |
| `send_user_file` | [Remote Control](/ja/code/remote-control) で共有したチャットで、スマートフォンやウェブにファイルを送ります（*オンデマンド*） |

## MCP、コネクター、コードインテリジェンス

| ツール | 動作 |
|---|---|
| `mcp__<server>__<tool>` | 自分の [MCP サーバー](/ja/code/extend/mcp)のツール |
| `connectors__<app>__<action>` | Aristra アカウントに接続したアプリの操作（コネクターを含むプランが必要） |
| `tool_search`、`tool_describe`、`tool_call` | 毎ターンすべてを送らずに、MCP とコネクターのツールを探して使います |
| `list_mcp_resources`、`read_mcp_resource` | MCP サーバーのリソース（*オンデマンド*） |
| `refresh_mcp_tools` | MCP サーバーのツールが変わったあとに、一覧を更新します（*オンデマンド*） |
| `lsp` | プラグインの言語サーバーを通じて、定義への移動、参照の検索、診断の読み取りを行います（*オンデマンド*） |

## モデルから見た結果

50,000 文字を超える、またはツール自体の上限を超えるツールの結果は、モデルが開けるファイルに保存され、モデルには 2,000 文字のプレビューが渡されます。外部からのコンテンツ（ページ、ファイル、ツールの出力）は、信頼できないデータという印付きでモデルに届き、シークレットのように見える値はマスクされます。
