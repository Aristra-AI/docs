description: "コンピューター上のチャットをスマートフォンや app.aristralabs.com から続けたり、そこから新しく始めたりします。作業はコンピューター上で実行されます。"
---

Remote Control は、コンピューター上で実行しているチャットを Aristra のアカウントと共有し、スマートフォンや app.aristralabs.com からチャットを読み、メッセージを送り、承認に応答できるようにします。コードとコマンドはコンピューター上にとどまり、やり取りされるのは会話だけです。

<Note>
Remote Control は、Aristra のサーバーで実行される[クラウドチャット](/ja/code/cloud-chats)とは別のものです。Remote Control では、作業はコンピューターが行います。
</Note>

共有したチャットはアカウントに保存されるため、Remote Control は[プラン](/ja/account/plans)に含まれます。プランがない場合は、オンにしようとすると、ターミナルと Aristra Desktop にその旨が表示されます。

## オンにする

<Tabs>
  <Tab title="ターミナル">
    チャットで次のコマンドを実行します。

    ```text
    /remote-control
    ```

    このコンピューター上のチャットで、最初のメッセージのあとに実行します。クラウドチャットはすでにウェブ上にあります。Aristra Code がチャットのリンクを表示します。`/rc` は短縮形で、`/remote-control off` で共有を停止します。
  </Tab>
  <Tab title="Aristra Desktop">
    この Mac で実行しているチャットを右クリックし、**Continue on phone and web** を選択します。共有したチャットには、サイドバーでスマートフォンのアイコンが付きます。停止するには **Stop sharing to phone and web** を選択します。
  </Tab>
</Tabs>

Remote Control を使うには、このコンピューターがデバイスキーでサインインしている必要があります。サインインしていない場合はメニューにその旨が表示されるので、このコンピューターでもう一度サインインしてください。

## スマートフォンとウェブからできること

- ステップも含め、実行中のチャットを読む。
- メッセージを送る。返信の実行中に送ったメッセージは待機し、その返信のあとに実行されます。Aristra Desktop で ⌘Enter を押してキューに入れたメッセージと同じです。
- 実行中の返信を停止する。
- ステップを承認または拒否する。別のデバイスから許可するには、そのデバイスで新たにサインインの確認が必要です。「don't ask again」の回答は表示されません。キーなどのシークレットを求める質問には、コンピューター上でしか回答できません。コンピューター上での回答が優先されます。
- コンピューターが提供するものの中から、チャットのモードとモデルを切り替える。より制限の緩いモードにする場合は、先に新たなサインインの確認が求められます。
- メッセージにファイルを添付する。

## コンピューターが離れているとき

ターミナルを閉じたりランタイムが停止したりしても、共有したチャットは共有されたままです。その間にスマートフォンやウェブから送ったものは、待機中の印が付いて待機し、コンピューターが戻ると実行されます。チャットのトランスクリプトは、共有を停止したあとも、削除するまでアカウントに残ります。

## ウェブやスマートフォンからコンピューター上のチャットを始める

コンピューターの前にいなくても、そのコンピューターで新しいチャットを始められます。app.aristralabs.com で、新しいチャットの上にある **Runs on Aristra Cloud** を選び、コンピューターを選択します。そのページでフォルダーを選び、メッセージを入力します。チャットはそのコンピューター上で、そのファイル、シェル、ツールを使い、残高から支払う Aristra のモデルで実行されます。他の共有チャットと同じようにアカウントに保存されます。プランと、デバイスキーでサインインしたコンピューターが必要です。

**コンピューター自体で**許可するまでは、何も始められません。既定ではオフで、ウェブサイトからオンにすることはできません。

<Tabs>
  <Tab title="Aristra Desktop">
    **Settings › General › From the web and phone** を開き、**Start chats on this Mac from the web and phone** をオンにします。次に、チャットを始めてよい各フォルダーをオンにします。
  </Tab>
  <Tab title="ターミナル">
    ```text
    /remote-control computer on
    /remote-control folder on
    ```

    1 つ目のコマンドで、このコンピューターについてオンにします。2 つ目のコマンドで、今いるフォルダーを許可します。`/remote-control computer` で許可されている内容を確認でき、`on` の代わりに `off` を付けるとそれぞれを元に戻せます。
  </Tab>
</Tabs>

| ルール | 意味 |
|---|---|
| **フォルダーは先に信頼しておく必要がある** | コンピューター上でそのフォルダーのチャットを開き、信頼します。信頼していないフォルダーは許可できません |
| **許可できないフォルダーがある** | ホームフォルダー自体、その中の隠しフォルダー、ディスクのルート |
| **ウェブサイトに伝わるのはフォルダー名だけで、パスは伝わらない** | ウェブサイトに見えるのはフォルダーの名前です。パスはコンピューター上にとどまります |
| **コンピューターが開始のたびに確認する** | スイッチ、フォルダー、信頼、モードは、毎回コンピューター上で改めて確認されます |
| **別のデバイスからは bypass できない** | Manual、Accept edits、Plan、Auto のいずれかを選ぶか、コンピューター自体の既定のままにします |
| **コンピューターがオンラインである必要がある** | 開始するには、コンピューターの電源が入っていて接続されている必要があります。そのあとに送ったメッセージは、他の共有チャットと同じように、コンピューターを待ちます |

承認は、チャット内、ウェブ、コンピューター上で待機し、最初の回答が採用されます。別のデバイスからチャットが始まると、コンピューターに通知が表示されます。

## いつでもアクセスできるコンピューター

[クラウドコンピューター](/ja/surfaces/cloud-computer)は、Aristra のクラウドにある自分専用のコンピューターです。ウェブやスマートフォンからチャットを始められ、メッセージを受けると起動するため、離れていることがありません。

## 接続のしくみ

コンピューターは、デバイストークンとデバイスキーで認証した、Aristra への外向きの HTTPS 接続を維持します。コンピューター上では何も待ち受けておらず、スマートフォンやウェブからの各リクエストは最大 1 回しか実行されません。
