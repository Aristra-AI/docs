## 1 つのエージェント、多くのサーフェス

入力するプログラムである `aristra` はクライアントです。エージェント自体は **Aristra Runtime** で、コンピューター上のバックグラウンドプロセスとして、すべてのサーフェスから共有されます。ターミナル、[Aristra Desktop](/ja/code/desktop)、[エディター](/ja/code/editors)、SSH で接続する[リモートマシン](/ja/code/remote-machines)です。

```text
 aristra (terminal)    Aristra Desktop    an editor (aristra acp)    aristra --remote <host>
          \                  |                    |                         |
           '------------ the runtime protocol on a private socket ---------'
                                       |
                            Aristra Runtime (one per user)
          chats, turns, approvals, permissions, sandbox, tools, models,
          sign-in and secrets, settings, memory, MCP servers, scheduled tasks
                                       |
   Out only: api.aristralabs.com, the model providers you use, model servers on
   this computer, and the pages, MCP servers and services your chats use
```

1 つのランタイムを共有するため、次のようになります。

- ターミナルで始めたチャットは Aristra Desktop の Code タブに表示され、その逆も同じです。
- 承認には、開いているどのサーフェスからでも応答できます。最初の回答が採用され、他のサーフェスには誰が応答したかが表示されます。
- 実行中のターンは、それを始めたウィンドウやターミナルに依存しません。ターンの実行中にターミナルを終了しようとすると、実行を続けるかどうかを尋ねられます。

ランタイムは、サーフェスが必要としたときに起動し、10 分間アイドル状態が続くと自動的に停止します。ネットワークで待ち受けることはありません。サーフェスは、自分のユーザーアカウントだけが開けるソケットを通じてランタイムに接続します。

## ターンで行われること

メッセージを送ると、Aristra Code は作業が終わるまでループを実行します。

1. **コンテキストを集めます**。メッセージ、それまでのチャット、指示ファイル（`AGENTS.md` とルール）、メモリ、使えるツールがモデルに渡されます。
2. **行動します**。モデルがツールを要求します。ファイルを読む、検索する、編集する、コマンドを実行する、ページを取得する、MCP サーバーを呼び出すなどです。各要求は[権限](/ja/code/configure/permissions)の設定を通り、実行されるか、確認を求めるか、拒否されます。
3. **確認します**。各ツールの結果がモデルに戻され、モデルが次のステップを決めます。別のツールを使うか、返信するかです。

いつでも介入できます。メッセージを送って次のステップでターンに指示を伝えることも、ターンのあとに送るメッセージをキューに入れることも、Esc キーを押して停止することもできます。長い会話は、モデルのコンテキストがいっぱいになると要約されます。[コンテキスト](/ja/code/guides/context)を参照してください。

## コンピューター上のチャットとクラウドのチャット

ほとんどのチャットは、選んだフォルダーでコンピューター上で実行され、このコンピューターの `~/.aristra` に保存されます。一部のチャットは代わりにクラウドで実行されます。

| | コンピューター上 | クラウド |
|---|---|---|
| 開始方法 | `aristra`、Aristra Desktop の Code タブ | `aristra --cloud`、ウェブサイト、スマートフォン |
| 保存先 | このコンピューターの `~/.aristra` | Aristra のアカウント |
| モデル | 設定したどのソースでも | Aristra のモデル。残高から支払い |
| プランの要否 | 不要。自分のモデルなら無料 | 不要。残高から支払い、プランにすると毎月の利用枠が加わります。[プランと料金](/ja/account/plans)を参照してください |
| フォルダー | 作業フォルダー | 任意。このコンピューター上のフォルダーを、ランタイムを通じて読み、変更します |

コンピューター上のチャットは、[Remote Control](/ja/code/remote-control) でスマートフォンやウェブから続けることもできます。その場合も作業はこのコンピューターで実行されます。Aristra のクラウドエージェントが実行するチャットについては、[クラウドチャット](/ja/code/cloud-chats)を参照してください。

## 保存場所

| 対象 | 場所 |
|---|---|
| プログラム | `~/.local/bin/aristra`。`~/.local/share/aristra/versions/<version>/` へのリンクです |
| データ（チャット、設定、ログ、シークレット） | `~/.aristra/`（または `ARISTRA_HOME`） |
| 自分の設定 | `~/.aristra/settings.json` |
| プロジェクトの設定 | `<folder>/.aristra/settings.json` と `settings.local.json` |
| プロジェクトの指示 | リポジトリのルートから下の各フォルダーにある `AGENTS.md`（または `.aristra/AGENTS.md`）、`.aristra/rules/*.md`、個人用の `AGENTS.local.md`。`AGENTS.md` がない場所では Claude Code の `CLAUDE.md` ファイル |
| ランタイムのログ | `~/.aristra/logs/runtime.log`（`aristra logs`） |

サインイントークンやプロバイダーキーなどのシークレットは、ログインキーチェーン（または Linux のキーリング。どちらも応答しない場合は、自分だけが読めるファイル）に保存されたキーで暗号化されます。コンピューターのサインインはデバイスキーに結び付けられ、Secure Enclave のある Mac ではキーはそこに保存されます。[セキュリティとプライバシー](/ja/code/security)を参照してください。
