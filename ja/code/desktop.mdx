[Aristra Desktop](/ja/surfaces/desktop) の **Code** タブは、Mac で使う Aristra Code です。フォルダーとそのチャット、そしてコーディング中にチャットの横で使うものすべてがあります。ターミナルと同じランタイムと `~/.aristra` フォルダーを使うため、一方で始めたチャットはもう一方にも表示されます。

## Code タブでチャットを始める

Code タブの新しいチャットでは、メッセージ欄の下に次の選択肢があります。

| 選択肢 | 内容 |
|---|---|
| **Folder** | チャットが作業するフォルダー。新しいチャットは、最後に使ったフォルダーで始まります。**Add folder…** でフォルダーを追加します |
| **Where it runs** | **On this Mac**：この Mac にのみ保存され、設定したどのモデルでも使えます。**In the cloud**：[残高](/ja/account/credits)または[プラン](/ja/account/plans)から支払われ、Aristra のアカウントに保存されるため、ウェブやスマートフォンにも表示されます。フォルダーはこの Mac に残ります |
| **Project** | Aristra のプロジェクト。その指示とメモリを使います。プロジェクトのチャットはクラウドで実行され、この Mac にプロジェクトのメインフォルダーがあればそこで作業します |
| **Permissions** | この Mac 上のチャットの場合は、**Manual**（変更の前に常に確認）、**Accept edits**、**Plan**、**Auto**（権限の判断を Aristra に任せる）のいずれか。チャットの途中でいつでも切り替えられます。クラウドのチャットでは、ウェブサイトと同じく Manual か Auto を使います |
| **+ menu** | この Mac 上のチャットの場合、**Work in a new worktree**（git のフォルダーで使用可）を選ぶと、チャットに専用のワークツリーとブランチが割り当てられ、フォルダーはそのまま保たれます。カスタムエージェントは **Run as …** として表示され、**Share my profile** と **Permissions and tools** もここにあります |

新しいチャットでは、メッセージ欄の下にフォルダーのブランチと変更されたファイルの数が表示されます。そのメニューから Review changes を開いたり、ブランチを切り替えたりできます。Code タブのホームには、最近のチャット、プルリクエスト、今月の作業、アクティビティが表示されます。

## チャットの横

Code のチャットのヘッダーには、コーディング中に使うパネルがあります。サイドパネルは一度に 1 つ表示され、ターミナルはチャットの下に開きます。Terminal、Review、Open in、Pull request は、この Mac 上のチャット用です。

| パネル | 開き方 | 内容 |
|---|---|---|
| **Terminal** | ⌘J | チャットのフォルダー（ワークツリーで作業するチャットではそのワークツリー）で動く本物のシェル。各チャットは独自のシェルをタブで保持し、パネルを隠している間も動き続けます |
| **Review** | ⌥⌘B | フォルダーの変更内容。コミットしていない変更、既定のブランチまたは別のブランチに対するすべての変更、1 つのコミット、直前のターン自体の編集を表示できます。各ファイルは、最初の変更箇所でエディターに開きます |
| **Browser** | ⇧⌘B、または返信内のリンク | タブを備えた本物のブラウザー。サイトごとに同意すれば、エージェントも使えます |
| **Files** | ヘッダー、またはチャット内のファイルカード | チャットのファイル。テキスト、PDF、画像、Office ファイルをプレビューできます |
| **Pull request** | ヘッダーの **PR #N** | チャットのプルリクエスト。ステータス、チェック、ファイル、コミット、会話を表示し、マージ、承認、チェックの再実行ができます |
| **Open in** | ヘッダーのエディターボタン | フォルダーを、VS Code、Cursor、Zed、Windsurf、Xcode（インストールされているもの）、Finder、またはチャットの Terminal パネルで開きます |

プルリクエストのないブランチでは、ヘッダーに **Create PR**、**Create draft PR**、**Manually create PR** が表示されます。Pull request パネルで、自分が開いたプルリクエストの **Auto-fix CI & address comments** スイッチをオンにすると、チェックが失敗したとき、コンフリクトが発生したとき、レビュアーがコメントしたときに、チャットが再開します。[Git とプルリクエスト](/ja/code/guides/git)を参照してください。

## チャットの中

- **ステップ**は 1 行の要約にまとめられ、開くと各コマンド、編集、読み取りが表示されます。編集では差分が表示されます。
- **承認**は、実際のコマンドや差分とともにチャット内に表示されます。承認にはどのサーフェスからでも応答でき、最初の回答が採用されます。
- この Mac 上のチャットで**返信の実行中**に Enter キーを押すと、メッセージは次のステップで返信に加わります。⌘Enter（または送信ボタン）では、返信のあとに送るようキューに入れます。ファイルを添付したメッセージは常にキューで待機します。キューに入ったメッセージは入力欄の上で待機し、そこで 1 つをすぐに送ったり、並べ替えたり、削除したりできます。
- **/ メニュー**には、Add files or photos、+ メニューの選択肢、New Craft doc（チャットの横に開きます）、Mention a Craft doc があり、この Mac 上のチャットではさらに Context usage、Compact、Goal があります（自分のスキルはターミナルの `/` メニューにあり、Aristra Code はすべてのサーフェスでスキルを使います）。`!` を入力すると、チャットのフォルダーで自分でコマンドを実行できます。
- この Mac 上のチャットで、自分のメッセージの **Restore to here** を選ぶと、そのメッセージの前の状態に戻ります。コードと会話の両方か、どちらか一方だけを戻せます。
- **バックグラウンドのコマンド**とチャットのエージェントは、実行中はメッセージ欄の上に一覧表示され、それぞれに出力と停止ボタンがあります。

## フォルダー

サイドバーの各フォルダーには、そのチャットが新しい順に一覧表示されます。フォルダーのメニューには、**New chat here**、**Open terminal**、**Review changes**、**Use from other devices**、**Open in Finder** があります。

- フォルダーの名前を変更したり移動したりしても追跡されます。Aristra がフォルダーを見つけられない場合は、サイドバーにその旨が表示され、**Locate folder…** が表示されます。
- **Use from other devices** を使うと、この Mac でそのフォルダーを使って始めたチャットで、ウェブサイトとスマートフォンからフォルダーを読めるように、または読んで変更できるようにします。選択肢は **Off**、**Read only**、**Read and edit** です。別のデバイスから変更を求めるたびに、そのデバイスで新たにサインインの確認を行うか、この Mac で応答する必要があります。**Activity from other devices…** で、他のデバイスが行ったことを一覧表示できます。Read only と Read and edit は[プラン](/ja/account/plans)に含まれます。
- フォルダーが別の Mac にあるコーディングのチャットは、**On other devices** に一覧表示されます。

## スマートフォンとウェブで続ける

この Mac で実行しているチャットを右クリックし、**Continue on phone and web** を選択します。チャットがアカウントに保存され、作業はこの Mac で実行したまま、app.aristralabs.com やスマートフォンでメッセージを読んだり送ったりできます。[Remote Control](/ja/code/remote-control) を参照してください。この機能と、ウェブからチャットを始める機能は[プラン](/ja/account/plans)に含まれます。

ウェブやスマートフォンからこの Mac で新しいチャットを始めるには、**Settings › General › From the web and phone** をオンにし、チャットを始めてよいフォルダーを許可します。[コンピューター上でチャットを始める](/ja/code/remote-control)を参照してください。

## スケジュールタスクと Inbox

この Mac のスケジュールタスクは、スケジュール（1 回のみ、毎時、毎日、平日、毎週）に沿ってフォルダーでプロンプトを実行します。毎回新しいチャットで実行することも、1 つのチャットで実行することもできます。プランは不要で、Aristra のモデルを使うタスクの料金は残高から支払われます。タスクのフォームで作成するか、チャットで頼んで（「平日の毎朝 9 時にビルドを確認して」）、Aristra が表示するタスクを承認します。[プラン](/ja/account/plans)があれば、この Mac の電源が切れていても、タスクをクラウドで実行できます。Code タブの **Inbox** には、すべての実行が未読のドット付きで一覧表示されます。報告することがない実行は、既読の状態で届きます。この Mac のタスクは、Aristra が開いている間、または **Keep Aristra running in the background**（Settings › General。タスクのフォームでも一度提案されます）をオンにしていればアプリを閉じていても実行されます。[バックグラウンド処理](/ja/code/guides/background)を参照してください。

## キーボードショートカット

| キー | 操作 |
|---|---|
| ⌘J | Terminal パネル |
| ⌥⌘B | Review パネル |
| ⇧⌘B | Browser パネル |

その他のショートカットは [Aristra Desktop](/ja/surfaces/desktop) にあります。
