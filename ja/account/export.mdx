## デバイス

**Devices** には、アカウントにサインインしているすべてのコンピューター（Aristra Desktop、Aristra CLI、クラウドコンピューター）が一覧表示されます。それぞれに、オンラインかどうかと、最後に確認された日時が表示されます。

**Sign out** を選択すると、そのコンピューターがアカウントから外されます。チャットとファイルはそのコンピューターに残ります。アカウントを使うには、もう一度サインインする必要があります。

## ダウンロード

**Downloads** には、Mac 用の Aristra Desktop と、Aristra CLI をインストールするコマンドがあります。

```sh
curl -fsSL https://aristralabs.com/install.sh | sh
```

どちらも無料で、自分のモデルで使えます。[Aristra Code をセットアップする](/ja/code/setup)を参照してください。

## エクスポート

**Import and export** では、アカウントのデータを 1 つの zip ファイルとして取得できます。プランは不要なので、プランが終了したあとも含め、作成したものはいつでも持ち出せます。

| ファイルの内容 | |
|---|---|
| `chats/` | アカウントに保存されたすべてのチャット。それぞれが Markdown ファイルで、全チャットの一覧も含まれます |
| `memory/` | Aristra があなたとあなたの作業について覚えていること。読みやすいファイルとデータの両方の形式 |
| `files/files.csv` | ファイルの一覧。名前、種類、サイズ、日付、ファイルが添付されたチャット |
| `usage.csv` | 1 年分の使用量の行 |
| `README.txt` | ファイルに含まれるものと含まれないもの |

1 つのファイルに含まれるのは、最大で 5,000 チャット（最新のもの）、20,000 件のメモリ、20,000 ファイル、50,000 行の使用量です。何かが含まれなかった場合は `README.txt` に記載されます。エクスポートは 1 時間に 6 回までできます。

別の場所に保存されているもの：

- **ファイル本体**は、**Files** からダウンロードします。
- **Craft のドキュメント**は、各ドキュメントのメニューから Markdown、Word、PDF でエクスポートします。
- 共有していない**コンピューター上のチャット**は、そのコンピューターの `~/.aristra` にあります。これらはアカウントには届いていません。
- **クラウドコンピューター**のチャットとメモリは、そのコンピューターのページからエクスポートします。[クラウドコンピューター](/ja/surfaces/cloud-computer)を参照してください。
