1 つの Aristra アカウントがどこでも使えます。自分のコンピューター上の Aristra は無料です。プランにすると、Aristra がホストする機能が加わります。

## Aristra の構成

| 名前 | 内容 |
|---|---|
| **Aristra One** | アカウントのプラン。Free、Plus、Pro、Max のいずれかです。ウェブサイト上のそのページに、プラン、残高、使用量、デバイスが表示されます |
| **ウェブサイト** | [app.aristralabs.com](https://app.aristralabs.com)。どのブラウザーやスマートフォンからでも使えるチャット（残高から支払うか、プランで利用）、ファイル、メモリ、Craft。[ウェブとスマートフォン](/ja/surfaces/web)を参照してください |
| **Aristra Desktop** | Mac 用のアプリ。チャットと Code タブ |
| **Aristra CLI** | Mac や Linux マシンのターミナルで使う `aristra` コマンド |
| **Aristra Code** | コーディングエージェント。Aristra Desktop の Code タブ、Aristra CLI、エディター、クラウドコンピューターで使います |
| **Aristra Cloud** | Aristra がホストするものすべて。Aristra のモデル、クラウドエージェント、クラウドコンピューター、アカウントのメモリ（すべてのアカウントにあります）、ストレージ、コネクター、クラウドのスケジュールタスクです |

## 無料で使えるもの

- アカウントにサインインし、自分のモデル（自分のプロバイダーキー、ChatGPT のプラン、コンピューター上で動くモデル）を使う **Aristra Desktop と Aristra CLI**。[モデル](/ja/code/configure/models)を参照してください。
- 自分のフォルダーで使う **Aristra Code** と、コンピューター上で動くすべてのツール。
- すべてのデバイスで使える**アカウントのメモリ**。Aristra があなたについて覚えていることで、チャット中に保存され、毎晩最近のチャットから学習されます。保存、インポート、検索に料金はかかりません。[メモリ](/ja/memory)を参照してください。
- Aristra Desktop とウェブの **Files**、ターミナルの `/files`。チャットが作成、共有したファイルや、チャットに渡したファイルです。コンピューター上での PDF、Word、Excel、PowerPoint のファイルの読み取りも無料です。クラウドでは、スキャンしたページの読み取りに 1 ページあたり $0.006（ビジョンを使う場合は $0.015）かかります。
- ウェブサイトと Aristra Desktop の **Craft**。Aristra と一緒に、または自分で書くドキュメントで、アカウントに保存されます。[Craft](/ja/craft) を参照してください。
- **ウェブとスマートフォンのチャットでのウェブ検索**。コンピューターからの検索は 1 回 $0.0075 で残高から支払われます。残高を使い切った場合は、オフにしない限り、無料の公開検索（Exa、Parallel、Firecrawl、Keenable）が使われます。
- アカウントの作成時に 1 回だけ付与される **$1 のスタータークレジット**。Aristra のモデルとホスト型ツールの支払いに使えるため、チャージする前にウェブやスマートフォンでチャットできます。
- ウェブサイト上のアカウントのページ。Overview、Profile、Personalization、Billing、Usage、Devices、Downloads、Import and export、Permissions、Agent payments、Cloud computer、Apps です。

プランがなくても[残高にチャージ](/ja/account/credits)できます。チャージした残高は、ウェブとスマートフォンのチャット、コンピューター上での Aristra のモデルとホスト型ツール、クラウドコンピューターの支払いに使えます。

## プランで追加されるもの

| | 無料アカウント | プランあり |
|---|---|---|
| ウェブとスマートフォン | チャット、プロジェクト、ファイル、Craft。チャットは残高から支払い | チャット、プロジェクト、ファイル、Craft のすべて |
| Aristra のモデル | すべてのモデル。残高から支払い | すべてのモデル。毎月の利用枠から支払い |
| Remote Control と共有チャット | なし | あり |
| クラウドのチャット | あり。残高から支払い | あり |
| コネクター、クラウドのスケジュールタスク、チャネル | なし | あり |
| クラウドコンピューター | Large まで。チャージした残高から支払い | あり。プランのサイズまで |
| ファイルのストレージ | 1 GB | 10 GB から |
| アカウントに保存する Craft のドキュメント | あり | あり |

プランとその料金、上限は[プランと料金](/ja/account/plans)に掲載しています。

## アカウントのページ

アカウントの設定はすべてこれらのページにあります。サイドバー下部のメニューから **Settings** を開くか、`app.aristralabs.com/account` にアクセスします。プロジェクト自体の設定（指示と、プランがあれば API キー）は、プロジェクトのページにあります。

| ページ | 内容 |
|---|---|
| **Overview** | アカウントにあるものと、各部分への入り口 |
| **Profile** | 名前、メールアドレス、アカウント ID、アカウントの削除 |
| **Personalization** | テーマとフォント、Aristra がどの程度自分の判断で動くか、メモリ、タイムゾーンと所在地 |
| **Billing** | ドル単位の残高、チャージ、プランとその比較、Stripe 上のカードと請求書 |
| **Usage** | モデル別、ツール別の支出の内訳、ツールの料金、Aristra が使う検索 |
| **Devices** | アカウントにサインインしているすべてのコンピューターと、そのサインアウト |
| **Downloads** | Aristra Desktop と Aristra CLI |
| **Import and export** | 1 つのファイルにまとめたアカウントのデータと、Aristra がインポートできる取り込み元 |
| **Permissions** | クラウドの Aristra が確認なしでできること、クラウドブラウザーがサインインしたままにするサイト |
| **Agent payments** | 何かの購入を頼んだときに Aristra が支払いに使えるウォレット |
| **Connectors** | プランが必要。アカウントにつないだアプリ。**Customize › Connectors** が開きます |
| **Cloud computer** | Aristra Cloud にある自分専用のマシン。プランがあれば、またはチャージした残高で使えます。作成、チャット、設定 |
| **Apps** | Aristra が公開した[サイト](/ja/sites)と、クラウドコンピューター上で Aristra が動かしているアプリ。それぞれ、あなただけが開けるアドレスにあります |
| **Scheduled tasks** | プランが必要。Aristra がスケジュールに沿ってクラウドで実行するタスク（ウェブサイトのサイドバーの **Scheduled tasks**）。自分のコンピューター上では無料です |
| **Storage** | プランが必要。アカウントの容量のうち、ファイルが使っている量 |
| **Workspace** | ワークスペースの名前とアイコン、メンバー、監査ログ。他の人を招待するにはチームワークスペースが必要ですが、まだ提供されていません |

[Models and prices](https://app.aristralabs.com/models) は、アカウントの有無にかかわらず誰でも読めます。
