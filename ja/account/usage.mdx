`app.aristralabs.com/account/usage` の **Usage** で、お金の使い道を確認できます。Aristra CLI では `/usage` で残高と今いるチャットの使用量を確認でき、Aristra Desktop には **Settings › Usage** があります。

## ページに表示される内容

| | |
|---|---|
| **Spent** | 期間（7 日、30 日、90 日）の合計と、そのうち毎月の利用枠、チャージした残高、スタータークレジットから支払われた額 |
| **Spending over time** | 日ごとの棒グラフ。モデル、ツール、クラウドコンピューターに分かれています。日にポインターを合わせるとその日の数値が表示されます。**Show as a table** で表として表示することもできます |
| **By model** | モデルごとのリクエスト数、入力トークン、キャッシュから読み取ったトークンとキャッシュに書き込んだトークン、出力トークン、費用 |
| **Tools and cloud** | 各ホスト型ツールとクラウドコンピューターの使用量と費用。無料の検索には Free と表示されます |
| **Recent tool calls** | 最近の呼び出しと、それぞれの費用 |
| **Download CSV** | 期間内のすべての使用量の行と、米ドル建ての正確な費用 |

合計はセント単位で四捨五入されます。1 セント未満の 1 回の課金は、合計では `<$0.01`、その行では小数点以下 4 桁（$0.0053）で表示されるため、お金がかかったものが $0.00 と表示されることはありません。

## モデルの価格

すべてのモデルは、プロバイダー自身の価格で課金されます。Aristra が上乗せすることはありません。各モデルの 100 万トークンあたりの入力と出力の価格は、[Models and prices](https://app.aristralabs.com/models) に掲載されています。キャッシュから読み取った入力は安くなります。一部のモデルでは、非常に長いプロンプトの場合、その呼び出しに限り料金が高くなります。何トークンからそうなるかはページに記載されています。

## ツールの価格

| ツール | 価格 |
|---|---|
| ウェブ検索（Brave。ニュース、画像、動画の検索も含む） | ウェブとスマートフォンのチャットでは無料。Aristra Desktop、CLI、クラウドコンピューターからは 1 回 $0.0075 |
| サンドボックスでのシェルコマンドとクラウドブラウザー | 1 分あたり $0.003。Aristra のコードツールでのコードの実行は無料 |
| ウェブページの読み取り | 1 ページあたり $0.01 |
| 画像生成 | 画像モデル自体の価格の 1.5 倍 |
| 文字起こし | 音声 1 分あたり $0.001 |
| ドキュメントのページの読み取り | 1 ページあたり $0.006、ビジョンを使う場合は $0.015 |
| クラウドコンピューター | 起動中 1 時間あたり $0.0122 から $0.0881（サイズによる） |
| クラウドコンピューターのディスク | 起動中かスリープ中かにかかわらず、1 GB あたり月額 $0.18 |
| コネクターの呼び出し | 現在は課金されません |

最新の一覧は Usage ページにあります。自分のコンピューター上で動くツール（ファイル、シェル、git、自分の MCP サーバー）には料金はかかりません。メモリも同様で、保存、インポート、検索、Aristra によるチャットからの学習に料金はかかりません。メモリを使うチャットで支払うのは、そのチャット自体のトークン分だけです。失敗した検索やページの読み取りには料金はかかりません。サンドボックスのコマンドは、失敗した場合でも実行した時間分が課金されます。

## Aristra が使う検索

Aristra は Brave でウェブを検索します。ウェブとスマートフォンのチャットでの検索は無料です。Aristra Desktop、CLI、クラウドコンピューターからの検索は 1 回 $0.0075 で、残高から支払われます。そこで残高を使い切った場合、オフにしない限り（`web.keylessFallback`）、検索は Exa、Parallel、Firecrawl、Keenable のいずれかの無料の公開検索に送られます。送信されるのは検索語だけです。

自分のコンピューターでは、**自分の Brave キー**を設定することもできます（Aristra Desktop では **Settings › Tools & keys**）。設定すると、自分のキーが常に最優先で使われ、Aristra での料金はかかりません。そのキーを読み取れない場合は、Aristra がその旨を知らせます。残高から支払う検索に黙って切り替えることはありません。Aristra の検索に戻すには、Settings でキーを削除します。
