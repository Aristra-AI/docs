ウェブサイト、スマートフォン、Aristra Desktop の Chat タブのチャットは Aristra Cloud で実行され、アカウントに保存されます。そのため、サインインしたどこでも同じチャットになります。コンピューター上のフォルダーで行うチャットは、[Aristra Code](/ja/surfaces/aristra-code) のチャットです。

## チャットを始める

- **ウェブまたはスマートフォンで**：[app.aristralabs.com](https://app.aristralabs.com) のサイドバーにある **New chat** を選択します。
- **Aristra Desktop で**：**Chat** ビューで新しいチャットを始めます。サインインが必要です。
- **Mac のどこからでも**：**⌥Space** を押してクイック入力を開き、入力して Enter キーを押します。
- **[プロジェクト](/ja/projects)の中で**：プロジェクトから始めると、そのプロジェクトの指示、ファイル、メモリが使われます。
- **Telegram から**：プランが必要です。[Telegram](/ja/surfaces/telegram) を参照してください。

## モデルを選ぶ

メッセージ欄の送信ボタンの横にあるモデルピッカーには、Aristra のモデルが並んでいます。Claude Haiku、Sonnet、Opus 5.5、GPT-6 Luna、GPT-6.1 Terra、GPT-6.1 Sol、Gemini 3.5 Flash-Lite、3.8 Flash、3.1 Pro です。**Auto** は Gemini 3.8 Flash を使います。各モデルにはコストの目安（$ から $$$）が表示され、一部のモデルでは思考の深さを選べます（Low、Medium、High、一部ではさらに Extra High と Max）。どのアカウントでもすべてのモデルを使えます。

メッセージごとに残高から支払われます。最初に新規アカウントのスタータークレジット、次にプランの毎月の利用枠、その次にチャージした残高が使われます。料金は [Models and prices](https://app.aristralabs.com/models) に掲載されています。残高がなくなると、メッセージ欄にその旨が表示され、チャージかプランへの加入を案内されます。

## チャットで Aristra にできること

| | |
|---|---|
| **ウェブを検索して読む** | ウェブ、ニュース、画像、動画を検索し、ページを読みます。**+** メニューに **Web search** と **URL extraction** のスイッチがあります |
| **ファイルを読む** | 添付ファイル、アカウントのファイル、PDF をページ単位で読みます |
| **コードを実行する** | 専用の Linux サンドボックスで、データを分析し、PDF、Word、Excel、PowerPoint のファイルやグラフを作成します |
| **画像を作る** | **+** メニューで **Create image** を選び、スタイルを指定します |
| **視覚的に示す** | グラフや図、天気、地図、比較表、メールの下書き（送信はできません）を表示します |
| **覚える** | 会話しながら、メモリを保存、更新、削除します。[メモリ](/ja/memory)を参照してください |
| **質問する** | 回答が必要なときに、質問や短いフォームを表示します |
| **アプリで作業する** | プランがあれば、接続したアプリで作業します。[コネクター](/ja/connectors)を参照してください |
| **ドキュメントを書く** | プランがあれば、チャットの横で [Craft](/ja/craft) のドキュメントを書きます |
| **作業をスケジュールする** | プランがあれば、[スケジュールタスク](/ja/scheduled-tasks)を設定します |

## ファイルを添付する

**+** を選択し、**Upload files or images** を選ぶか、アカウントにすでにあるファイルなら **Attach from Files** を選びます。1 つのメッセージに添付できるのは 5 ファイルまでで、1 ファイルあたり 50 MB、合計で 50 MB までです。Aristra は PDF（スキャンしたページも含む）、Word、Excel、PowerPoint、テキスト、CSV、JSON、コード、画像を読めます。

添付したファイルはチャットとともに保存され、チャットを削除するまで[ストレージ](/ja/files)の使用量に含まれます。

## 編集と再生成

メッセージにポインターを合わせると編集でき、返信にポインターを合わせると再生成できます。各バージョンは保存され、メッセージの矢印で切り替えられます。

## シークレットチャット

ウェブではチャット上部の、Aristra Desktop の Chat タブでは新しいチャットのゴーストアイコンを選択します。ターミナルでは `aristra --cloud --incognito` を実行します。シークレットチャットには次の特徴があります。

- チャットの一覧に表示されず、内容がメモリに保存されたり、あとで学習に使われたりすることはありません。
- Memory がオンなら、Aristra がすでに覚えているあなたのことは使えます。
- 一度離れると、もう一度開くことはできません。
- 最後のメッセージから 30 日後に削除されます。

## チャットを探す

- **ウェブで**：**Chats** ページにすべてのチャットが一覧表示され、タイトルで検索できます。**⌘K** で最近のチャット、プロジェクト、操作を開けます。**⌘F** で、開いているチャット内の語句を検索できます。
- **Aristra Desktop で**：**⌘K** で、タイトルによるチャットの検索、フォルダーとコマンドの検索、この Mac のチャットのメッセージ内の語句の検索ができます。

## エクスポートと削除

チャットのメニューには **Rename**、**Export as Markdown**、**Copy transcript (Markdown)**、**Delete** があります。チャットを削除すると、チャットとそのファイルが削除されます。すべてのチャットのコピーを一度に取得するには、[エクスポート](/ja/account/export)を参照してください。

チャットを公開リンクとして共有することはできません。Aristra が書いたものを共有するには、[Craft](/ja/craft) のドキュメントを公開します。Aristra が作成したファイルも、カードの **Publish** から公開リンクで公開できます。

## 音声入力

Aristra Desktop では、メッセージ欄のマイクボタンで最大 10 分の音声入力ができ、文字に起こして入力してくれます。料金は 1 分あたり $0.001 で、残高から支払われます。[Telegram](/ja/surfaces/telegram) では、Aristra がボイスメッセージを読み取ります。
