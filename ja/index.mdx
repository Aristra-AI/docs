Aristra は、1 つのアカウントで使う 1 つのアシスタントです。ウェブやスマートフォン、Mac の Aristra Desktop、ターミナル、Telegram から話しかけられます。Aristra Cloud にあるチャット、Aristra が覚えているあなたのこと、そしてファイルは、どこで使っても引き継がれます。

## 使える場所

Aristra を使う場所のそれぞれをサーフェスと呼びます。どのサーフェスも同じアカウントを共有するため、Aristra Cloud のチャットはどのサーフェスにも表示されます。Aristra Code がコンピューター上で実行するチャットは、Remote Control で共有しない限り、そのコンピューターにとどまります。

| サーフェス | 内容 |
|---|---|
| [ウェブとスマートフォン](/ja/surfaces/web) | [app.aristralabs.com](https://app.aristralabs.com)。どのブラウザーでも、スマートフォンでも使えます。アカウントのページもここにあります |
| [Aristra Desktop](/ja/surfaces/desktop) | Mac 用のアプリ。会話用の **Chat** タブと、Aristra Code 用の **Code** タブがあります |
| [Aristra Code](/ja/surfaces/aristra-code) | コンピューター上のフォルダーで作業する Aristra。ターミナルの `aristra` コマンド、Aristra Desktop の Code タブ、エディターで使えます |
| [Telegram](/ja/surfaces/telegram) | プランがあれば、Telegram から Aristra にメッセージを送れます |
| [クラウドコンピューター](/ja/surfaces/cloud-computer) | Aristra のクラウドにある自分専用の Linux コンピューター。手元のコンピューターの電源が切れている間も、Aristra がここで作業します。プランかチャージした残高が必要で、スタータークレジットでは支払えません |

## 料金

アカウントの作成は無料で、Aristra のモデルとツールに使える $1 のクレジットが付いてきます。ウェブでのチャットは使った分だけ残高から支払われ、メモリ、Craft、1 GB のファイル保存はすべてのアカウントに含まれます。Aristra Desktop と Aristra CLI は、自分のモデル（自分のプロバイダーキー、ChatGPT のプラン、コンピューター上のモデル）を使えば無料です。[自分のモデルを使う](/ja/own-models)を参照してください。

プラン（Plus は月額 $20、Pro は $100、Max は $200）にすると、その金額分の Aristra のモデルの利用枠が毎月付き、さらにコネクター、クラウドでのスケジュールタスク、Telegram、ウェブからのコンピューターの利用が加わります。[アカウントと Aristra One](/ja/account/overview) と[プランと料金](/ja/account/plans)を参照してください。
