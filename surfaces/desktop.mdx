Aristra Desktop is the Aristra app for Mac. Its sidebar has two tabs:

- **Chat**: your Aristra conversations without a folder, with Chats & tasks, Files and Craft. A chat without a folder runs in Aristra Cloud, which comes with a [plan](/account/plans); without one the message box says so.
- **Code**: Aristra Code. Your folders with their chats, and everything you use while coding beside the chat.

Switch between them with the switch at the top of the sidebar, or with **⌥⌘←** and **⌥⌘→**. The tab you are not on shows a dot when a chat there waits for you (amber) or is working (green). Opening any chat, from search, a notification or the Dock, moves to its tab.

Aristra Desktop includes Aristra Code, so you don't need to install the Aristra CLI separately. Both use the same runtime and the same `~/.aristra` folder: a chat started in the terminal shows in the Code tab, and the other way round.

## Start a chat in the Code tab

Under the message box of a new chat in the Code tab:

| Choice | What it does |
|---|---|
| **Folder** | The folder the chat works in. A new chat starts in the last folder you used. **Add folder…** adds one |
| **Where it runs** | **On this Mac**: saved only here, with any model you set up. **In the cloud**, paid from your [balance](/account/credits) or a [plan](/account/plans): saved to your Aristra account, on the web and your phone too, while the folder stays on this Mac |
| **Project** | An Aristra project: its instructions and memory. A project chat runs in the cloud, in the project's main folder when it has one on this Mac |
| **Permissions** | **Manual** (always ask before making changes), **Accept edits**, **Plan** or **Auto** (Aristra handles permission decisions). You can switch at any point in the chat |
| **+ menu** | **Work in a new worktree** gives the chat its own git worktree and branch, so the folder stays as it is. Your custom agents appear here as **Run as …** |

A new chat also offers starters: **Explain this folder**, **Review changes**, **Build something**.

## Beside the chat

The header of a Code chat has the panels you use while coding. One side panel shows at a time.

| Panel | Opens with | What it shows |
|---|---|---|
| **Terminal** | ⌘J | A real shell in the chat's folder (its worktree's, for a chat in one). Each chat keeps its own shells, in tabs, running while the panel is hidden |
| **Review** | ⌥⌘B | The folder's changes: uncommitted, the branch against its base, or the last turn's own edits. Each file opens in your editor |
| **Browser** | ⇧⌘B, or a link in a reply | A real browser with tabs. The agent can use it too, with your consent per site |
| **Files** | The header, or a file card in the chat | The chat's files, with previews of text, PDFs, images and Office files |
| **Pull request** | The header's **PR #N** | The chat's pull request: status, checks, files, commits and the conversation, with Merge, Approve and re-running checks |
| **Open in** | The header's editor button | The folder in VS Code, Cursor, Zed, Windsurf, Xcode, Finder or Terminal |

On a branch without a pull request, the header offers **Create PR**, **Create draft PR** or **Manually create PR**. On your own open pull request, **Auto-fix CI & address comments** wakes the chat when checks fail, conflicts appear or reviewers comment. See [Git and pull requests](/guides/git).

## In the chat

- **Steps** fold into a one-line summary that opens to each command, edit and read. Edits show their diffs.
- **Approvals** appear in the chat with the exact command or diff. An approval can be answered from any surface, and the first answer wins.
- **While a reply runs**, Enter sends your message into it at its next step, and ⌘Enter queues it for after. Queued messages wait above the box, where you can send one now, reorder or remove them.
- **The / menu** has Context usage, Compact and Goal, and a new Craft doc beside the chat. (Your skills are in the terminal's `/` menu, and Aristra Code uses them in every surface.) Type `!` to run a command yourself in the chat's folder.
- **Restore to here** on one of your messages goes back to before it, with its files.
- **Background commands** and the chat's agents are listed above the message box while they run, each with its output and a Stop button.

## Folders

Each folder in the sidebar lists its chats, newest first. Its menu has **New chat here**, **Open terminal**, **Review changes**, **Use from other devices** and **Open in Finder**.

- A folder is followed when you rename or move it. If Aristra can't find it, the sidebar says so and offers **Locate folder…**.
- **Use from other devices** lets the website and your phone read the folder, or read and change it, in chats started with it on this Mac: **Off**, **Read only** or **Read and edit**. Each change asked from another device needs a fresh sign-in check there, or your answer on this Mac. **Activity from other devices…** lists what they did.
- Coding chats whose folder is on another Mac are listed under **On other devices**.

## Continue on your phone and the web

Right-click a chat that runs on this Mac and choose **Continue on phone and web**. The chat is saved to your account, and you can read and send messages from app.aristralabs.com or your phone while the work still runs here. See [Remote Control](/surfaces/remote-control).

To start a new chat on this Mac from the web or your phone, turn on **Settings › General › From the web and phone**, then allow the folders a chat may start in. See [Start a chat on your computer](/surfaces/remote-control#start-a-chat-on-your-computer-from-the-web-or-phone).

## Find something you said

Press **⌘K** and type. Under the chats and commands whose names match, **In messages** lists what was said in any chat on this Mac that holds your words. Choose one to open its chat. The search runs on this Mac; chats in the cloud are searched on the website.

## Files

**Files** in the sidebar lists what your chats on this Mac shared with you, made or changed, and the files you attached, newest first, with the chat each came from. Nothing is copied: a file opens where it is, beside the list, in its app, or in Finder, and **Go to the chat** opens its chat. A file that was moved or deleted shows as gone. Search by name, folder or chat title, or press Return to search inside the files: their words, from an index kept on this Mac (no AI, nothing sent), with the page of a PDF. In the terminal, `/files` lists the same files and `/files find` searches inside them.

Signed in, Files shows the files in your account too, the same ones as **Files** on the website: **All**, **On this Mac** or **In your account**. A file in your account downloads when you open it. Upload with the button or by dropping files on the list, rename, star, and send files to the trash and back. Press Return in the search box to search inside your account's files too, by the words in them and by name. Every account has room for them: 1 GB on a Free account, more with a [plan](/account/plans).

A file on this Mac reaches your account only when you save it: **Save to your account** in its menu, or ask Aristra to save it (`library_save`). The file stays on this Mac, shows once, marked **In your account**, and when it changes it offers **Update in your account**. If its copy was also changed on the web since, Aristra asks whether to replace that copy or keep both. Deleting either one never deletes the other. Without a connection, a save waits and goes when Aristra is reachable. When your account's storage is full, a save is refused and says so.

## Craft

**Craft** in the sidebar holds your docs: write them with Aristra or yourself, with versions, export to Markdown, a web page or PDF, and with a plan, comments and a share link.

Without a plan, a new doc is kept on this Mac, marked **On this Mac**: it opens, edits, keeps its versions and exports with no connection, and Aristra can write in it from a chat on this Mac. A doc made while offline is kept on this Mac too. With a plan, **Move to your account** in a doc's menu (or **Move all** at the top of Craft) puts it in your account with everything written in it, and it opens on the web and your phone. Nothing moves unless you ask. When a plan ends, your account's docs open to read and export, and new docs are kept on this Mac.

## Your plan and account

**Settings › Aristra One**, **Aristra One** in the account menu (your name, bottom left) or in **⌘K** opens your account's pages on app.aristralabs.com in a new tab of your browser: the plans, your balance, spending by day, your devices, the cloud computer and export. **Settings › Billing** shows your plan and balance in dollars in the app; without a running plan, **See plans** opens the plans there too. Payments always happen on Stripe's page in your browser. See [Plans](/account/plans).

## Scheduled tasks and the Inbox

A scheduled task on this Mac runs a prompt in a folder on a schedule (once, hourly, daily, weekdays or weekly), in a new chat each time or in one chat. It is free. Make one in the task form, or ask in a chat ("every weekday at 9, check the build") and approve the task Aristra shows you. With a [plan](/account/plans), a task can run in the cloud instead, even when this Mac is off. The **Inbox** in the Code tab lists every run, with unread dots; a run with nothing to report arrives already read. Tasks on this Mac run while Aristra is open, or with the app closed once **Keep Aristra running in the background** is on (Settings › General; the task form offers it once). See [Background work](/guides/background#scheduled-tasks).
